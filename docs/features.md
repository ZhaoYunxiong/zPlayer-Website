# 功能概览

zPlayer 的使用可以理解为三层：

| 层级 | 解决的问题 | 文档入口 |
| --- | --- | --- |
| 文件服务 | 媒体文件在哪里，怎样连接和浏览 | [文件服务](/docs/media/file-services) |
| 首页管理 | 怎样把媒体整理成可搜索、可推荐的首页 | [首页管理](/docs/media/home-management) |
| 在线媒体 | 怎样从在线站点搜索和播放内容 | [在线媒体](/docs/media/online-media) |

在此基础上，播放器负责实际播放体验，同步负责跨服务记录观看状态，设置参考则用于查询具体选项。

## 主要能力

- 聚合浏览本地目录、网络文件服务、云盘和媒体服务器。
- 通过扫描、刮削和元数据建立首页内容。
- 在媒体详情中查看剧集、版本、片源、演员和相关媒体。
- 支持在线媒体站点的搜索、线路选择和片源切换。
- 提供播放控制、硬件加速、画质、音频、字幕和弹幕设置。
- 支持 Bangumi、Trakt 以及部分媒体服务器的记录或进度同步。
- 提供 Whisper AI 字幕、语义搜索等可选能力，部分功能需要在设置中启用相应服务。

## 适合怎样开始

只想播放电脑里的文件，可以先看[文件服务](/docs/media/file-services)。

想要海报墙、分类和继续观看，可以看[首页管理](/docs/media/home-management)。

想直接搜索在线内容，可以看[在线媒体](/docs/media/online-media)。
