# 获取帮助

遇到问题时，建议先按下面的顺序处理：

1. 在[常见问题](/docs/faq)中搜索关键词；
2. 根据现象查看[故障排查](/docs/troubleshooting/)；
3. 在软件中导出日志，参考[日志导出与反馈](/docs/troubleshooting/logs-and-feedback)；
4. 仍然无法解决时，再联系开发者。

## 邮件里写什么

请尽量说明：

- Windows 版本和 zPlayer 版本；
- 媒体来源类型、连接方式和当前片源；
- 发生问题的作品、文件或集数；
- 从打开软件到出错的最短步骤；
- 是否可以稳定复现；
- 关闭某个设置或更换来源后的结果；
- 脱敏后的日志、刮削信息导出或播放诊断。

不要直接公开账号密码、Cookie、访问令牌、邮箱授权码或私有媒体地址。详细收集方式见[日志导出与反馈](/docs/troubleshooting/logs-and-feedback)。

## Microsoft Store 购买失败

如果 Microsoft Store 内购无法完成（例如网络错误、商店服务异常，或软件以管理员权限运行），不需要联系开发者：可以在官方网店大熊小铺自助购买 Microsoft Store 激活码，自动发货、价格与内购一致，在 Microsoft Store 兑换后即可解锁。完整步骤见[购买失败怎么办](/docs/getting-started/unlock#购买失败怎么办)。

如果订单已显示支付成功、或已经兑换了激活码，但软件长时间显示未解锁，请先按[内购解锁](/docs/getting-started/unlock)里的检查顺序处理；确认检查都正常后，再通过上面的邮箱或 zPlayer“关于”页面的动态二维码联系开发者，并附上脱敏后的订单成功记录。
