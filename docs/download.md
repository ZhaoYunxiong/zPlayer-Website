# 下载 zPlayer

zPlayer 通过 Microsoft Store 安装。打开商店页面，点击“获取”即可完成下载、安装和后续更新。

<a class="VPButton brand" href="https://apps.microsoft.com/detail/9n2p3rq5vxxj?hl=zh-CN&gl=CN">从 Microsoft Store 安装 zPlayer</a>

## 安装步骤

1. 点击上面的按钮，打开 zPlayer 的 Microsoft Store 页面；也可以直接在商店里搜索 **zPlayer**。
2. 点击“获取”或“安装”，等待 Windows 完成安装。
3. 从开始菜单启动 zPlayer。
4. 第一次使用可以先看[首次启动](/docs/getting-started/first-launch)，根据自己的媒体来源选择使用方式。

安装完成后不需要先配置所有选项：想马上播放一个视频，可以直接双击文件；想长期管理本地目录、NAS 或媒体服务器，再进入[文件服务](/docs/media/file-services)添加来源。

## 需要连接媒体服务器？

连接 Emby、Jellyfin、Plex、飞牛影视等媒体服务器属于内购解锁功能。普通本地文件播放不受影响；需要这项功能时，再阅读[内购解锁](/docs/getting-started/unlock)。

## 更新软件

打开 Microsoft Store，进入 zPlayer 页面即可查看是否有更新。商店会负责下载和安装新版本，更新前通常不需要移动媒体文件。

## 安装或更新遇到问题

- 商店页面打不开：先确认 Microsoft Store 能正常打开，并尝试搜索其他应用测试网络。
- 下载或安装停滞：重新打开商店，确认 Windows 有足够的磁盘空间，再重试安装。
- 找不到应用：使用上方官方链接，或在商店中搜索完整名称 `zPlayer`。
- 更新后发现异常：先重启 zPlayer，再查看[故障排查](/docs/troubleshooting/)；反馈时请附上 Windows 版本、zPlayer 版本和错误提示。

不要从不明镜像下载所谓“免安装版”或修改版。需要帮助时，可以前往[获取帮助](/support)联系开发者。
