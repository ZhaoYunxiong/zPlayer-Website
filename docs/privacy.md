# 隐私说明

最后更新：2026 年 9 月

本说明适用于当前面向 Windows 的 zPlayer 应用。zPlayer 是本地媒体库与播放器，很多功能直接在你的电脑上完成；当你主动使用联网服务时，应用才会向相应服务发起请求。

应用功能和第三方服务可能随版本变化。如果隐私相关行为发生变化，会在后续版本中更新本说明。

## 不需要注册才能播放本地媒体

播放本地文件不要求注册 zPlayer 账号，也不要求把本地媒体库上传到网络服务。你可以直接用资源管理器双击文件，或通过媒体库打开本地目录。

zPlayer 的本机账户用于区分同一台电脑上的使用者，不是网站账号，也不是 Microsoft 账户登录。账户、播放记录和播放列表默认属于本机配置。

## 哪些数据保存在本机

为了提供媒体库、播放器和设置功能，zPlayer 可能在本机保存：

- 媒体来源地址、目录和连接配置；
- 播放历史、继续观看进度、收藏、片单和播放列表；
- 媒体刮削结果、海报、背景图、缩略图和其他缓存；
- 播放器、字幕、弹幕、AI、RSS 和界面设置；
- 本机账户信息及你主动填写的第三方服务授权信息；
- 播放诊断和应用日志。

这些数据通常位于 Windows 的应用数据目录中。具体位置可以在“设置 → 其它 → 配置路径”打开查看。

缓存不是原始媒体。删除缓存会让部分海报、首页内容或缩略图重新生成，但不会删除你的电影、电视剧、音乐或 NAS 文件。

## 什么时候会联网

以下操作可能访问外部服务：

| 使用场景 | 可能访问的服务 |
| --- | --- |
| 获取标题、简介、海报和剧集信息 | TMDB 及相关图片服务 |
| 同步观看记录 | Bangumi、Trakt |
| 连接媒体服务器 | 你配置的 Emby、Jellyfin、Plex、飞牛影视等服务 |
| 浏览和播放在线媒体 | 你配置的在线站点、线路和媒体地址 |
| 搜索字幕或弹幕 | 你选择的字幕、弹幕服务 |
| 使用云端 AI | 你填写的 AI 服务商 |
| 下载 Whisper 模型 | 你选择的模型下载来源 |
| RSS 订阅和远程下载 | 你填写的 RSS、下载器 API 和邮件服务 |
| 更新部分在线站点或扩展配置 | 应用使用的相关在线服务 |
| 应用内购买和授权检查 | Microsoft Store |

访问哪个服务由你的操作和配置决定。第三方服务可能记录 IP、请求时间、账号标识或其服务正常运行所需的其他信息，具体以第三方自己的隐私政策为准。

## AI 和 Whisper

如果选择云端 AI 服务，发送给该服务的内容可能包括你触发功能时提供的文本、媒体资料、图片或字幕上下文。请先阅读服务商的隐私政策和计费规则。

如果使用本机 Ollama 或本机 Whisper 模型，主要处理过程可以在本机完成，但 Ollama、模型下载源和其他你启用的在线功能仍可能产生网络请求。不要把“使用本地模型”理解成整个 zPlayer 自动断网。

没有配置 AI 服务时，不需要为了普通本地播放启用语义搜索、内容识别或实时字幕。

## 账号、密钥和备份

你主动填写的 TMDB Key、AI API Key、媒体服务器密码、Bangumi/Trakt 授权信息、下载器密码和邮箱授权码，可能会保存到本机配置中，以便下次使用。

请只在你信任的服务中输入凭据，不要把凭据发送给开发者。软件导出的 zpb 数据备份可能包含来源地址、账号配置和授权信息，请像保管密码一样保管备份文件。

Microsoft Store 的购买、付款和授权由 Microsoft 处理。zPlayer 只根据商店授权状态判断相应功能是否解锁，不接触你的银行卡或支付账户信息。

## 日志和问题反馈

日志用于记录应用运行过程和错误上下文，可能包含媒体文件名、目录、服务器地址、用户名、请求 URL 和错误信息。Debug 级别通常比日常日志更详细。

向开发者反馈前，请删除或遮挡 API Key、访问令牌、Cookie、密码、邮箱授权码、私人媒体路径和不希望公开的服务器地址。详细步骤见[日志导出与反馈](/docs/troubleshooting/logs-and-feedback)。

## zPlayer 对外共享媒体

如果你主动开启 WebDAV、FTP 或 DLNA 共享，zPlayer 会在你指定的网络范围内提供相应服务。其他设备可能因此访问你允许共享的媒体或目录。

共享服务不是默认的公网存储服务。请在可信网络中使用，配置用户验证和防火墙，不要把端口直接暴露到公网。

## 数据删除和迁移

你可以在应用设置中清理缓存、重置配置，或导出/恢复软件数据。重置配置会删除当前设置和本机相关配置，恢复操作也会覆盖当前软件数据；操作前请先备份。

清理应用数据、卸载应用或手动删除应用数据目录前，请确认是否还需要播放记录、片单、来源配置和授权信息。原始媒体文件通常位于你自己的磁盘、NAS 或服务器中，不等同于 zPlayer 的应用数据。
