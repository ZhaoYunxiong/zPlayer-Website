# 常见问题

## zPlayer 支持什么系统？

zPlayer 面向 Windows，安装和更新请通过 Microsoft Store 完成。

## 文件服务、首页管理和在线媒体有什么区别？

文件服务负责连接和浏览来源；首页管理负责扫描、刮削和整理媒体信息；在线媒体负责从在线站点搜索和选择片源。三者可以同时使用。

## 是否需要配置 TMDB 才能播放本地文件？

不一定。播放本地文件主要依赖文件访问和播放器；TMDB 等元数据服务主要影响海报、简介、演员和首页整理。

## 为什么能看到媒体信息，却播放失败？

媒体信息和实际片源是两个层级。请在媒体详情中确认当前剧集、版本和片源，并尝试其他片源或查看媒体详情中的播放诊断。

## 内购后为什么没有立即解锁？

确认 Microsoft 账户、商店连接和安装渠道一致，然后重启软件。不要重复购买，仍有问题时保留订单信息并提交反馈。

## 需要把所有设置都改一遍吗？

不需要。设置参考用于查询具体选项；建议先按实际使用流程完成连接、首页和播放，再针对现象调整单个选项。

## 安装后为什么双击视频没有用 zPlayer 打开？

全新安装不代表 Windows 已经把媒体格式关联给 zPlayer。先在软件中使用“打开 → 文件”；需要双击打开时，到 Windows 11“设置 → 应用 → 默认应用 → zPlayer”，逐个选择希望交给 zPlayer 的扩展名。详细步骤见[打开文件、链接与种子](/docs/getting-started/open-media#用-windows-11-管理双击打开方式)。

## 在线媒体点击后为什么有时是详情页，有时直接选线路？

“设置 → 在线库 → 优先打开媒体详情”决定点击后的路径。开启时会尝试匹配统一媒体详情，无法匹配时使用简易线路弹窗；关闭时直接进入线路和剧集选择。见[搜索、线路与播放](/docs/media/online/source-selection)。

## 储物箱是不是等同于 BitLocker？

不是。储物箱主要降低他人从文件名、扩展名和双击操作直接识别内容的概率；它不替代 Windows 账户权限或整盘加密。需要应对电脑丢失或管理员读取时，应同时使用系统级保护。见[储物箱与加密播放](/docs/tools/storage-box)。

## 官网首页提到的功能在哪里找说明？

首页的每个功能标题都可以点击进入对应章节，也可以查看[首页功能与文档索引](/docs/features)。
