# 首页功能与文档索引

官网首页展示的每一项能力都对应一份可操作的说明。可以在首页直接点击功能标题，也可以从下面按目标进入文档。

## 媒体来源与整理

| 首页功能 | 能做什么 | 从哪里开始 |
| --- | --- | --- |
| 媒体库管理 | 连接本地目录、NAS、网盘和对象存储 | [文件服务与连接](/docs/media/file-services) |
| 批量重命名 | 按前缀、后缀、替换和编号规则批量改名 | [文件服务与连接](/docs/media/file-services#批量重命名) |
| 同步媒体服务器 | 接入 Emby、Jellyfin、Plex、飞牛影视、极影视等来源 | [媒体服务器连接](/docs/media/connections/media-servers) |
| 在线媒体 | 配置站点，浏览、搜索并按线路播放 | [在线媒体](/docs/media/online-media) |
| 下载中心 | 把首页、媒体库和在线库的下载任务集中到一处，查看进度、重试或清理 | [下载中心](/docs/media/downloads) |
| JS 脚本源 | 按源安装站点脚本，用 GitHub Pages 制作和分享个人源 | [JS 脚本源：安装、制作与分享](/docs/media/online/js-script-sources) |
| 在线栏目 | 把在线库的站点分类固定到首页，实时浏览 | [首页栏目与布局](/docs/media/home/layout#在线栏目) |
| 首页管理 | 扫描、刮削并建立海报墙和动态栏目 | [首页管理](/docs/media/home-management) |
| 媒体目录同步 | 本地剧集目录增删文件后，预览并重建剧集卡片 | [媒体目录同步](/docs/media/home/directory-sync) |
| 媒体详情 | 管理 TMDB 匹配、季集、片源、收藏和内容结构，也可进入作品观看历史 | [媒体详情](/docs/media/home/media-detail) |
| 播放历史与统计 | 查看单次播放、作品历程、统计排行，以及月度和年度片单 | [历史记录](/docs/media/history)、[作品观看详情](/docs/media/history/work-details)、[播放统计](/docs/media/history/playback-statistics)、[观看回顾](/docs/media/history/viewing-recap) |
| 收藏与继续观看 | 收藏喜欢的内容，并从上次进度继续播放 | [收藏、观看状态与继续观看](/docs/media/home/favorites-and-history) |
| 观看进度同步 | 同步媒体服务器、Bangumi 与 Trakt 的观看状态 | [同步功能](/docs/sync/) |
| 历史同步 | 按作品或单集推送、拉取观看记录，也可从备份恢复本地历史 | [历史同步](/docs/sync/history-sync) |
| 局域网历史同步 | 同一局域网内的多台电脑用同一个密钥合并观看记录 | [历史同步](/docs/sync/history-sync#device-sync) |

| 首页功能 | 能做什么 | 从哪里开始 |
| --- | --- | --- |
| 智能播放引擎 | 选择播放内核、硬件解码并处理兼容问题 | [播放内核、解码与硬件加速](/docs/player/engine-and-decoder) |
| 快速启动与续播 | 临时打开媒体并从上次进度继续 | [打开媒体](/docs/getting-started/open-media)、[继续观看](/docs/media/home/favorites-and-history#继续观看) |
| 画面预设与滤镜 | 使用 Anime4K、补帧、内置色彩滤镜和播放美颜 | [画质与滤镜](/docs/player/video-quality) |
| RTX 视频增强 | 用 NVIDIA 驱动做 RTX 视频超分和 RTX 视频 HDR | [画质与滤镜](/docs/player/video-quality#rtx-video-enhancement) |
| 音频控制中心 | 切换音轨、调整同步、均衡器与语音增强 | [音频与均衡器](/docs/player/audio) |
| 多字幕系统 | 加载多字幕、翻译、动画并调整样式 | [字幕](/docs/player/subtitles)、[字幕设置](/docs/settings/subtitles) |
| 书签与笔记系统 | 记录章节时间点，并通过内容结构找回片段 | [播放列表与内容模块](/docs/player/content-modules) |
| 音乐 MV | 在动画 MV 和字幕 MV 两种播放界面之间切换 | [音乐播放器](/docs/player/music) |
| 媒体徽章 | 按分辨率、HDR 和音频信息展示技术规格，首次使用自动获取内置徽标库 | [媒体徽章](/docs/player/media-badges) |
| 精彩片段 | 把当前集值得回看的片段剪成 GIF，点击直接起播 | [精彩片段](/docs/media/home/highlights) |
| 播放失败重试 | 网络中断自动重试，失败后可以手动重播 | [播放失败排查](/docs/troubleshooting/playback#播放中断后的自动重试) |
