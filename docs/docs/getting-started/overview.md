# 先别急着配置一大堆东西

zPlayer 可以只是一个“点开就播”的播放器，也可以把电脑硬盘、NAS 和媒体服务器整理成一套每天都会回来的片库。

第一次使用时，最重要的不是把所有选项都看一遍，而是先判断：你现在是想播放一个文件，还是准备长期管理一整套媒体。

## 它适合谁

如果你属于下面任意一种情况，zPlayer 都能从你现有的媒体开始用：

- 视频放在电脑本地硬盘、移动硬盘或 NAS 上，希望按文件夹浏览。
- 已经部署了 Emby、Jellyfin、Plex 等媒体服务器，希望在 Windows 上统一播放。
- 电影和电视剧越来越多，想要海报、分类、搜索、继续观看和收藏。
- 不想部署媒体服务器，只想让本地文件经过刮削后变成一个好用的首页。
- 平时也会从在线媒体入口搜索和播放内容。

你不需要为了使用 zPlayer 重新整理现有环境：常见的 Emby、Jellyfin、Plex，以及 SMB、WebDAV 等文件服务，都从“连接管理”开始配置。

## 先选一条最适合你的路线

| 你现在想做什么 | 从哪里开始 | 接下来阅读 |
| --- | --- | --- |
| 临时播放一个本地视频 | 点击左上角“打开 → 文件”；设置默认应用后也可在资源管理器中双击 | [打开文件、链接与种子](/docs/getting-started/open-media) |
| 长期浏览电脑或 NAS 里的文件 | 进入“媒体库”，点击“连接管理”，添加视频所在的位置 | [文件服务](/docs/media/file-services) |
| 连接 Emby、Jellyfin、Plex 等服务器 | 在“连接管理”中添加媒体服务器 | [文件服务](/docs/media/file-services) · [内购解锁](/docs/getting-started/unlock) |
| 把电影和电视剧整理成海报墙 | 先添加文件位置，再进入“首页”进行扫描和刮削 | [首页管理](/docs/media/home-management) |
| 直接搜索在线内容 | 进入“在线库” | [在线媒体](/docs/media/online-media) |

::: tip 只有一个视频要看？
不用为了播放一个文件先建立完整媒体库。使用左上角的“打开 → 文件”通常是最快的路径；若希望以后直接双击，请先在 Windows 11“设置 → 应用 → 默认应用”中把对应扩展名交给 zPlayer。
:::

::: tip 会反复看同一个目录？
还是建议把视频所在的位置加入“连接管理”。这样以后从“媒体库”进入即可，不用每次重新找文件；等片库稳定后，再决定是否切换到支持刮削的“首页”。
:::

## 三个入口，分别解决什么问题

### 文件服务：先找到文件

文件服务关注的是“媒体在哪里”。它可以把本地目录、NAS、网络文件服务和已经部署好的媒体服务器接进来，然后按照来源或目录结构浏览。

这条路线不要求你一开始就把所有内容整理成海报墙，尤其适合刚装好软件、想先确认连接和播放是否正常的时候。

### 首页管理：再把片库整理好

首页管理关注的是“这些文件是什么”。扫描和刮削后，zPlayer 可以为电影、电视剧等内容整理标题、海报、简介、分类、收藏和继续观看。

如果你本地已经积累了不少电影和电视剧，建议把首页设为启动页。它不要求你另外部署媒体服务器，直接使用本地目录或 NAS 中的文件也可以开始整理。

### 在线媒体：直接搜索内容

在线媒体适合不想先整理本地片库、希望直接搜索站点内容的场景。不同在线来源的配置方式会有差异，文档会按来源类型说明通用思路，不要求你先记住每个站点的填写细节。

## 你只需要先记住这三个词

- **来源**：媒体从哪里来，例如本地目录、NAS、Emby 或在线站点。
- **媒体**：你看到的电影、电视剧、音乐或其他内容。
- **片源**：同一部媒体实际播放时使用的某个文件、线路或版本。

文档会把“怎么连接”“怎么整理”和“怎么播放”分开说明。具体选项请查[设置参考](/docs/settings/)，实际使用流程优先看[媒体库](/docs/media/)、[播放器](/docs/player/)和[同步](/docs/sync/)。
