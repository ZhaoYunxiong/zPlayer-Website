# 第一次打开，先走一条最短路径

全新安装第一次启动 zPlayer 时，会先进入“媒体库”。这是一个比较通用的起点：你可以先像打开文件夹一样浏览媒体，也可以从这里把本地目录、NAS 或媒体服务器加进来。

不要一上来就把所有设置和所有来源都填满。先让一条播放路径跑通，之后再慢慢把片库整理成你喜欢的样子。

## 只想马上播放一个本地视频

这是最快的方式：

1. 在 Windows 资源管理器中双击视频文件；或者
2. 点击 zPlayer 左上角的“打开”，选择“文件”；
3. 视频进入播放器后，确认画面、声音和字幕都正常。

这种打开方式适合临时播放、测试一个文件，或者你还没决定要怎样整理片库的时候。它不需要你先配置刮削，也不需要先部署媒体服务器。

## 想长期浏览本地文件或 NAS

如果这些视频以后还会反复观看，建议在第一次播放后把位置加进媒体库：

1. 回到“媒体库”页面。
2. 点击页面上方的“连接管理”。
3. 添加视频所在的位置，例如本地文件夹或 NAS 上的共享目录。
4. 保存后回到媒体库，刷新并展开目录，先确认文件能够正常列出。

这里添加的是视频所在的位置，不是每次播放时单独挑一个文件。这样更适合管理一整个目录，也方便以后继续观看和查找。

详细的连接类型和填写方式见[文件服务](/docs/media/file-services)。

## 已经有 Emby、Jellyfin 或 Plex

如果你已经在家里或局域网里部署了媒体服务器，同样从“连接管理”开始。选择对应的媒体服务器类型，填入服务器地址和账户信息后，再回到媒体库确认内容是否出现。

媒体服务器连接功能属于内购解锁范围，购买前可以先看[内购解锁](/docs/getting-started/unlock)。

## 本地片库很多，建议把首页设为启动页

如果本地已经有不少电影和电视剧，单纯按文件夹浏览很快会变得不够方便。这时可以这样做：

1. 先按上面的方式添加本地目录或 NAS 位置。
2. 进入“首页”，让 zPlayer 扫描并刮削媒体信息。
3. 确认海报、标题和剧集匹配基本正常。
4. 在首页的“更多”菜单中选择“设置为启动页”。

以后启动软件就会直接进入首页，打开软件时看到的是继续观看、最近更新和分类内容，而不是一层层寻找文件夹。也可以从“设置 → 模块 → 启动默认页面”修改启动页。

::: tip 这不需要另外部署媒体服务器
首页管理可以直接使用本地目录或 NAS 中的媒体文件。媒体服务器适合已经在使用 Emby、Jellyfin、Plex 等服务的用户；如果你只是想整理本地片库，先添加文件位置就够了。
:::

## 第一次成功，应该看到什么

- 在“媒体库”里能找到刚添加的目录或媒体服务器。
- 点击一个文件或媒体后能进入播放器。
- 如果使用首页管理，扫描后能看到媒体卡片、标题或海报。
- 播放一段时间后，返回首页能看到“继续观看”记录。

如果只是临时播放，到这里就可以开始看了；如果要继续整理片库，再阅读[首页管理](/docs/media/home-management)。
