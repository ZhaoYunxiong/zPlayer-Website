# 从 Microsoft Store 安装

zPlayer 面向 Windows。最省心的方式是从 Microsoft Store 安装：安装、更新和购买授权都在同一个渠道里完成。

<a class="VPButton brand" href="https://apps.microsoft.com/detail/9n2p3rq5vxxj?hl=zh-CN&gl=CN">打开 Microsoft Store 安装 zPlayer</a>

## 安装步骤

1. 打开上面的 Microsoft Store 页面，也可以在商店里搜索 **zPlayer**。
2. 点击“获取”或“安装”，等待 Windows 完成安装。
3. 从开始菜单启动 zPlayer。
4. 第一次打开时，先看[首次启动](/docs/getting-started/first-launch)，按自己的使用场景选择入口。
5. 如果需要连接 Emby、Jellyfin、Plex 等媒体服务器，再查看[内购解锁](/docs/getting-started/unlock)。

::: tip 为什么推荐商店版？
商店版是 zPlayer 的官方安装入口。更新软件或恢复购买授权时，Microsoft Store 和购买时使用的 Microsoft 账户可以直接对应起来。
:::

## 更新软件

打开 Microsoft Store，进入 zPlayer 页面即可确认版本和更新状态。更新前不需要移动媒体文件。

如果更新后发现菜单或功能位置变化，回到对应的使用文档即可。

## 安装遇到问题

如果商店页面无法打开、下载停滞或安装失败，可以先确认 Windows 的 Microsoft Store 本身能够正常安装其他应用，再重新打开 zPlayer 商店页。

不要从不明镜像下载所谓“免安装版”或修改版。仍然无法安装时，请前往[获取帮助](/support)反馈 Windows 版本、商店提示和 zPlayer 版本信息。
