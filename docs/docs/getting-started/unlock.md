# 内购解锁：给需要连接媒体服务器的用户

如果你只是想播放本地视频，可以先按[首次启动](/docs/getting-started/first-launch)里的本地播放路线使用；如果你想把 Emby、Jellyfin、Plex 等媒体服务器接入 zPlayer，再考虑购买内购项目。

## 价格和解锁内容

- **价格：88 元人民币**
- **方式：一次性买断，不是订阅**
- **解锁内容：媒体服务器连接功能**
- **授权关系：与购买时使用的 Microsoft 账户永久绑定**

媒体服务器连接会涉及不同服务版本、网络环境、权限和媒体数据差异，因此作为单独的内购功能提供，以便持续维护兼容性。

::: info 这笔购买适合谁？
已经在使用 Emby、Jellyfin、Plex 等媒体服务器，或者明确需要把媒体服务器接进 zPlayer 的用户，更适合购买。只播放本地文件时，可以先不把购买当作第一次使用的前置步骤。
:::

## 在哪里购买

1. 确认已从[Microsoft Store](https://apps.microsoft.com/detail/9n2p3rq5vxxj?hl=zh-CN&gl=CN)安装 zPlayer。
2. 打开 zPlayer，进入“设置 → 账户”。
3. 在账户页面找到“立即解锁”，按提示打开 Microsoft Store 完成购买。
4. 购买完成后回到 zPlayer；如果授权状态没有马上刷新，可以关闭并重新打开软件。

购买和授权都由 Microsoft Store 处理。请确认商店当前登录的 Microsoft 账户，就是你希望永久绑定授权的账户。

## 买过之后仍然显示未解锁

先不要重复购买，按下面顺序检查：

1. Microsoft Store 当前账户是否和购买账户一致。
2. Microsoft Store 的订单记录中是否已经显示购买成功。
3. zPlayer 是否已经重新启动。
4. 当前网络、系统时间和 Microsoft Store 是否工作正常。

仍然无法解锁时，请准备购买结果或订单信息，并通过[获取帮助](/support)联系开发者。反馈时不要公开完整订单号、账号、支付截图中的隐私信息或访问令牌。

## 购买失败怎么办

如果 Microsoft Store 购买失败，可以通过开发者邮箱或微信群联系开发者，说明遇到的提示和当前 Microsoft 账户状态。确认情况后，也可以使用红包支付，由开发者提供 Microsoft Store 兑换码完成兑换。

兑换码方案请先和开发者确认，不要把红包发给未经确认的个人账号。公开联系方式会统一放在[获取帮助](/support)页面。
