# 打开文件、链接与种子

左上角“打开”适合临时播放，不要求先建立媒体库。点击“打开”后可以选择文件、文件夹、流媒体、磁力链接、种子文件或网页。

## 文件与文件夹

- **文件**：可以一次选择一个或多个媒体文件；选择多个时会按队列播放。
- **文件夹**：读取该目录中的可播放媒体，并从第一项开始播放。
- **拖放**：也可以把媒体文件或文件夹拖到 zPlayer 主窗口。

如果提示“未找到可播放的媒体”，先到“设置 → 文件夹 → 文件格式”确认扩展名是否已被识别。临时打开不会自动把目录加入连接管理。

## 用 Windows 11 管理双击打开方式

全新安装后，资源管理器中的媒体文件不一定已经关联到 zPlayer。需要双击打开时：

1. 按 `Win + I` 打开 Windows“设置”。
2. 进入“应用 → 默认应用”。
3. 搜索并打开 **zPlayer**。
4. 选择要交给 zPlayer 的扩展名，然后确认应用。

以后要更换播放器，也在这个页面修改。Windows 的默认应用与 zPlayer 内部“文件格式”列表是两件事：前者决定双击交给谁，后者决定媒体库识别什么。

## 流媒体 {#open-stream}

选择“打开 → 流媒体”，输入完整媒体地址，例如 HTTP/HTTPS 的视频或 M3U8 地址。此入口立即尝试播放，不会保存到“流媒体”模块；想保留常用链接，见[流媒体链接](/docs/tools/streaming)。

地址能在浏览器中打开，不代表一定是播放器可读取的媒体流。遇到失败时，确认链接尚未过期、没有缺少请求头或登录态，并尝试同一来源的其他清晰度。

## 磁力链接与种子文件

- **磁力链接**：粘贴以 `magnet:?xt=urn:btih:` 开头的完整链接。
- **种子文件**：选择本机 `.torrent` 文件。

zPlayer 会先解析元数据，再列出其中可播放的媒体。解析和播放速度取决于网络、资源可用性与对方连接情况。请只处理自己有权访问和使用的内容。

## 网页 {#extract-from-web}

“网页”入口仅在 Windows 上提供。输入网页地址后，zPlayer 会尝试从页面请求中识别 M3U8、MP4、FLV 等媒体链接。页面采用加密媒体扩展、登录验证、一次性令牌或特殊脚本时，可能无法识别。

网页入口用于提取当前页面中可直接访问的媒体流，不等于通用网页下载器。没有找到媒体时，可以改用站点自身提供的播放或下载方式。
