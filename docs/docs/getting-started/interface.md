# 认识界面，不用一次学完

zPlayer 的入口看起来不少，但可以先把它们理解成三件事：找到媒体、整理媒体、播放媒体。

左侧是主导航；内容页顶部通常会放当前页面最常用的操作，例如“连接管理”“刷新”“栏目”“切换”“收藏”和“更多”。窗口较窄时，部分按钮会以图标或菜单形式呈现，仍然位于对应页面的操作区。

## 左侧主导航怎么用

| 入口 | 适合什么时候打开 |
| --- | --- |
| **打开** | 临时打开文件、文件夹、网络流、磁力链接、种子或网页等内容。 |
| **媒体库** | 按目录或来源浏览本地文件、NAS 和媒体服务器，是第一次启动后的默认入口。 |
| **首页** | 查看刮削后的海报墙、最近更新、继续观看、推荐、收藏和片单。 |
| **在线库** | 进入在线媒体来源，搜索内容并选择线路或片源。 |
| **流媒体** | 查看和使用已经配置的流媒体入口。 |
| **播放列表** | 集中管理已经加入播放列表的内容。 |
| **历史记录** | 找回最近播放过的内容。 |
| **工具箱** | 使用 zPlayer 提供的辅助工具。 |
| **设置** | 调整账户、首页、主题、文件夹、播放、字幕、在线服务等选项。 |
| **关于 / 评分** | 查看软件信息，或为 zPlayer 提供反馈。 |

## 两个最常用的按钮

### “打开”：临时播放

“打开”适合“我现在就想看这个文件”。它不会要求你先建立完整的媒体库，尤其适合测试一个下载文件、播放移动硬盘里的单个视频，或打开一个网络流。

### “连接管理”：长期使用

“连接管理”会出现在“媒体库”页面，也会出现在“首页”的操作区域。它适合添加本地目录、NAS、网络文件服务和媒体服务器。

可以这样记：

- 打开一个文件：用“打开”。
- 以后要反复访问一个位置：用“连接管理”。
- 想让这些文件变成海报墙：连接完成后进入“首页”进行扫描和刮削。

## 首页和媒体库的区别

“媒体库”更像一扇文件柜的门：先让你确认来源和目录结构，内容在哪里一目了然。

“首页”更像整理好的客厅：它把媒体按照电影、电视剧、分类、最近更新和继续观看组织起来。两者使用的是同一批媒体来源，但浏览思路不同；你可以先从媒体库确认连接，再把首页设为日常启动页。

## 遇到选项时去哪里找

不需要为了记住每个设置而来回翻文档：

- 想完成一件事：优先看[媒体库](/docs/media/)、[播放器](/docs/player/)或[同步](/docs/sync/)中的操作流程。
- 想确认某个开关在哪里：查[设置参考](/docs/settings/)。
- 想知道某个来源如何添加：先看[文件服务](/docs/media/file-services)或[在线媒体](/docs/media/online-media)。

先把“打开”“连接管理”“首页”这三个入口用熟，其他菜单可以在真正需要时再展开。
