# 同步：让“看到哪儿”跟着你

zPlayer 里的“同步”不是一个总开关，而是几件用途不同的事情：播放器把进度告诉媒体服务器、把观看记录同步到 Bangumi 或 Trakt，以及在媒体库模式下把服务器的历史和收藏带回首页。

先把它们分清楚，后面遇到“为什么服务器有记录、首页却没有”或“为什么 Bangumi 没有更新”时，就不会把几个问题混在一起排查。

## 你想同步的是什么？

| 你想同步的内容 | 对应功能 | 什么时候发生 |
| --- | --- | --- |
| 当前播放到几分几秒 | 媒体服务器播放进度 | 播放、暂停、停止或切换片源时自动上报；Emby 播放中还会定期上报 |
| 一集或一部电影是否看过 | Bangumi / Trakt | 播放记录保存后，已开启并登录的服务会在后台尝试推送；也可以手动双向同步 |
| 服务器里的观看历史和收藏 | 媒体服务器媒体库模式 | 首页刷新媒体库模式来源时，尝试合并到 zPlayer 的本地记录和首页 |
| zPlayer 自己的本地观看记录 | 本地历史 | 播放过程中由 zPlayer 保存，不需要联网或登录任何账户 |

## 先记住三个区别

### 播放进度，不等于“已观看”

“播放进度”是 `00:37:12` 这种精确位置，主要用于下次继续播放；“已观看”是看过或没看过的状态。媒体服务器通常可以同时记录这两类信息，而 Bangumi 和 Trakt 主要同步观看记录与已看状态，并不是把播放器的每一秒位置同步过去。

### 外部账号同步，不等于媒体服务器同步

Bangumi、Trakt 需要在“设置 → 首页 → 历史记录”里登录授权。Emby、Jellyfin、Plex、飞牛影视等媒体服务器则是在[文件服务](/docs/media/file-services)中添加来源后，播放对应来源的媒体时自动上报，不需要再找一个“同步按钮”。

### 同步的前提是“认成同一部作品”

标题、年份、季数、集数和 TMDB 匹配不正确时，软件可能找不到远端对应的媒体。同步失败时先修正媒体信息，再反复点击同步，通常更有效。

## 第一次配置，建议这样试跑

不要一上来就把全部来源、两个外部服务和双向同步一起打开。先用一部你确定匹配正确的电视剧或电影做测试：

1. 先添加来源，确认媒体能正常打开，并播放一小段后停止，检查 zPlayer 本地确实留下了播放记录。
2. 如果使用媒体服务器，确认连接所用的账户有读取和更新播放状态的权限。
3. 如果使用 Bangumi 或 Trakt，先只开启一个服务，点击“登录验证”完成浏览器授权。
4. 根据目的只打开一个方向：想把本地记录传出去就先开“推送”，想把远端已看记录带回来就先开“拉取”。
5. 点击“立即同步”，再分别检查本地媒体和外部服务中的结果。
6. 确认结果符合预期后，再决定是否开启另一个方向或另一个服务。

::: warning 双向同步不是智能冲突合并
“拉取”和“推送”是明确的同步方向，不是一个会自动判断哪边更新、再替你合并的冲突解决器。两边记录差异较大时，建议先关闭其中一个方向，确认你想保留哪一边的结果后再同步。
:::

## 从哪里开始设置？

- 想同步到追番或观影账户：看[Bangumi 与 Trakt](/docs/sync/bangumi-and-trakt)。
- 想让 Emby、Jellyfin、Plex 或其他媒体服务器收到播放进度：看[媒体服务器播放进度同步](/docs/sync/media-server)。
- 已经配置过，但结果不对：看[同步异常排查](/docs/sync/troubleshooting)。

同步是可选能力。只在本地电脑上播放视频时，不登录外部账号也不影响正常播放；先把媒体来源和刮削匹配做好，再配置同步，体验会稳定很多。
