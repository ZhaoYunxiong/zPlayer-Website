# 媒体处理工具箱：下载、剪辑、转码与轨道处理

左侧“工具箱”把常见的媒体处理任务集中在一个页面。选择工具、填写参数后，任务会进入任务列表；你可以在列表中查看进度或取消仍在运行的任务。

## 工具可以做什么

| 类别 | 包含的工具 |
| --- | --- |
| 网络与下载 | 网页媒体提取、HTTP 下载、M3U8 下载、M3U8 合并、STRM 文件生成 |
| 视频处理 | 视频剪辑、视频转 GIF、批量合并、转码、封装转换、GIF 转视频、缩略图生成 |
| 音频处理 | 音轨提取、替换、移除，以及音频封面替换 |
| 字幕处理 | 字幕轨道提取、字幕嵌入、Whisper 音视频翻译 |
| 高级处理 | 直接执行 FFmpeg 命令 |

不同版本或运行环境显示的工具可能略有区别；以当前“工具箱”中的实际列表为准。

## 通用使用流程

1. 打开“工具箱”，选择最接近目标的工具。
2. 填写带“必填”提示的输入、输出及格式参数。
3. 确认输出文件不要覆盖唯一的原始文件。
4. 提交后打开任务列表，等待任务完成。
5. 用播放器检查输出文件的画面、声音、字幕和时长，再决定是否删除原文件。

参数不完整时，zPlayer 会要求补充后再运行。任务加入列表只代表已经开始处理，不代表输出一定成功；大文件、复杂滤镜和语音识别都可能需要较长时间。

## 该选哪个工具

- 只想截取一段：用“视频剪辑”。
- 编码不兼容、需要改变分辨率或编码器：用“视频转码”。
- 只改变 MP4、MKV 等容器，不想重新压制画面：先试“视频封装转换”。
- 多段视频需要顺序拼接：用“批量合并”，输入文件的编码和参数越一致越稳定。
- 只要视频中的声音或字幕：用对应的音轨、字幕提取工具。
- M3U8 是网络播放列表：下载分片用“M3U8 下载”，已有分片需要整合时用“M3U8 合并”。
- 没有字幕并希望离线生成或翻译：用 Whisper 工具；边播放边识别则看[Whisper AI 字幕](/docs/player/whisper)。

## FFmpeg 与输出安全

桌面版的多种处理工具依赖 FFmpeg。找不到 FFmpeg、输入格式不受支持、输出目录不可写，都会让任务失败。直接使用“FFmpeg 命令”前，应先在副本上验证参数。

::: warning 先保留原文件
剪辑、转码、替换轨道和嵌入字幕都可能生成与预期不同的结果。重要媒体先输出到新文件，验收完成前不要覆盖或删除原件。
:::
