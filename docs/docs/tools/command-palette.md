# 命令面板：把常用操作直接搜出来

zPlayer 的功能不少，设置、工具箱、播放控制分散在不同页面。命令面板把这些入口收在一起：按快捷键打开搜索框，输入几个字，找到想做的事，回车执行。用熟以后，可以少翻很多层菜单。

## 怎么打开

- 在主界面按 `Ctrl+P`。当前页面支持内容搜索时，搜索框会同时给出内容和命令；当前页面不支持搜索时，会直接进入命令模式。
- 按 `Ctrl+Shift+P` 直接进入命令模式。你已经知道要执行哪个操作、不想先看内容搜索结果时，用这个更快。
- 播放器里也能按 `Ctrl+P` 打开命令面板，暂停、切集、打开设置之类的操作不用先退出播放界面。
- 设置中心里不要用这个快捷键。设置页有自己的搜索框，直接在里面搜设置项更顺手。
- 也可以在顶部搜索框里直接输入 `>` 开头的内容进入命令模式。中文输入法下打出的全角 `＞` 和 `》` 同样有效，把鼠标停在输入框上会看到这条提示。

## 里面有什么

命令面板会收录软件内置的导航、设置页和设置项、工具箱工具、播放控制、收藏入口，以及 AI 对话和在线库相关操作。每条命令旁边会标出它是跳转、弹窗还是直接执行，避免按下去才发现不是自己想要的东西。

打开时如果没有输入内容，会先显示“常用命令”。用得多的命令会排在前面，最近用过的也会更靠前。搜索时可以输入功能名称，也可以输入设置项说明里的关键词；比如想改硬件解码，可以直接搜“硬解”或“GPU”。

执行后的结果分几种：

- 导航命令会打开对应页面。
- 设置命令会进入设置中心，定位到对应子页或设置项，并短暂高亮。
- 工具箱命令会直接弹出工具参数窗口，不用先打开工具箱再找工具。
- 播放器命令会在当前播放窗口里执行，比如播放、暂停、切集、打开字幕或弹幕面板。

## 搜索技巧

先输入你记得住的词，不必完整。功能名、页面名、设置说明里的词都可以试。搜不到时，换一个更短的关键词，或者直接到设置页的搜索框里找。

命令面板只负责找到入口，不会替你满足前置条件。比如 AI 生成站点仍然要先配置支持工具调用的模型，在线站点仍然要先添加并启用，工具箱也仍然需要填对输入和输出路径。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 按 `Ctrl+P` 没有反应 | 当前在设置中心，或窗口没有获得焦点 | 点一下主窗口再按；设置中心改用页面内的搜索框 |
| 只看到内容结果，没有命令 | 当前页面支持内容搜索 | 按 `Ctrl+Shift+P` 直接进入命令模式 |
| 输入 `>` 没有进入命令模式 | 用了别的相似符号，或符号不在开头 | 用 `>`、`＞` 或 `》` 开头，符号要放在最前面 |
| 搜不到某个设置 | 关键词和设置说明不一致 | 换更短的词，或到设置页搜索 |
| 命令执行后没有变化 | 当前页面或播放状态不满足条件 | 看命令旁边的状态；播放命令需要先打开媒体 |

命令面板适合记不住菜单位置的时候用。常用操作用熟以后，还是可以直接点按钮或按快捷键，不必每次都打开它。
