# 媒体属性与 Markdown 导出

媒体属性用于回答“这个文件到底是什么规格”，Markdown 导出则把媒体资料和解析结果保存成便于阅读、归档或继续编辑的文本文件。

## 查看媒体属性

媒体详情会显示当前所选片源的媒体属性；播放时也可以点击播放器中的媒体信息区域打开属性面板。这里可以查看容器、时长、文件大小，以及视频、音频、字幕等轨道信息，特别适合排查：

- 文件后缀相同但某一个无法播放；
- 实际分辨率、帧率、编码或 HDR 类型与文件名不一致；
- 多音轨或多字幕文件选错轨道；
- 远程文件显示的大小、更新时间或播放状态不符合预期。

媒体属性来自当前文件和解析结果。远程来源无法读取完整文件时，某些字段可能为空；这不一定代表媒体损坏。

## 导出 Markdown

1. 打开媒体详情，先选中要查看的季、集或实际片源。
2. 在媒体操作中选择“导出 Markdown”。
3. 选择一个可写的位置并保存 `.md` 文件。
4. 用任意文本编辑器或 Markdown 阅读器打开结果。

导出内容适合做媒体档案、影片笔记或问题排查附件。它不会复制原视频，也不会把 Markdown 自动加入首页片单。

## 分享前先检查

导出的内容可能含有本地路径、远程地址、文件名、媒体标题和技术参数。准备上传 GitHub 或发给他人前，先用文本编辑器搜索并移除：

- Windows 用户名和私人目录；
- NAS、WebDAV 或媒体服务器地址；
- 不希望公开的片名、文件名和来源名称；
- 任何账号、令牌或密钥。

如果是为了反馈播放问题，通常同时提供[日志导出](/docs/troubleshooting/logs-and-feedback)和一份脱敏后的媒体属性，就足够判断格式、解码与来源问题。
