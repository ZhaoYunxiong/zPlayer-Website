# 储物箱与加密播放

储物箱用于把媒体复制到 zPlayer 管理的空间中。保存后的文件使用无语义的标识名称，Windows 资源管理器里不能再通过原文件名辨认内容，双击时也不会按常规视频文件直接打开；zPlayer 保留对应关系，并在应用内解密播放。

这项功能的主要目标，是降低共用电脑时从文件名、后缀和双击操作中直接暴露媒体内容的概率。

## 放入文件或文件夹

1. 打开“媒体库或首页 → 连接管理 → 添加”，选择“储物箱”。
2. 选择一个专门保存储物箱数据的本机路径，填写别名并保存连接。
3. 打开刚创建的储物箱来源，选择“上传文件”或“上传文件夹”。
4. 选中要复制的媒体，等待处理完成。
5. 回到储物箱列表，确认项目能显示并播放；确认无误前，先保留原文件作为备份。

上传文件夹时会保留 zPlayer 内部需要的目录对应关系；磁盘上的储物箱文件名则不再直接展示原始名称。移动、改名或手工删除这些文件，可能让 zPlayer 找不到对应内容。

## 它能防住什么

- 他人在资源管理器里浏览目录时，难以从文件名和扩展名直接判断内容。
- 文件没有普通媒体类型和关联程序，双击不会像常规视频那样直接播放。
- 配合 zPlayer 本机账户和解锁 PIN，可减少共用电脑时的误看和误操作。

## 它不替代什么

储物箱不是 Windows 账户隔离、文件权限或整盘加密的替代品。能够登录同一 Windows 账户、访问应用数据、复制磁盘文件或分析程序行为的人，仍可能进一步处理这些数据。

如果你的目标是防止电脑丢失、磁盘被拆走或其他管理员账户读取，请同时使用 Windows 登录密码、合适的文件权限，以及 BitLocker 或设备加密等系统级能力。

::: warning 先考虑恢复路径
不要把储物箱当成唯一备份。应用配置损坏、磁盘故障、手工移动文件或忘记登录信息，都可能影响读取。重要内容至少在另一个受保护的位置保留一份副本。
:::

## 和两种备份文件的区别

- 储物箱：保存实际媒体的受管理副本，用于在 zPlayer 内浏览和播放。
- `.zplinks`：密码保护的连接配置交换文件，用于迁移媒体来源；见[连接备份与迁移](/docs/media/connections/backup-and-health)。
- `.zpb`：软件配置和数据备份，不包含原始媒体；见[软件数据备份与恢复](/docs/settings/account-and-network#软件数据备份与恢复)。
