# 工具与扩展：播放之外还能做什么

这里收录不属于媒体库整理或播放器控制、但经常和媒体使用连在一起的能力。它们各自独立，不需要为了使用其中一个而配置全部功能。

| 你想做什么 | 使用入口 | 对应文档 |
| --- | --- | --- |
| 保存并反复播放网络直播、广播或直链 | 左侧“流媒体” | [流媒体链接](/docs/tools/streaming) |
| 下载、转码、剪辑或处理音轨、字幕 | 左侧“工具箱” | [媒体处理工具箱](/docs/tools/media-toolbox) |
| 查看完整媒体参数或导出 Markdown | 媒体详情或播放器的媒体操作 | [媒体属性与 Markdown 导出](/docs/tools/media-properties-and-export) |
| 把媒体投到电视，或让其他设备访问本机文件 | 投屏入口或“设置 → 媒体服务” | [投屏与局域网共享](/docs/tools/casting-and-sharing) |
| 把私密媒体放进不易被文件名和双击直接识别的空间 | “连接管理 → 添加 → 储物箱” | [储物箱与加密播放](/docs/tools/storage-box) |

## 先分清几个容易混淆的入口

- “打开 → 流媒体”适合临时播放一个 URL；左侧“流媒体”适合保存以后还会使用的 URL。
- “投屏”是 zPlayer 主动把当前媒体发送到电视等接收设备；“DLNA 服务”是让 zPlayer 所在电脑作为接收端出现。
- “局域网共享”让其他设备读取本机内容；它不会把媒体上传到云端。
- “工具箱”会生成或修改媒体文件，开始任务前应单独选择输出位置，并保留原文件。

::: tip 第一次使用建议
先拿一个可随时重新获取的小文件或测试链接走完整流程。确认输出、播放和网络访问都符合预期后，再处理重要媒体。
:::
