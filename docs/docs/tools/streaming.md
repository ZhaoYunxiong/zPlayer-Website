# 流媒体链接：保存直播、广播和网络直链

“流媒体”页面适合保存会反复使用的网络媒体地址，例如直播流、网络广播、单个视频直链或 M3U 播放列表。只播放一次的地址，可以直接使用[“打开 → 流媒体”](/docs/getting-started/open-media#open-stream)。

## 添加一个地址

1. 打开左侧“流媒体”。如果导航里没有该入口，到“设置 → 模块”开启它。
2. 点击“添加”，填写便于识别的标题和完整 URL。
3. 确认后，在列表中选择刚添加的项目播放。

普通 HTTP 或 HTTPS 媒体地址会作为一个项目保存。相同标题和地址的项目不会重复加入。

## 导入 M3U 或 M3U8

- URL 以 `.m3u` 结尾时，zPlayer 会读取其中的项目并逐条加入列表。
- URL 以 `.m3u8` 结尾时，zPlayer 会先判断它是包含多个频道的播放列表，还是单个 HLS 媒体流；前者会展开导入，后者作为一个项目保存。
- 播放列表中的名称来自 `#EXTINF`；没有名称时，会尽量使用 URL 最后一段作为标题。

导入只保存地址，不会把媒体文件自动下载到本地。需要下载或合并 M3U8 时，请使用[媒体处理工具箱](/docs/tools/media-toolbox)。

## 管理列表

列表中的项目可以直接播放或单独删除。“清空”会移除当前保存的全部流媒体项目，但不会删除服务器上的内容。

## 地址无法播放时

按下面的顺序检查：

1. 把同一地址放到浏览器或其他播放器中测试，确认链接仍然有效。
2. 检查 URL 是否需要登录、Cookie、请求头或短期令牌。普通直链输入框不会替你完成网页账号登录。
3. 确认地址没有过期，且网络代理不会阻断目标站点。
4. 如果地址其实是网页而不是媒体流，改用[“打开 → 网页”](/docs/getting-started/open-media#extract-from-web)尝试提取。
5. 视频有声音但画面异常时，继续查看[播放内核、解码与硬件加速](/docs/player/engine-and-decoder)。

请只使用你有权访问和播放的地址。直播源的可用性、清晰度和内容由来源服务决定。
