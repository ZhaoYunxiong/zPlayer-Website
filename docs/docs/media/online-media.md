# 在线媒体：不用先整理文件，也能直接找片播放

如果说[文件服务](/docs/media/file-services)是“把自己的文件接进 zPlayer”，在线媒体就是“直接浏览外部站点提供的内容”。它不要求你先下载电影、整理目录或搭建媒体服务器，打开站点后就可以浏览分类、搜索作品、选择线路并播放。

软件界面里有些地方仍然会显示“在线库”，它与文档中的“在线媒体”指的是同一项功能。

::: warning 在线媒体不是 zPlayer 自己提供的片库
zPlayer 只负责读取你配置的站点信息、展示搜索结果和调用返回的播放地址，不托管这些站点的内容。请只添加你有权访问、来源可靠且符合当地法律和站点规则的来源。
:::

## 先记住一条主线

在线媒体的各种站点类型，底层格式虽然不同，但对用户来说做的事情基本一样：

```text
普通浏览站点 / 搜索
        ↓
在线媒体尝试匹配 TMDB
        ↓
匹配成功：进入统一媒体详情
匹配失败：显示简易线路与集数弹窗
        ↓
在详情或弹窗中选择线路和剧集
        ↓
进入播放器播放
```

你不需要先弄懂 Maccms、TVBox、Miru 或 Kazumi 的技术差异。它们只是 zPlayer 读取站点数据的不同方式，真正使用时都围绕“找内容”和“选播放源”。

## 推荐先从 Maccms 开始

如果你第一次使用在线媒体，建议优先配置 **Maccms 站点**。这类接口在互联网上相对容易找到，站点数量也比较多，通常能够提供分类、搜索、详情、线路和剧集信息，比较适合熟悉 zPlayer 的完整流程。

文档不提供默认站点地址。你可以从自己信任的来源获取 Maccms 配置，再添加到软件中；站点是否稳定、内容是否完整，最终取决于站点本身。

## 第一次使用

### 1. 先配置一个站点

进入 **设置 → 在线媒体（软件中可能显示“在线库”）→ 站点配置**，在对应的站点类型中添加或导入配置。

以 Maccms 为例，完成后可以：

- 开启或停用某个站点；
- 检测站点是否可用；
- 为站点设置分组，方便在在线媒体页面切换；
- 在站点列表中查看状态。

不需要为每个站点单独学习一套播放操作。站点能正常检测到分类或内容，就可以进入下一步。

### 2. 进入在线媒体页面

从主导航进入“在线媒体”。如果侧栏没有显示，可以在设置的模块选项中打开在线媒体模块。

页面底部或筛选区域可以切换：

- 站点分组；
- 当前站点；
- 站点提供的内容分类；
- 上一页、下一页和指定页码。

首次进入时，软件会加载默认站点；默认站点可以在站点配置中设置。站点信息也可以按设置在启动后自动更新。

### 3. 浏览、搜索和播放

先按分类浏览，或者使用软件顶部的搜索入口搜索片名。找到卡片后，点击它进入统一的媒体详情流程。完整的 TMDB 匹配、线路选择和兜底弹窗流程，见[搜索、线路与播放](/docs/media/online/source-selection)。

## 点击在线媒体后，默认会怎么处理

在线媒体已经统一采用媒体详情体验，不需要用户额外选择“详情模式”或“直接线路模式”。点击作品后，zPlayer 会先从 TMDB 查找元数据：

- **匹配成功**：进入统一媒体详情页，在详情中查看资料、选择季集、切换线路和播放；
- **无法匹配**：不阻止播放，改为显示简易的线路与集数选择弹窗，确认后直接进入播放器。

这样既能让大多数作品使用完整的媒体详情，也能保证站点标题特殊、TMDB 没有对应条目时仍然可以播放。

无论哪种模式，点击结果都不会自动把它加入本地文件服务，也不会把外部内容下载到你的媒体库。在线媒体和首页管理是两条独立入口。

## 在线媒体和首页管理的区别

| 功能 | 在线媒体 | 首页管理 |
| --- | --- | --- |
| 内容从哪里来 | 外部站点实时返回 | 本地、NAS、媒体服务器等已连接来源 |
| 是否需要整理文件 | 不需要 | 长期使用时建议整理目录和命名 |
| 主要操作 | 浏览、搜索、选线路、播放 | 扫描、刮削、收藏、栏目和片源管理 |
| 作品资料 | 由站点返回，或尝试匹配 TMDB | 由来源扫描和刮削建立 |
| 内容是否自动出现在首页 | 不会自动加入 | 来源保存后首页会自动刷新和刮削 |

首页的联网推荐点击后，也可能使用已配置的在线媒体来源寻找播放片源；这和直接进入在线媒体页面浏览，是同一批在线来源的两种入口。推荐行为详见[搜索、分类与推荐](/docs/media/home/search-and-recommendation#联网推荐先弄清推荐从哪里来点进去会发生什么)。
