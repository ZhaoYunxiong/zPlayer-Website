# 搜索、分类与推荐

首页适合“逛”，搜索和分类适合“我现在就想找某一部”。当媒体越来越多时，掌握这几个入口，比把所有内容都塞进一个大栏目更省心。

## 搜索本地和已连接的媒体

在首页或媒体库中搜索标题、原名等关键词，可以快速定位已经扫描到的电影、电视剧和其他媒体。打开结果后，进入媒体详情查看季集、版本和片源。

搜索不到时，按这个顺序排查：

1. 来源是否已经在[连接管理](/docs/media/file-services)中保存成功。
2. 回到首页后是否仍在自动刷新或刮削。
3. 文件是否放在所添加的目录下面，而且当前账号有访问权限。
4. 是否把电影目录误选成电视剧，或反过来。
5. 如果首页有卡片但关键词搜不到，检查标题是否被刮削成了另一种译名。

## 联网搜索和聚合搜索

首页设置中有“联网搜索”和“聚合搜索”选项：

- **联网搜索**：允许搜索尚未加入本地首页的在线媒体或在线媒体库内容。适合偶尔找一部还没加入来源的片子。
- **聚合搜索**：把多个已连接来源的结果合并展示，适合同时使用本地目录、NAS 和媒体服务器的人。

如果你只想搜索已经整理好的本地库，可以关闭联网搜索；如果来源较多，希望一次看到各处结果，可以打开聚合搜索。远程来源多时，聚合搜索的等待时间也可能更长。

## 按分类浏览

分类适合先缩小范围，再慢慢挑选：电影、电视剧、动漫、音乐，或者按来源、媒体库查看。分类不是重新刮削，它只是使用已有的媒体类型和元数据进行浏览。

如果一个目录的媒体类型本身就混乱，分类页面出现“电影里有电视剧”通常不是分类按钮的问题，而是来源添加时内容分类不准确，或媒体服务器返回的媒体库划分不符合预期。

## 联网推荐：先弄清“推荐从哪里来，点进去会发生什么” {#online-recommendation}

首页里有两个容易混淆的入口：

| 入口 | 内容来源 | 适合做什么 |
| --- | --- | --- |
| 首页的“媒体推荐”栏目 | 从你已经接入的媒体中挑选内容 | 在自己的片库里找一部还没看、或想随机看的作品 |
| 首页右上角“更多” → “联网推荐”，或“媒体推荐”栏目里的更多按钮 | 从互联网推荐服务获取作品信息 | 发现还没有加入自己媒体库的新电影、新剧和动漫 |

简单说，首页的“媒体推荐”是在**你的媒体里挑片**；“联网推荐”是在**互联网内容里找片**。联网推荐展示的是作品信息，并不等于 zPlayer 已经拥有这部作品的播放文件。

### 联网推荐有哪些来源

当前联网推荐按来源和用途分成几组：

| 推荐分组 | 推荐来源 | 里面会看到什么 |
| --- | --- | --- |
| 动漫推荐 | 弹弹 Play 提供的 Bangumi 每日更新数据 | 按星期一至星期日查看正在更新或近期播出的动漫 |
| 趋势推荐 | TMDB | 今日趋势和本周趋势中的电影、电视剧 |
| 热门推荐 | TMDB | 当前热门电影、热门电视剧 |
| 高分推荐 | TMDB | 高评分电影、高评分电视剧 |

这些推荐不是根据 zPlayer 用户的私人观看记录计算的，也不是从你的 NAS 或媒体服务器里刮出来的。它们来自对应的在线推荐服务，因此会受到网络、服务接口、区域、语言和当天数据的影响；同一个入口在不同时间看到的内容也可能不同。

进入完整的“联网推荐”页面后，每一组会以独立栏目展示。某些分组右上角还有切换按钮，例如在动漫推荐中切换星期，在趋势推荐中切换“今日”和“本周”。横向卡片可以翻页浏览，首页只展示较短的一部分，完整页面适合慢慢挑选。

### 点击推荐卡片后会发生什么

点击卡片的结果取决于这部作品是否已经在你的媒体库中：

1. **已经在本地、NAS 或媒体服务器中存在**：zPlayer 会优先找到对应的本地媒体，直接打开它的媒体详情。你看到的是自己已有的文件、剧集和片源。
2. **媒体库中没有，但已配置在线媒体来源**：zPlayer 会先读取 TMDB 的完整资料，再尝试在已配置的在线库中搜索对应的视频或剧集，最后打开媒体详情。详情页里如果找到了在线片源，就可以选择集数和来源播放。
3. **媒体库中没有，也没有匹配到在线片源**：仍可能打开作品详情，查看标题、海报、年份和简介，但详情页不一定有可播放的片源。这时它只是一个推荐结果，不会自动把文件下载到本地，也不会自动添加成你的文件服务来源。

电视剧会进一步按季集尝试匹配在线内容；不同在线库的命名、集数和更新速度不一样，所以推荐卡片能打开不代表每一季、每一集都一定有播放源。

::: tip 推荐来源和播放来源是两件事
TMDB 或 Bangumi 告诉你“这部作品值得看、它叫什么”；已配置的在线媒体来源或你自己的文件服务，才决定“有没有可以播放的内容”。如果想让联网推荐尽量能够直接播放，需要先在[在线媒体](/docs/media/online-media)中配置可用来源。
:::

### 什么时候用联网推荐，什么时候用搜索

- 想随便发现新内容：打开联网推荐，先看趋势、热门、高分或本周动漫。
- 已经知道作品名称：使用搜索；如果本地搜不到，可以根据设置允许联网搜索 TMDB 结果。
- 找到推荐作品后想播放：点击卡片进入媒体详情，再看是否有本地、服务器或在线片源。
- 想让一组条件长期固定在首页：使用[动态栏目](/docs/media/home/layout#dynamic-columns)，不要每次重复翻推荐页。

联网推荐需要网络和对应服务支持。它适合“找下一部”，不能替代本地来源的连接、文件访问和刮削管理。

## 动态栏目比反复搜索更适合长期使用

如果你每次都搜索“高分、未观看、4K”的内容，可以把这组条件保存成首页动态栏目。动态栏目会随着新增媒体、观看状态和元数据变化自动更新，详细设置见[首页栏目与布局](/docs/media/home/layout#dynamic-columns)。

几个实用的组合：

| 想做的事 | 推荐条件 |
| --- | --- |
| 找还没看完的高分片 | 评分 + 观看状态 |
| 找最近补进来的内容 | 最近更新天数 + 最近添加排序 |
| 找家庭影院版本 | 分辨率 + 动态范围 + 音频格式 |
| 处理刮削问题 | 识别状态或元数据完整性 |
| 追正在更新的剧 | 剧集状态 + 最近更新天数 |

## 搜索、推荐和片单怎么分工

- **搜索**：你已经知道要找什么。
- **分类**：你想从某一类媒体里浏览。
- **推荐**：你想看看系统或联网内容提供了什么选择。
- **动态栏目**：你有稳定的筛选习惯，希望它一直固定在首页。
- **片单**：你想保存一份固定的观看清单。

把它们分开使用，首页会更像一个按你习惯工作的媒体工作台，而不是不断重复筛选的搜索页。
