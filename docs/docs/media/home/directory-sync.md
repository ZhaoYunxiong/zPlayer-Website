# 媒体目录同步：文件增删后，把剧集卡片补齐

你在资源管理器里给一部剧加了新集，或者删掉了几集，zPlayer 的剧集卡片不一定马上跟着变。媒体目录同步就是处理这种情况的：它扫描这部剧所在的目录，和当前的剧集卡片对比，先给你看会发生什么，确认后再重建。

## 从哪里进入

在媒体库或首页找到一部本地剧集，右键打开菜单，进入“内容管理 → 媒体目录同步”。

这个功能只对本地剧集开放。电影、普通视频、媒体服务器来源不会显示这个入口；媒体服务器的内容以服务器返回的信息为准，应该回到服务器侧处理。

## 它会做什么

1. 读取这部剧当前的剧集卡片。
2. 扫描同一部剧的目录，找出新增和删除的文件。
3. 在预览窗口里按季度折叠展示“将添加”和“将移除”的剧集。
4. 你确认后，软件重新刮削并替换这张剧集卡片。

预览顶部会显示同步前后的季数、集数摘要。新增的剧集可以调整季号和集号，适合文件名里季集信息不清楚、或者你刚补了一集特别篇的情况。准备移除的条目只用来核对，不会在预览里修改。

## 什么时候用

- 从别的设备拷进来几集新剧，首页还没有显示。
- 删除了几集文件，卡片里还留着旧条目。
- 文件名或季集编号有变化，自动刷新没有认出来。
- 你想在执行前先确认到底会加哪些、删哪些，不想直接全库重刮。

日常只是新增一个来源或少量文件时，首页的自动刷新通常就够了。媒体目录同步更适合“这部剧的目录变了，但卡片没跟上”的情况。

## 注意什么

同步会重建这部剧的剧集卡片，文件本身不会被删除。开始前最好确认目录结构没有混进其他剧，不要把包含很多部剧的公共根目录当成一部剧来同步。

如果扫描后提示“已是最新”，说明目录和卡片没有差异，不需要再执行。重建过程中顶部会显示进度条，剧集多或网络目录慢时需要等一会儿。

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 入口不显示 | 当前不是本地剧集，或是媒体服务器来源 | 换到本地剧集卡片，或到服务器侧整理 |
| 提示目录范围过大 | 选中的是包含多部剧的父目录 | 先整理成一部剧一个目录，再同步 |
| 提示剧集无法匹配 | 文件名和目录信息不足 | 先修正文件名或季集编号，再重试 |
| 同步后仍有缺集 | 文件不在这个剧的目录里，或命名无法识别 | 检查目录和文件名，必要时手动添加内容 |

媒体目录同步解决的是文件增删和季集对应，不负责修正 TMDB 匹配错误。整部剧认错作品时，仍然要在媒体详情里重新刮削。
