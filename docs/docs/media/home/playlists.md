# 片单：把想看的内容整理成一份清单

片单适合做有明确主题、希望自己掌控内容的集合，例如“周末电影”“给家人看的动画”“待测试的 4K 片源”。它和收藏、动态栏目都不一样。

## 片单、收藏和动态栏目有什么区别

| 功能 | 内容怎么进入 | 内容会不会自动变化 | 适合的场景 |
| --- | --- | --- | --- |
| 收藏 | 你在媒体详情中主动收藏 | 通常不会因为评分或来源变化自动筛选 | 长期喜欢、想保留的作品 |
| 普通片单 | 你主动把媒体加入清单 | 不会自动加入新媒体 | 一次性的观看计划、主题整理 |
| 动态栏目 | 由规则筛选来源 | 会随媒体、元数据和观看状态变化 | 高分未看、4K HDR、最近更新 |

如果你希望名单“永远就是这几部”，用普通片单；如果你希望新内容符合条件后自动出现，用动态栏目。

## 从哪里把媒体加入片单

打开电影或电视剧的[媒体详情](/docs/media/home/media-detail)，在操作菜单中选择加入片单或相关的片单操作，再选择已有片单或创建新的整理方式。电视剧可以根据需要把系列或具体内容加入清单，添加后回到首页的片单栏目查看。

创建片单时，名称最好体现用途：

- `2026 春季待看`
- `投影仪测试片`
- `周末和孩子看`

这样比“片单 1”更容易长期维护。

## 用动态栏目生成片单

对于“最近 30 天更新且未看完”“评分 8 分以上”“收藏且未看完”这类条件，普通片单需要你不断手动补充，动态栏目更合适。它会一直根据规则从来源中计算结果。

如果某次筛选结果已经确定，不想以后再变化，可以在动态栏目编辑页打开**静态片单**：保存时会查询当前规则的完整结果，并把它固定为普通片单，之后来源新增媒体或观看状态变化不会自动改动这份名单。

可以这样理解：

```text
动态栏目：规则仍在运行 → 结果会变化 → 适合长期入口
静态片单：保存当前结果 → 名单被冻结 → 适合一次性清单
```

## 维护片单的小建议

- 一份片单尽量只表达一个主题，后续更容易清理。
- 需要自动更新的名单不要手动复制成普通片单，避免两个列表逐渐不一致。
- 片单中的媒体无法打开时，先从详情页确认来源是否仍然在线，或媒体是否正在重新刮削。
- 如果只是想标记“喜欢”，用收藏更轻量，不必专门创建片单。

片单是整理结果，来源和元数据才是内容基础。来源增删改后首页会自动刷新；若片单中的某些媒体变成不可用，先检查[文件服务](/docs/media/file-services)和[扫描与刮削](/docs/media/home/scraping)。
