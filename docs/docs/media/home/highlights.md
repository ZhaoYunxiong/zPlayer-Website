# 媒体详情里的“精彩”：把高能片段挑出来

“精彩”是媒体详情页里的一个内容栏目。它会从当前集里挑出几段比较精彩、值得回看的位置，剪成 GIF 片段放在详情页里。浏览一部剧时，不用先播放整集，也能快速看看这一集有哪些值得跳过去看的片段。

## 它跟着当前剧集走

打开一部电视剧或动漫，选中某一集后，“精彩”栏目会按这一集生成内容。换一集，栏目也会跟着换，不会把其他集的片段混进来。

软件会从当前集里挑出比较精彩、值得回看的位置，再截取附近的画面做成 GIF。片段生成后会缓存在本地，下次打开同一集通常不用重新等。

## 怎么用

把鼠标移到片段卡片上，可以看到浮动预览，里面通常有 GIF、片段标题、开始时间和一句简介。点击卡片会从这段片段的开始时间起播，不用自己拖进度条。

如果某一段生成失败，卡片上会提供单独重试的入口。其他已经生成好的片段不受影响，不需要把整集重新生成一遍。

## 设置在哪里

入口是“设置 → 首页 → 剧集详情”：

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| 精彩栏目 | 是否在媒体详情页显示“精彩”栏目 | 开启 |
| 精彩片段数量 | 单集最多生成多少个片段，范围 1～20 | 6 |

这个功能需要联网处理当前集，生成时也会占用一些 CPU 和磁盘空间。片段会缓存在本地，缓存被清理或换设备后需要重新生成。

## 没有片段怎么办

| 现象 | 先检查什么 | 处理 |
| --- | --- | --- |
| 栏目整个不显示 | 精彩栏目开关是否关闭 | 到“设置 → 首页 → 剧集详情”打开 |
| 有栏目但没有卡片 | 当前集能不能正常生成片段 | 先正常播放这一集，再回到详情页重试 |
| 只有一两段 | 当前集可用的精彩片段本来就少 | 属于正常结果；可以换一集试试 |
| 片段画面不对 | 当前集数和片段信息是否对应 | 重新选中这一集，必要时重新生成 |
| 生成一直失败 | 网络、磁盘空间或片段生成服务异常 | 单独重试；仍然失败时查看播放诊断和日志 |

“精彩”只是自动挑出的辅助片段，不能替代完整观看。当前集没有足够的可用片段时，这里会少一些或者没有内容。
