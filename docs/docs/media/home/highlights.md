# 媒体详情里的“精彩”：把高能片段挑出来

“精彩”是媒体详情页里的一个内容栏目。它会根据当前剧集的弹幕高能波峰，自动挑出几段热闹、密集或者情绪明显的位置，剪成 GIF 片段放在详情页里。浏览一部剧时，不用先播放整集，也能快速看看这一集有哪些值得跳过去看的片段。

## 它跟着当前剧集走

打开一部电视剧或动漫，选中某一集后，“精彩”栏目会按这一集生成内容。换一集，栏目也会跟着换，不会把其他集的片段混进来。

生成需要先拿到这一集的弹幕。软件会分析弹幕出现得密集、情绪起伏明显的时间段，再截取附近的画面做成 GIF。片段生成后会缓存在本地，下次打开同一集通常不用重新等。

## 怎么用

把鼠标移到片段卡片上，可以看到浮动预览，里面通常有 GIF、片段标题、开始时间和一句简介。点击卡片会从这段片段的开始时间起播，不用自己拖进度条。

如果某一段生成失败，卡片上会提供单独重试的入口。其他已经生成好的片段不受影响，不需要把整集重新生成一遍。

## 设置在哪里

入口是“设置 → 首页 → 剧集详情”：

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| 精彩栏目 | 是否在媒体详情页显示“精彩”栏目 | 开启 |
| 精彩片段数量 | 单集最多生成多少个片段，范围 1～20 | 6 |

这个功能需要联网获取弹幕，生成时也会占用一些 CPU 和磁盘空间。片段会缓存在本地，缓存被清理或换设备后需要重新生成。

## 没有片段怎么办

| 现象 | 先检查什么 | 处理 |
| --- | --- | --- |
| 栏目整个不显示 | 精彩栏目开关是否关闭 | 到“设置 → 首页 → 剧集详情”打开 |
| 有栏目但没有卡片 | 当前集是否有可用弹幕 | 先在播放器里搜索并加载这一集的弹幕，再回到详情页 |
| 只有一两段 | 弹幕密度低或高能区间少 | 属于正常结果；可以换一集或换一个弹幕来源 |
| 片段画面不对 | 弹幕和当前集数是否匹配 | 检查弹幕匹配结果，必要时重新搜索弹幕 |
| 生成一直失败 | 网络、磁盘空间或弹幕服务异常 | 单独重试；仍然失败时查看播放诊断和日志 |

“精彩”只是根据弹幕做的辅助剪辑，不能替代完整观看。弹幕少、没有弹幕，或者弹幕和画面本身不对应时，生成结果也会受影响。
