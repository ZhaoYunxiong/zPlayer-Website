# 扫描与刮削：让文件变成好用的媒体库

“扫描”解决的是：来源里有哪些文件、文件在哪里、能不能访问。

“刮削”解决的是：这些文件对应哪部电影或电视剧，以及应该显示什么标题、海报、简介、评分和剧集信息。

两件事经常一起发生，但不是一回事。文件能播放，不代表它已经正确出现在首页；首页有海报，也不代表每个片源都一定能正常打开。

## 什么时候会自动处理

来源在[连接管理](/docs/media/file-services)中保存后，回到首页会自动刷新并处理新增、删除或变更的媒体。你不需要为了让新文件出现在首页而手动点击刷新。

这也是推荐使用连接管理的原因：临时打开文件可以很快，但长期管理的目录交给来源后，zPlayer 才能持续发现变化，并把它们纳入首页、搜索、收藏和栏目。

## 自动处理前，先把这三件事做好

### 1. 一个来源尽量只放一种内容

如果一个目录里既有电影又有电视剧，软件很难仅凭路径准确判断内容类型。更稳妥的做法是把它们拆开：

```text
媒体库/
├─ 电影/
│  └─ 流浪地球 2 (2023)/
└─ 电视剧/
   └─ 庆余年 (2019)/
```

在连接管理中，电影目录选择“电影”，电视剧目录选择“电视剧”。不要把包含多种内容的公共根目录直接添加进去，否则 TMDB 匹配和首页分类都可能不准确。

媒体服务器则不同：媒体服务器模式下不需要手动选择电影或电视剧，软件会使用服务器返回的媒体库和内容类型。具体连接方式见[文件服务](/docs/media/file-services)。

### 2. 文件名给出足够的线索

电影名后带年份，电视剧尽量保持剧名、年份和季集目录清晰。例如：

```text
电影/奥本海默 (2023)/Oppenheimer.2023.mkv
电视剧/庆余年 (2019)/Season 01/庆余年.S01E01.mkv
```

不需要为了 zPlayer 把所有文件重命名成固定格式，但同名作品较多时，年份和 `S01E01` 这样的信息会明显提高匹配成功率。

### 3. 确认 TMDB 和网络设置

刮削需要访问元数据服务。若所有新媒体都没有海报，优先检查网络、TMDB 区域和语言设置；若只有某一部作品出错，更可能是匹配问题。

## 需要手动刷新时怎么选

首页顶部的“刷新”菜单有三种操作：

| 操作 | 什么时候用 |
| --- | --- |
| 仅刷新新增或删除的媒体 | 想主动检查某个来源刚加入或移除的文件 |
| 重新刮削刷新全部媒体 | 修改刮削相关设置、需要整体重建元数据，或大量匹配异常 |
| 停止当前刷新 | 当前任务耗时太久，想先停止再检查来源或网络 |

日常新增来源、修改来源连接信息或删除来源，保存后首页会自动处理，不需要把“重新刮削刷新全部媒体”当成日常动作。全库重刮可能耗时较长，媒体很多或服务端带宽有限时尤其明显。

## 某一部作品匹配错了，推荐这样修复

### 先从 TMDB 重新选择正确作品

1. 在首页找到错误的电影或电视剧，打开[媒体详情](/docs/media/home/media-detail)。
2. 在该媒体的操作菜单中选择“重新刮削”。
3. 输入更完整的名称，必要时带上年份，再点击搜索。
4. 对照海报、年份、类型和简介，从 TMDB 结果中选中正确作品。
5. 回到媒体详情，检查剧集、海报和片源是否已经对应。

同名电影、翻拍作品、特别篇和剧场版最容易匹配错。不要只看标题，年份和海报通常是最有用的判断依据。

### 只改显示资料时编辑元数据

如果作品已经是正确的 TMDB 条目，只是译名、简介、海报、背景图、剧集标题或日期不符合你的习惯，可以使用“编辑元数据”，不必再次搜索整部作品。

编辑范围可以是整个系列、当前季或当前集。需要了解每个字段怎么改，可以看[TMDB 与元数据](/docs/media/home/metadata)。

## 仍然刮削错误，怎样反馈最有用

请不要只发一句“这部剧刮不出来”。从首页右上角的“更多”菜单选择**导出刮削调试信息**，按页面提示选择相关来源并导出文件，然后通过开发者邮箱反馈。

反馈时最好同时写上：

- 哪个来源、哪个目录或哪部作品出现问题；
- 期望匹配的作品名称和年份；
- 是没有结果、匹配错误，还是海报、剧集、片源信息异常；
- 是否已经尝试过“重新刮削”和手动选择 TMDB 条目。

导出的调试信息能让开发者看到刮削过程中的关键上下文，比截图或口头描述更容易定位问题。若购买或解锁本身遇到问题，请看[内购解锁](/docs/getting-started/unlock)。

::: warning 不要把账号密码发进反馈
导出文件前后都请确认内容中没有你不想公开的服务器密码、访问令牌或私有地址。如果不确定，可以先检查文本再发送；反馈时只提供定位问题所需的信息。
:::
