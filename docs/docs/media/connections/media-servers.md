# 连接媒体服务器

Emby、Jellyfin、Plex、飞牛影视、极影视等来源从“连接管理 → 添加 → 媒体服务器”进入。连接这些服务器属于内购解锁范围；DLNA 目录浏览不需要填写媒体服务器账号。

## 地址与登录方式

| 来源 | 服务器地址示例 | 登录方式与说明 |
| --- | --- | --- |
| Emby | `http://192.168.1.11:8096` | 填写服务器中的用户名、密码；不要填写 Web 管理页面后面的具体路由。 |
| Jellyfin | `http://192.168.1.11:8096` | 填写 Jellyfin 用户名、密码；HTTPS 或反向代理用户以实际外部地址为准。 |
| Plex（Beta） | `http://127.0.0.1:32400` 或服务器局域网地址 | 保存时会通过浏览器完成 Plex 验证；返回 zPlayer 后会校验服务器和令牌。 |
| 飞牛影视 | `http://192.168.1.11:8005` | 默认使用影视服务端口 `8005`，填写飞牛影视账号；不是 NAS 管理端口 `5666`。 |
| 极影视（Beta） | `http://192.168.1.11:8021` | 填写极影视服务器地址、用户名和密码，以服务器实际端口为准。 |
| DLNA | 设备描述地址 | 可以先用附近服务扫描自动发现；手动添加时需要设备描述地址和初始对象 ID。 |

地址中必须包含正确的 `http://` 或 `https://`。在浏览器中只能打开登录页，不代表当前账号一定拥有媒体库读取和播放权限。

## 媒体库模式和直连模式

部分媒体服务器会显示“媒体库模式”：

- **开启**：扫描服务器下的全部媒体，与其他来源合并后参与首页管理、搜索和栏目组织。
- **关闭**：按需浏览和播放服务器内容，不主动把整个服务器作为首页媒体库扫描。

自建且由自己管理的服务器，需要统一首页时可以开启；他人共享、公共或不确定限制的服务器优先关闭。媒体库模式会产生更多列表和元数据请求，非自建服务器可能限制账号。

媒体服务器会返回自己的电影、剧集和音乐分类，因此通常不需要再手动指定普通文件连接使用的内容类型。

## Plex 授权没有完成

1. 确认服务器地址能访问 Plex，默认端口通常为 `32400`。
2. 保存连接后，在浏览器中完成账号确认。
3. 保持 zPlayer 打开，等待令牌返回并完成服务器校验。
4. 浏览器确认成功但软件仍失败时，检查代理、回调拦截和 Plex 服务可访问性，再重新添加。

不要手工复制来历不明的 Plex Token。令牌相当于登录凭据，反馈问题时必须遮挡。

## DLNA 目录与投屏不是同一件事 {#dlna}

- 在连接管理添加 **DLNA 来源**：从其他 DLNA 服务器浏览媒体目录。
- 在“设置 → 投屏”启用 **DLNA 投屏**：让其他控制端把媒体发送到 zPlayer，或从 zPlayer 选择渲染设备。
- 在“设置 → 媒体服务器”开启 **DLNA 服务**：把 zPlayer 可访问的内容提供给局域网设备。

三者方向不同。投屏和共享的完整流程见[投屏与局域网共享](/docs/tools/casting-and-sharing)。

## 连接成功后的检查

1. 在连接管理中打开来源，确认媒体库或目录能列出。
2. 打开一部媒体，确认季集、版本和片源与服务器一致。
3. 播放一段时间后停止，再确认进度是否回写服务器。
4. 开启媒体库模式时，等待首次扫描完成后再判断首页是否缺项。

能浏览但不能播放通常是媒体地址、转码权限或服务器返回信息的问题；完全无法登录则先检查地址、账号和网络。进度同步异常见[媒体服务器播放进度同步](/docs/sync/media-server)。
