# 本地与网络文件服务

本页说明如何把本机目录、NAS 和常见网络文件服务接入 zPlayer。统一入口是：

> **媒体库或首页 → 连接管理 → 添加 → 选择来源 → 填写信息 → 确定**

保存前先填写一个容易辨认的别名，并选择与目录相符的内容类型。电影目录选“电影/剧场版”，剧集和动漫目录选“剧集/动漫/电视剧”，音乐目录选“音乐”；只想按目录浏览、不参与首页刮削时选“无”。

## 本地文件夹与储物箱

| 来源 | 必填内容 | 使用建议 |
| --- | --- | --- |
| 文件夹 | 路径 | 每个连接尽量只放一种内容类型，不要直接选择混合了电影、剧集和音乐的公共根目录。 |
| 视频库、音乐库、图片库 | 无额外地址 | 作为对应类型的聚合入口使用，同一种系统库通常只需要添加一次。 |
| 储物箱 | 路径 | 选择用于保存储物箱文件的本机目录；完整操作见[储物箱与加密播放](/docs/tools/storage-box)。 |

本地路径失效时，先在资源管理器中确认磁盘仍在线、盘符没有变化、当前账户有读取权限。

## 先试“扫描附近服务”

连接管理可以发现同一局域网中的部分 SMB、FTP、SFTP、WebDAV、DLNA、Emby 和 Jellyfin 服务。发现结果会预填地址、端口或路径，但不会替你填写账号密码。

扫描不到不代表服务不可用。跨网段、VPN、防火墙或服务端关闭局域网发现时，直接按下面的字段手动添加即可。

## 网络文件服务填写表

| 来源 | 地址与路径 | 账号和端口 | 示例或注意事项 |
| --- | --- | --- | --- |
| FTP | “IP 地址”填主机；“初始路径”填进入后开始浏览的位置 | 用户名、密码；端口填 `0` 时自动选择 | IP 示例 `192.168.1.11`，初始路径示例 `/anime/`。 |
| SFTP | “IP 地址”填 SSH/SFTP 主机；“初始路径”按服务端目录填写 | 用户名、密码；默认端口 `22` | SFTP 与 FTP 不是同一协议，不能只改端口互换。 |
| SMB | “IP 地址”只填 NAS 主机；共享目录放在“初始路径” | 用户名、密码；SMB 版本默认 `2` | 优先使用 SMB 2 或 3；仅在旧设备明确只支持时选择 SMB 1。 |
| WebDAV | “Api”填协议、主机和端口；“Path”填 WebDAV API 路径；“初始路径”填浏览起点 | 按服务配置填写用户名、密码 | zPlayer 自建共享可参考 `http://192.168.1.11:62106` 与 `/dav`。 |
| AList | “Api”填 AList 服务地址；“Path”通常为 `/dav` | WebDAV 用户名和密码 | 地址示例 `http://192.168.1.11:5244`，不要把管理后台的具体文件页面 URL 填进 Api。 |
| OpenList | 与 AList 相同，填写服务地址、WebDAV 路径和初始路径 | WebDAV 用户名和密码 | 先在浏览器或其他 WebDAV 客户端确认账号可访问目标目录。 |

::: tip 地址和路径不要混在一起
“Api”或“IP 地址”用于找到服务器，“Path”表示服务入口，“初始路径”表示登录后从哪个媒体目录开始。连接失败时，先用根路径 `/` 测试，再逐步缩小到具体目录。
:::

## 保存后如何验收

1. 回到“连接管理”，确认连接没有立即显示错误状态。
2. 点击该来源，确认能列出预期目录。
3. 打开一个小文件测试播放。
4. 回到首页，确认来源栏目自动刷新。
5. 如果能浏览但海报或剧集匹配错误，检查内容类型和目录结构，不要先改网络参数。

只有部分目录看不到时，通常是服务端权限或初始路径问题；整个来源都打不开时，再检查地址、端口、协议、账号和防火墙。
