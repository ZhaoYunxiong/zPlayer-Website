# 连接检查、备份与迁移

“连接管理”右上角提供“检查全部”“导出”和“导入”。来源较多、准备换电脑或重装系统时，先在这里把连接单独备份。

## 检查全部连接

点击“检查全部”后，zPlayer 会逐项检查支持健康检查的来源，并在连接卡片上显示当前结果。检查失败不一定表示配置已经损坏，也可能是服务器暂时离线、外网超时或授权刚好过期。

建议先只编辑失败的来源，测试能否浏览和播放，再决定是否删除。删除连接可能使依赖该来源的历史记录无法继续播放。

## 导出 `.zplinks`

1. 打开“媒体库或首页 → 连接管理”。
2. 点击右上角“导出”。
3. 选择 `.zplinks` 文件保存位置。
4. 设置至少 8 位的备份密码并再次确认。
5. 等待“连接配置导出成功”提示。

`.zplinks` 会保存当前连接配置，包括来源地址以及连接需要的账号、密码、令牌或登录会话。文件使用密码加密，但备份密码无法找回；应把文件和密码分开保存。

## 导入：覆盖还是融合

1. 点击“导入”，选择 `.zplinks` 文件。
2. 输入导出时设置的密码。
3. 当前已有连接时，选择导入方式。

| 方式 | 结果 | 适合场景 |
| --- | --- | --- |
| 覆盖 | 用备份中的连接替换当前连接 | 新电脑完整迁移，或确定当前配置不再需要 |
| 融合 | 保留当前连接，并按连接标识添加或更新备份内容 | 两台设备的来源需要合并 |

覆盖会要求再次确认。执行前先把当前连接再导出一份，以便选择错误时恢复。导入结束后，运行一次“检查全部”，再分别验证需要浏览器授权或扫码登录的云盘、音乐和 Plex 来源。

## `.zplinks` 与 `.zpb` 的区别

- `.zplinks`：只迁移连接管理中的来源，适合在不同设备间搬运服务器、网盘和目录配置。
- `.zpb`：从“设置 → 其它 → 软件数据备份与恢复”生成，范围更大，可能包含设置、记录及其他应用数据。

两类备份都可能包含隐私信息。不要上传到公开网盘链接、反馈附件或聊天群；需要提交问题时，只提供脱敏后的错误信息和日志。
