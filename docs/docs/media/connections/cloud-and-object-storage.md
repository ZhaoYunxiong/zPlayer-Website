# 云盘与对象存储

云盘和对象存储同样从“连接管理 → 添加 → 云盘与对象存储”进入。它们依赖外部服务、授权状态和网络，建议先用一个小目录验证浏览与播放，再交给首页扫描。

## S3 对象存储

添加“对象存储”时需要：

| 字段 | 填写内容 |
| --- | --- |
| AccessKey | 对象存储服务生成的访问密钥 ID |
| SecretKey | 与 AccessKey 配对的秘密密钥 |
| Endpoint | 服务商提供的 S3 兼容端点 |
| 桶名称 | 保存媒体的 Bucket 名称 |
| 初始路径 | 桶内开始浏览的位置，例如 `anime/`；根目录可用 `/` |

Endpoint 不是控制台首页，也不是某个对象的临时下载链接。不同服务商的虚拟主机、区域和 HTTPS 证书规则不同，应以服务商给出的 S3 兼容端点为准。

建议给 zPlayer 单独创建只读或最小权限密钥，不要直接使用拥有删除桶、修改策略等管理权限的主账号密钥。

## Google Drive、OneDrive 与 Dropbox

这些来源使用浏览器授权：

1. 选择对应云盘并设置内容类型。
2. 点击确定后，在系统浏览器中完成服务商登录和授权。
3. 返回 zPlayer，等待授权结果写入连接。
4. 打开来源，确认目录可列出并测试播放。

授权令牌由 zPlayer 保存在本机连接配置中。浏览器没有打开、回到软件后一直没有结果，或提示客户端配置不可用时，说明当前版本没有完成授权回调或服务端应用配置；反复填写网盘密码不会解决这一问题。

要缩小浏览范围，可以把“初始路径”设为媒体目录。授权失效后，编辑或重新添加该来源并再次完成浏览器授权。

## 115 网盘

当前 115 网盘连接仍受开发者接入状态限制，扫码入口可能提示暂不可用。它与 Google Drive、OneDrive 或 Dropbox 的授权相互独立，不要为了排查 115 网盘去修改其他来源。

## 云端来源的使用建议

- 先选择一个小目录测试，避免第一次就扫描整个网盘或大桶。
- 外网来源的场景缩略图建议保持关闭，减少流量和详情页等待。
- 临时签名链接可能过期；应保存服务连接，而不是把一次性下载 URL 当作永久来源。
- 连接凭据和令牌会随 `.zplinks` 导出，请像保管密码一样保存备份，见[连接检查、备份与迁移](/docs/media/connections/backup-and-health)。
- 能列出文件但播放失败时，检查服务是否允许读取文件内容、是否存在流量限制，以及返回的媒体地址能否持续访问。
