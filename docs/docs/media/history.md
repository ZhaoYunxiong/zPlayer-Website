# 历史记录：找回真正播放过的内容

“历史记录”是 zPlayer 左侧导航中的独立模块，用来查看真正开始播放过的电影、剧集、音乐和其他媒体。它不是首页中的一个栏目，也不等同于“继续观看”或收藏夹。

## 从哪里进入

在主界面左侧选择“历史记录”。如果没有看到这个入口，前往“设置 → 模块”开启“历史记录”；关闭模块只会隐藏入口，不会删除已有记录，详见[模块与启动页](/docs/settings/modules)。

打开媒体详情页不会自动产生历史记录。通常需要真正开始播放，zPlayer 才会保存这次播放；播放过程中以及暂停、停止、切换片源或关闭播放器时，会尽量更新最后位置。

## 页面上方的操作

| 操作 | 用途 |
| --- | --- |
| 播放统计 | 查看基于本地播放记录生成的统计信息 |
| 分组切换 | 在按日、按月或按年分组之间切换，也可以快速跳到某个时间分组 |
| 列表排序 | 按播放记录时间正序或倒序排列 |
| 清空 | 确认后清除全部本地历史记录 |

分组方式和排序方向会被保存，下次进入历史记录时会继续使用。点击列表中的分组标题，会打开当前分组方式下的时间选择器；选择目标年份、月份或日期后，会跳到包含该分组的页面。

## 记录较多时如何翻页

历史记录每页最多显示 60 项。超过一页后，页面底部会出现分页控件：

- 使用 `<` 和 `>` 查看上一页或下一页；
- 在输入框中填写 `1` 到总页数之间的页码；
- 按 Enter 或点击发送按钮跳转；
- 翻页或跳转后，列表会回到页面顶部。

输入空值、超出范围的页码或当前页时，不会执行跳转。

## 删除记录和清空历史

清空历史只会删除 zPlayer 本地保存的播放记录，不会删除媒体文件，也不会自动清空媒体服务器、Bangumi 或 Trakt 上的记录。

处理单条记录时，请注意确认窗口的文字：部分可删除的本地媒体还会继续询问是否同步删除文件；如果只想移除观看记录，不要确认删除原文件。

来源离线、文件被移动或服务器连接被删除后，旧记录仍可能暂时出现在这里，但重新播放可能失败。确认文件已经不存在时，可以移除对应记录。

## 它与首页、收藏和继续观看有什么区别

| 功能 | 展示范围 | 适合做什么 |
| --- | --- | --- |
| 历史记录 | 真正播放过的内容 | 按时间找回观看足迹、查看统计 |
| 继续观看 | 尚未完成且仍可继续的内容 | 快速回到上次进度 |
| 已观看状态 | 作品或剧集是否看完 | 筛选未观看、观看中和已观看内容 |
| 收藏 | 主动保留的作品 | 长期找回喜欢的内容 |

首页会利用播放记录生成“继续观看”等栏目，但完整的时间列表仍应从本页查看。首页中的收藏、动态栏目和续播方式见[收藏、观看状态与继续观看](/docs/media/home/favorites-and-history)。

## 本地记录与同步记录

本地文件的历史记录只保存在 zPlayer 中；播放 Emby、Jellyfin、Plex、飞牛影视等媒体服务器来源时，zPlayer 还会尝试向服务器上报进度。Bangumi 和 Trakt 主要同步观看记录与已看状态，不会保存精确到每一秒的本地续播位置。

这些同步关系彼此独立：清理本地历史不代表远端记录也会消失。具体区别和设置方式见[同步功能](/docs/sync/)。
