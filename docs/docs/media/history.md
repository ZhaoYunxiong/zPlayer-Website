# 历史记录：按日期找回每次观看

历史记录按“日期 → 作品或文件 → 当天的播放明细”整理观看足迹。你可以展开剧集、找回一次播放、删除某次记录，也可以进入一部作品的完整观看历程。

## 从哪里进入

在主界面左侧选择“历史记录”。如果没有看到入口，前往“设置 → 模块”开启它；关闭模块只会隐藏入口，不会删除已有记录，详见[模块与启动页](/docs/settings/modules)。

打开媒体详情页不会自动产生播放记录。开始播放后，zPlayer 会在播放过程中以及停止、切集、关闭播放器等时机保存观看记录。

| 想查看什么 | 使用哪个入口 |
| --- | --- |
| 某一天看了什么、每次从何时看到何时 | 当前历史记录列表 |
| 一部作品跨日期、跨季的完整观看历程 | 卡片上的“查看全部历史”，进入[作品观看详情](/docs/media/history/work-details) |
| 一段时间看了多久、什么作品看得最多 | 页面上方的[播放统计](/docs/media/history/playback-statistics) |
| 某个月或某一年看过哪些作品、留下哪些观看节点 | 播放统计上方“回顾”，进入[观看回顾](/docs/media/history/viewing-recap) |

## 展开作品和单次播放

电影、普通视频和音乐保留各自的记录。已确认作品身份的电视剧或动漫，会按作品、来源和季度整理成卡片；展开后查看当天播放过的具体剧集。

剧集条目会显示缩略图、季集编号、剧集名、原文件名、观看时长和播放次数。把鼠标移到缩略图上可以使用播放按钮，移到卡片上可以找到“查看全部历史”和删除操作。

有单次明细的条目可以点击“X 次播放”继续展开，即使只播放过一次也可以查看：

| 字段 | 含义 |
| --- | --- |
| 开始播放 | 这次播放开始的日期和时间 |
| 结束播放 | 这次播放结束或最近保存的日期和时间 |
| 观看时长 | 这次播放从开始到结束经过的时间 |
| 结束位置 | 这次播放结束时在视频中的位置；记录中有此信息时显示 |
| 观看进度 | 这次播放结束时保存的进度 |

旧版历史可能只保留累计次数和最后位置，没有逐次时间。此时会保留已有汇总，但无法展开并不存在的单次明细。

## 搜索、筛选和时间分组

使用程序顶部搜索框，可以搜索作品名、剧集名、原文件名或 `S01E02` 这样的季集编号。搜索会覆盖完整历史，再对结果分组和分页。

页面提供时间、来源和媒体类型等筛选；从统计图表进入时，上方还会显示带入的筛选条件。点击条件标签可以逐项移除，扩大查看范围。

“分组切换”可以选择按日、按月或按年整理列表，“列表排序”控制时间正序或倒序。分组方式和排序方向会被保存。点击时间分组标题，可以选择目标年份、月份或日期，跳到对应页面。

按月、按年分组只是改变历史列表的组织方式。需要查看这一期间的片单和观看节点，请使用[观看回顾](/docs/media/history/viewing-recap)。

## 整剧进度与来源归属 {#work-and-source}

历史卡片的整剧进度表示**截至卡片日期已经看完的集数**。后来继续观看或换来源重看，不会把早期日期的进度倒填成今天的进度。同一集重复播放会增加观看时长和次数，但不会重复增加已看集数。

作品归属会结合已有的刮削资料、媒体服务器提供的系列与季集信息，以及能够确认属于同一作品的历史资料。只靠剧名相同或文件名中出现 `S01E01`，不会把普通视频、手机自拍视频识别成电视剧。

### 从资源管理器打开的本地文件

例如，你已经在 zPlayer 中添加并整理了一个名为“动漫”的本地媒体库，再从资源管理器打开其中一集：

- 如果完整文件路径能明确匹配到该媒体库，历史会补齐作品、季集和缩略图，来源显示为“动漫”。
- 来源筛选、播放统计和作品观看详情使用同一个归属，查看媒体详情时也会优先使用对应媒体库。
- 如果文件没有匹配资料，或同一文件同时属于多个已配置的本地媒体库，就保留“本地媒体”，不会随意选择来源。

文件路径相同的本地关联与服务器来源匹配分别处理，不会拿服务器返回的内部编号去认领一个本地文件。来源显示的调整也不会改变历史原本对应的播放文件或删除目标。

### 同一作品来自多个来源

历史列表仍区分来源和季度，便于确认当天播放的是哪个版本。[作品观看详情](/docs/media/history/work-details)和作品排行则可以汇总已确认属于同一作品的不同来源与季度，同时保留每条记录的来源和文件信息。

旧记录补齐资料后，正常浏览、关键词搜索和作品详情会使用一致的作品归属。媒体来源离线时仍可查看已有历史；是否能够重新播放或打开媒体详情，取决于原文件、连接和已保存资料是否可用。

## 记录较多时如何翻页

历史记录每页最多显示 60 张作品或文件卡片。超过一页后，可以使用上一页、下一页，或输入 `1` 到总页数之间的页码，再按 Enter 或点击跳转按钮。翻页后列表会回到顶部。

同一天一部剧展开后的单集和播放明细属于这张卡片，不会因为展开而变成新的分页项。输入空值、超出范围的页码或当前页时，不会执行跳转。

## 删除一次、删除整条与清空 {#deleting-history}

| 操作 | 删除范围 |
| --- | --- |
| 单次播放明细中的删除按钮 | 只删除选中的那一次播放，其余次数保留 |
| 作品或文件卡片上的删除按钮 | 删除该卡片所包含媒体的全部播放历史，可能包含其他日期的记录；确认前请阅读提示 |
| 页面上方“清空” | 删除全部本地历史记录 |

删除最后一次有效播放后，对应历史条目会一并移除。历史、统计、作品观看详情和回顾会随保留下来的记录重新计算。

这些历史删除操作不会删除媒体文件，也不会自动清除媒体服务器、Bangumi 或 Trakt 的远端记录。远端同步关系见[同步功能](/docs/sync/)。

## 与首页、收藏和继续观看的关系

| 功能 | 适合做什么 |
| --- | --- |
| 历史记录 | 按时间查看实际发生过的播放 |
| 作品观看详情 | 围绕一部作品查看累计数据、分季进度和所有记录 |
| 继续观看 | 快速回到尚未看完的内容 |
| 已观看状态 | 区分未观看、观看中和已观看内容 |
| 收藏 | 主动保留以后还想找回的作品 |

首页会利用播放记录生成“继续观看”等栏目。首页的收藏、动态栏目和续播方式见[收藏、观看状态与继续观看](/docs/media/home/favorites-and-history)。
