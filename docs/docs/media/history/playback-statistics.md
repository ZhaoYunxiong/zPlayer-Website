# 播放统计：看懂自己的观看习惯

播放统计把本地观看历史整理成累计时长、播放次数、活跃天数、观看日历、来源与类型分布，以及作品排行。页面上的指标和图表可以继续打开对应记录，方便核对数字来自哪些播放。

本页介绍的是“历史记录”上方的播放统计。播放器菜单“属性 → 播放统计”展示当前播放过程中的实时技术信息，入口和用途不同。

## 进入与筛选

在主界面左侧打开“历史记录”，点击上方“播放统计”。页面上方提供时间、筛选、回顾和返回入口。

| 筛选 | 可选择的范围 |
| --- | --- |
| 时间 | 全部、过去 7 天、30 天、180 天、今年，或自定义起止日期 |
| 来源 | 当前历史中实际出现过的媒体库、本地媒体、媒体服务器、在线库、流媒体或 Strm 等来源 |
| 类型 | 全部、电影、剧集、普通视频、音乐 |
| 状态 | 全部、已看完、未完成 |

这些条件共同决定统计范围。“重置筛选”可恢复全部范围；“无可用统计”表示当前条件下没有可统计的播放记录。

## 统计口径 {#counting-rules}

| 指标 | 如何理解 |
| --- | --- |
| 观看时长 | 有单次明细的播放按开始到结束经过的时间累计，包含期间的暂停和缓冲；视频位置、拖动进度和倍速不直接换算为观看时长 |
| 播放次数 | 统计范围内的播放次数；同一次播放的重复保存不会重复计数 |
| 活跃天数 | 按本地日期去重，只要当天存在播放记录就计入 |
| 媒体数量 | 按电影、具体剧集、普通视频和音乐统计可识别的不同媒体；同一媒体多次播放不重复增加数量 |
| 已看完 | 在所选时间和来源范围内达到“已观看”进度阈值的媒体；阈值沿用首页设置 |
| 未完成 | 当前范围内还没有达到完成条件的媒体 |

跨午夜播放的观看时长会分配到各个自然日。例如从 23:50 看到次日 00:20，前一天记 10 分钟，后一天记 20 分钟；同时查看这两天时，这次播放仍只算一次。点击某天或某个小时查看记录时，列表累计的是落在该范围内的时长，单次详情仍展示完整播放的开始和结束时间。

某个媒体在期间内看完后又从头播放，不会抹掉这个期间的“已看完”状态。历史卡片的整剧进度、单集播放进度和作品排行中的作品数量分别表达不同含义，不能直接互相相加或替代。

旧版历史缺少逐次明细时会沿用已有观看数据；没有保存的开始、结束时间不会被补造成新的播放明细。

## 点击数字查看对应记录

| 点击位置 | 打开的记录范围 |
| --- | --- |
| 观看时长、播放次数、活跃天数、媒体总数 | 当前统计筛选范围内的历史 |
| 电影、剧集、普通视频或音乐数量 | 当前范围内对应媒体类型的历史 |
| 已看完或未完成数量 | 当前范围内对应观看状态的历史 |
| 播放活动图、日历日期、星期或小时分布 | 当前范围内对应时间段的历史 |
| 数据源或类型偏好条目 | 当前范围内对应来源或题材标签的历史 |
| 作品排行中的作品 | 独立的[作品观看详情](/docs/media/history/work-details)，并带入当前条件查看观看记录 |

进入历史列表后，上方会显示带入的筛选条件。可以逐项移除条件，查看更大范围；返回后继续查看原来的统计页。

## 观看日历、来源和类型偏好

“播放活动”“观看日历”“星期分布”和“小时分布”用于查看观看时间的分布。日历单元格可以查看当天时长与播放次数，并直接打开当天记录。

“数据源”按观看时长展示来源及其占比。直接打开的本地文件如果已经明确归属于某个本地媒体库，会计入该媒体库，例如“动漫”，与历史列表的来源名称一致。具体匹配规则见[作品与来源归属](/docs/media/history#work-and-source)。

“类型偏好”展示作品的题材标签，例如剧情、动画或科幻。它与上方“电影／剧集／普通视频／音乐”的媒体类型筛选分别使用：一部作品可能具有多个题材标签，因此不同题材的观看时长可能重叠。

来源或题材较多时，可以点击该栏目的“查看全部”展开完整列表。

## 作品排行

作品排行放在播放统计页面，可以在“按观看时长”“按播放次数”和“按观看天数”之间切换。每部作品显示在当前范围内的观看时长、播放次数、观看天数和进度；列表右上角的“X 部作品”表示这一范围内的作品数量。

已确认属于同一作品的多季、多个来源会汇总到一部作品下。普通视频和音乐仍保留自己的条目，不会只因名称相同而合并。排行中的“一部剧”与上方媒体数量中的“一集”是不同层级。

点击作品进入观看详情，可以查看它的完整历程，并在观看记录区域核对当前排行对应的播放。需要更多结果时，点击“查看更多作品”。

## 待续媒体与观看回顾

“待续媒体”显示已有进度、尚未完成的内容，可以播放或查看对应记录。预览数量会随页面空间调整，“查看全部”打开当前范围内的完整待续记录。

点击页面上方“回顾”，进入独立的[观看回顾](/docs/media/history/viewing-recap)页面，再选择月度或年度。回顾围绕片单、第一次与最后一次观看、重看、看完一季或隔一段时间后续看这些节点展开。

## 数据变化与删除

统计只使用 zPlayer 本地保存的历史。浏览媒体详情不会增加播放次数，远端账户存在记录也不代表本地一定有对应明细。删除一次播放、删除某个媒体的全部历史或清空历史后，统计会按剩余记录重新计算。

需要删除时，先点击指标进入历史列表，核对记录后再执行[删除操作](/docs/media/history#deleting-history)。本地历史删除不会自动清理远端观看记录，详见[同步功能](/docs/sync/)。
