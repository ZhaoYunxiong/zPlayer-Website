# 播放统计：看懂自己的观看习惯

“播放统计”会把 zPlayer 本地保存的历史记录整理成总览、时间分布、进度状态、数据源排行和常看媒体，适合回答“最近看了多久”“通常什么时候看”“主要从哪个来源播放”等问题。

::: tip 两个“播放统计”不是同一个功能
本页介绍的是历史记录中的观看数据统计。播放器菜单“属性 → 播放统计”显示的是当前播放过程中的实时技术信息，两者用途不同。
:::

## 从哪里进入

1. 在主界面左侧打开“历史记录”。
2. 点击页面上方的“播放统计”。
3. 使用左上角返回按钮回到完整历史记录。

如果页面显示“无可用统计”，通常表示当前筛选范围内没有本地播放记录。只是打开媒体详情、但没有真正开始播放的内容，不会形成可统计的观看数据。

## 筛选统计范围

页面上方的筛选会共同作用于整张统计页：

| 筛选 | 可选择的范围 |
| --- | --- |
| 时间 | 全部、今年、过去 1 天、7 天、30 天、180 天或 365 天 |
| 来源 | 本地文件夹、已连接的文件服务或媒体服务器、在线库、流媒体、Strm 媒体等实际出现过的来源 |
| 状态 | 全部、已看完、正在看、未完成或无有效时长 |
| 类型 | 当前时间范围内实际出现过的本地媒体、在线媒体、文件夹等类型 |

筛选项后面的数字表示该范围内的记录数量。想重新查看完整统计时，把时间、来源、状态和类型都切回“全部”。

## 总览指标怎么看

| 指标 | 含义 |
| --- | --- |
| 总观看时长 | 根据当前范围内的本地播放历史估算出的累计时长 |
| 播放次数 | 已记录的播放次数；旧记录缺少次数时会根据已有观看数据估算 |
| 媒体数 | 当前筛选范围内的历史记录数量 |
| 已完成数 | 被识别为已经看完的记录数量 |
| 待续数 | 仍处于观看中、可以继续播放的记录数量 |
| 最常用数据源 | 估算观看时长最高的数据源 |

这些数字来自 zPlayer 的本地历史记录，不是精确计时器。已看完内容、旧版本留下的记录或缺少时长信息的媒体都可能需要估算，因此更适合观察趋势，不适合当作严格的工时统计。

## 播放活动与时间分布

- **播放活动**：按选择的时间跨度自动使用日、周或月汇总，并显示估算观看时长与播放次数。
- **星期分布**：比较一周中不同日期的观看活动。
- **小时分布**：按一天中的整点时段查看观看活动。
- **播放进度**：比较已看完、正在看、未完成和无有效时长的记录数量。

活动、星期和小时分布中的进度条用于比较同一区域内各项的相对高低；准确的估算时长和播放次数以右侧文字为准。

## 数据源排行

数据源排行按估算观看时长排列本地文件夹、文件服务、媒体服务器、在线库或流媒体等来源。每项会显示：

- 估算观看时长、媒体数和播放次数；
- 完成率、待续数量和最近播放时间；
- 相对于其他来源的观看时长比例。

点击右侧箭头，可以进入只显示该来源、并符合当前统计筛选条件的历史记录。

::: warning 删除数据源历史前先确认
排行右侧的删除按钮会在确认后清除该数据源的全部本地历史记录，不只清除当前时间范围内显示的部分。它不会删除媒体文件，也不会自动清除媒体服务器、Bangumi 或 Trakt 中的远端记录。
:::

## Top 媒体与待续媒体

“Top 媒体”会从当前筛选结果中找出最长观看、最多播放、最近观看和待续媒体。某一部内容可能同时符合多个类别；点击条目可以查看它对应的历史记录。

“待续媒体”按最近播放时间列出最多 8 项仍在观看中的内容，并显示来源、播放次数、最近播放时间和当前进度。这里用于分析和回看记录；日常快速续播仍建议使用首页的“继续观看”。

## 统计为什么可能不完整

- 当前时间、来源、状态或类型筛选过窄；
- 媒体只有打开或浏览记录，没有真正开始播放；
- 旧历史记录缺少媒体总时长、观看时长或播放次数；
- 对应历史记录已经被删除，或曾经执行过“清空”；
- 远端服务有观看记录，但 zPlayer 本地没有相应历史。

统计会随着本地历史记录的新增、删除和清空而变化。历史列表的分组、翻页和删除方式见[历史记录概览](/docs/media/history)，远端观看状态的边界见[同步功能](/docs/sync/)。
