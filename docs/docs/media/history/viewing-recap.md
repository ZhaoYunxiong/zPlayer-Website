# 观看回顾：翻看一个月或一年的片单

观看回顾按月份或年份整理观看经历：这一期间从哪部作品开始、最近停在哪一集、重看了什么、看完了哪一季，或者隔了一段时间又接着看了哪部剧。

## 进入与选择时间

从“历史记录 → 播放统计”点击上方的“回顾”，进入独立回顾页面。

1. 在下拉框选择“月度回顾”或“年度回顾”。
2. 使用旁边的日期选取器选择时间：月度选择年和月，年度只选择年份。
3. 查看当前期间的观看节点和片单。正在进行的月份或年份会标明“截至”日期。

初次进入时，月份取统计范围的结束日期；未指定结束日期时使用本月。回顾随后按所选月份或年份读取全部本地历史，统计页中的来源、媒体类型和完成状态筛选不会带入回顾。

## 月度回顾

有记录的月份会展示第一次和最后一次观看。存在符合条件的记录时，还会补充重看或看完一季的节点：

| 节点 | 展示内容 |
| --- | --- |
| 本月第一次观看 | 作品名、具体剧集、观看时间和可用的剧集简介 |
| 本月最后一次观看 | 本月最近开始的一次观看，帮助找回当时看到的内容 |
| 又回到这一集或这部作品 | 本月识别出的重看次数与日期 |
| 这个月看完了一季 | 本月完成的一季及完成日期 |

第一次、最后一次观看卡片右上角的圆形历史按钮，可以查看这次播放的明细；旧记录没有单次明细时，会进入该作品对应日期的观看记录。

重看需要已有记录能够确认“看完后重新回到前段，再次看完”的过程。仅重新打开文件或更换来源，不会直接算作完成了一轮重看。整季完成也需要可靠的总集数，不能把零散缓存当作全集。

## 年度回顾

年度回顾展示这一年的第一次和最后一次观看，以及能够确认的重看节点；还可能展示“隔了一段时间又接着看”的作品。

续看节点要求两次观看相隔至少 30 天，并且回归后已看集数确实增加。卡片会显示前后日期、相隔天数和已看集数的变化，点击后可以查看这段观看历程。

年度页面下方提供“再翻到某个月”，可以直接切换到同一年的月度回顾。当年只列出已经到来的月份。

## 本月片单与年度片单

片单汇总这一期间播放过的作品，右侧“X 部作品”显示完整数量。每部作品会展示相关日期，以及“本期开始观看”“本期继续观看”“本期重看过”等观看节点标签。

预览数量会随页面空间调整；点击“展开完整片单”可以查看全部作品。点击任意作品进入[作品观看详情](/docs/media/history/work-details)，并在观看记录区域保留当前月份或年份的范围。

同一部剧的多集、多季和已确认的不同来源可以汇总为一部作品。整部作品数量与播放次数、单集数量不同，详见[播放统计口径](/docs/media/history/playback-statistics#counting-rules)。

## 为什么有时没有四张卡片

回顾只展示记录能够支持的节点。没有重看或完成一季时，不会为了填满位置增加一张没有依据的卡片；当整个月或整年没有记录时，页面会显示没有可回顾的内容。

删除历史后，回顾会依据剩余记录重新计算。它使用 zPlayer 本地保留的观看历史，远端账户单独存在的记录不一定会出现在这里。记录与同步的关系见[历史记录](/docs/media/history)和[同步功能](/docs/sync/)。
