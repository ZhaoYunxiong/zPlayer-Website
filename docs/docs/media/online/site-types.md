# 站点类型与配置管理

在线库支持 6 种站点类型，是因为外部来源采用了不同的接口、订阅或扩展格式。配置完成后，它们都会回到同一套“选择站点 → 浏览或搜索 → 选择线路与剧集 → 播放”流程。

zPlayer 不内置或托管这些站点的媒体内容。请只导入来源明确、你有权使用且符合所在地法律及站点规则的配置。

## 6 种类型怎样选择

| 类型 | 配置方式 | 适合的内容 |
| --- | --- | --- |
| **Maccms** | 新增单个接口，或更新已有列表 | 提供分类、搜索、详情和线路的影视接口 |
| **JS 爬虫** | 新建或导入脚本，也可从扩展市场安装 | 需要用 JavaScript 适配网页或接口的来源 |
| **TVBox** | 填写 TVBox 订阅地址，一次导入多个站点 | 已经维护好的 TVBox 配置集合 |
| **IPTV** | 从订阅、本地 M3U 文件或仓库导入 | 直播频道和节目流 |
| **Miru** | 导入扩展、从市场安装，支持编辑扩展 | Miru 格式的视频扩展 |
| **Kazumi** | 导入规则或从市场安装 | Kazumi 格式的番剧、影视规则 |

类型不是质量等级，不需要全部配置。先根据手中来源的实际格式选择，导入一个并检测通过后再继续添加。

## Maccms：新增单个接口

进入“设置 → 在线库 → Maccms 站点”：

1. 点击“新增”，填写站点名称、接口地址和分组。
2. 保存后勾选“启用”。
3. 点击该站点操作区的“检测可用性”。
4. 回到在线库，选择刚才的分组和站点验证分类、搜索与线路。

“检测”用于批量检查，“更新”用于刷新站点信息，“清空”会移除当前类型的配置。单个站点失败通常不代表其他站点或播放器故障。

## TVBox：从订阅地址导入

1. 进入“设置 → 在线库 → TVBox 站点”。
2. 点击“导入”，填写完整订阅地址。
3. 导入后只启用需要的站点，点击“检测”查看状态。

一份订阅可能包含大量站点。不要把“导入成功”当成“所有站点可用”，也不建议一次启用全部来源。

## JS 爬虫：新建、导入或从市场安装

JS 爬虫页面提供“新增”“导入”“市场”“更新”“检测”和“清空”：

- 自己维护脚本时使用“新增”进入代码编辑器；
- 已有本地扩展文件时使用“导入”；
- 从扩展市场安装前，先阅读名称、说明、版本和更新时间；
- 安装后先检测，再只启用实际要用的扩展。

JS 扩展可以发起网络请求并解析外部内容。它不是普通的静态书签，只安装你信任来源的代码；扩展异常时先停用或删除，不要向扩展填写 zPlayer、网盘或其他服务的敏感账号。

## Miru 与 Kazumi

两类页面都支持导入、市场安装、更新、检测和清理。Miru 还可以从站点操作区打开扩展代码编辑。

1. 确认拿到的文件或仓库明确标注为 Miru 或 Kazumi 格式。
2. 使用对应页面的“导入”或“市场”，不要跨类型尝试安装。
3. 导入后检查名称、分组、版本和启用状态。
4. 运行检测，只保留能正常返回数据的规则。

扩展更新后突然失效时，先停用并回退到其他来源；不要同时清空所有类型，否则会失去对照项。

## IPTV：订阅、本地文件与仓库

IPTV 页面中的“导入”菜单提供三种入口：

- **从订阅导入**：填写以 HTTP/HTTPS 提供的 M3U 地址，可另填保存名称；
- **从本地导入**：选择本机 M3U 文件；
- **从仓库导入**：选择内置仓库入口，或打开“更多”查看来源。

导入后先检测频道列表，再尝试播放少量频道。节目源失效、地区限制和服务器并发限制都可能造成部分频道不可用。

## 启用、检测、更新和删除

| 操作 | 什么时候用 |
| --- | --- |
| 启用/停用 | 控制站点是否出现在在线库；排错时先停用慢或失效来源。 |
| 检测 | 验证当前配置能否返回基本数据；检测成功仍不保证每条播放线路都有效。 |
| 更新 | 获取来源或扩展的较新配置；更新后应重新检测。 |
| 删除/清空 | 确认不再需要时移除；“清空”通常影响当前整个站点类型。 |

::: warning 导入前先确认来源
订阅、脚本和扩展可能随时变更，也可能访问其作者指定的网络服务。优先使用公开说明清楚、可追溯、仍在维护的来源；不要导入陌生人发送的配置后直接长期启用。
:::
