# 站点类型与配置管理

在线库支持 3 种站点类型，是因为外部来源采用了不同的接口、脚本或订阅格式。配置完成后，它们都会回到同一套“选择站点 → 浏览或搜索 → 选择线路与剧集 → 播放”流程。

zPlayer 不内置或托管这些站点的媒体内容。请只导入来源明确、你有权使用且符合所在地法律及站点规则的配置。

## 3 种类型怎样选择

| 类型 | 配置方式 | 适合的内容 |
| --- | --- | --- |
| **Maccms** | 新增单个接口，或更新已有列表 | 提供分类、搜索、详情和线路的影视接口 |
| **JS 爬虫** | 新建或导入脚本，也可从脚本源安装 | 需要用 JavaScript 适配网页或接口的来源 |
| **IPTV** | 从订阅、本地 M3U 文件或仓库导入 | 直播频道和节目流 |

类型不是质量等级，不需要全部配置。先根据手中来源的实际格式选择，导入一个并检测通过后再继续添加。

## Maccms：新增单个接口

进入“设置 → 在线库 → Maccms 站点”：

1. 点击“新增”，填写站点名称、接口地址和分组。
2. 保存后勾选“启用”。
3. 点击该站点操作区的“检测可用性”。
4. 回到在线库，选择刚才的分组和站点验证分类、搜索与线路。

“检测”用于批量检查，“更新”用于刷新站点信息，“清空”会移除当前类型的配置。单个站点失败通常不代表其他站点或播放器故障。

## JS 爬虫：新建、导入或从脚本源安装

JS 爬虫页面提供“新增”“导入”“市场”“更新”“检测”和“清空”：

- 自己维护脚本时使用“新增”进入代码编辑器；
- 已有本地扩展文件时使用“导入”；
- 从脚本源安装前，展开脚本源，阅读站点名称、说明和版本；
- 安装后先检测，再只启用实际要用的扩展。

市场内置不能删除的官方脚本源，也支持在右上角“脚本源”中添加个人订阅。脚本按源分组，展开后再安装需要的站点。使用方法和个人源发布教程见[JS 脚本源：安装、制作与分享](/docs/media/online/js-script-sources)。

JS 扩展可以发起网络请求并解析外部内容。它不是普通的静态书签，只安装你信任来源的代码；扩展异常时先停用或删除，不要向扩展填写 zPlayer、网盘或其他服务的敏感账号。

### AI 生成、修复和站点参数

JS 页面顶部有“AI生成站点”。给它一个站点地址和名称，它会打开聊天窗口，抓取站点页面、写 JS 草稿、跑验证，通过后自动装进在线库。前提是先配置支持工具调用的默认对话模型；模型不支持时，页面会提示你去 AI 设置里补上。

列表里每个 JS 站点还有两个按钮：“AI修复”会先自动检测站点，按打不开、列表为空、看不到集数、播放失败这些表现给出修复方向；齿轮按钮打开“站点参数配置”，用来填模板声明的外部参数。参数以明文保存在本机，不随脚本分享，密码类字段可以显示、隐藏、粘贴和清空。

完整流程、验证范围和注意事项见[AI 生成与修复 JS 站点](/docs/media/online/js-site-generation)。AI 生成的是会发网络请求的脚本，只对自己信任、有权使用的站点使用。

## IPTV：订阅、本地文件与仓库

IPTV 页面中的“导入”菜单提供三种入口：

- **从订阅导入**：填写以 HTTP/HTTPS 提供的 M3U 地址，可另填保存名称；
- **从本地导入**：选择本机 M3U 文件；
- **从仓库导入**：选择内置仓库入口，或打开“更多”查看来源。

导入后先检测频道列表，再尝试播放少量频道。节目源失效、地区限制和服务器并发限制都可能造成部分频道不可用。

## 启用、检测、更新和删除

| 操作 | 什么时候用 |
| --- | --- |
| 启用/停用 | 控制站点是否出现在在线库；排错时先停用慢或失效来源。 |
| 检测 | 验证当前配置能否返回基本数据；检测成功仍不保证每条播放线路都有效。 |
| 更新 | 获取来源或扩展的较新配置；更新后应重新检测。 |
| 删除/清空 | 确认不再需要时移除；“清空”通常影响当前整个站点类型。 |

::: warning 导入前先确认来源
订阅、脚本和扩展可能随时变更，也可能访问其作者指定的网络服务。优先使用公开说明清楚、可追溯、仍在维护的来源；不要导入陌生人发送的配置后直接长期启用。
:::
