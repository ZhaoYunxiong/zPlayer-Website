# 站点类型：换的是来源格式，不是换一套用法

在线媒体支持多种站点类型，是因为互联网上的内容来源使用了不同的接口、订阅或扩展格式。对普通用户来说，它们最终都要完成同样的事情：返回分类和搜索结果，再提供可播放的线路或剧集。

## 6 种类型分别是什么

| 类型 | 它主要解决什么问题 | 你可以怎样理解 |
| --- | --- | --- |
| **Maccms** | 读取 Maccms 接口站点 | 最常见、最适合入门的影视站点来源 |
| **JS 爬虫** | 运行 JavaScript 站点脚本 | 用脚本适配网页或接口变化的来源 |
| **TVBox** | 导入 TVBox 订阅或配置 | 一份配置可以带来多个站点 |
| **IPTV** | 读取直播源和节目流 | 更偏向频道、直播和节目列表 |
| **Miru** | 使用 Miru 扩展描述站点 | 通过扩展适配不同站点 |
| **Kazumi** | 使用 Kazumi 扩展描述站点 | 同样是扩展式站点来源，常用于番剧等内容 |

这些图标只是帮助你在设置页面里快速认出来源类型，不代表需要把它们全部配置一遍：

这张表只用于帮助你选择来源格式，不代表每种类型有一套独立的播放逻辑。配置好以后，在线媒体页面仍然是“选择站点 → 浏览或搜索 → 选择线路和剧集 → 播放”。

## 为什么推荐 Maccms

Maccms 站点在互联网上相对容易找到，来源数量多，影视分类和搜索流程也比较直观。第一次配置时，建议先添加一个自己信任的 Maccms 站点，确认完整流程可用后，再按需要添加其他类型。

如果某个 Maccms 站点失效，通常不代表 zPlayer 的其他在线媒体功能失效；可以先检测该站点，再切换到其他可用站点。

## 什么时候需要其他类型

- 你手里已经有 TVBox 订阅：使用 TVBox 导入，不必把其中每个站点手动拆开配置。
- 你找到的是 JS 爬虫、Miru 或 Kazumi 扩展：按对应类型导入或安装即可，使用时仍回到同一套浏览和播放流程。
- 你主要看直播频道：选择 IPTV，比影视点播站点更符合使用场景。

不要为了“类型越多越好”一次添加大量来源。在线媒体页面会需要加载站点列表，来源越多，检测、搜索和切换时越容易遇到慢站点或失效站点。

::: warning 外部站点需要自己判断可信度
站点配置、订阅和扩展都来自外部。请确认来源的合法性、稳定性和隐私风险，不要把账号密码或私人信息填入不明站点；zPlayer 不负责外部站点的内容质量和可用性。
:::
