# 音频与均衡器：无声时先检查音轨

播放器里的“没有声音”，可能是静音、音量、系统输出设备、音频轨道或片源本身的问题。先按最容易确认的项目排查，比直接修改均衡器更快。

如果你要了解歌单、在线音乐、动态歌词和独立音乐播放器，请先看[音乐播放器](/docs/player/music)；本页主要处理音频轨道、系统输出和均衡器。

## 播放时的常用操作

底部音量按钮可以打开音量面板，进行静音和音量调整；播放器也支持用鼠标滚轮或已配置的快捷键调整音量。播放器音量上限可以单独设置，超过系统常见的 100% 并不代表所有设备都能按同样的音量输出。

右键打开“音频”分组，可以查看并切换当前媒体提供的音频轨道。多语言电影、评论音轨和不同声道版本，通常都在这里选择。

## 没有声音时按顺序检查

1. 看播放器是否处于静音状态，音量滑块是否被拉到最低。
2. 检查 Windows 系统音量和当前输出设备，确认其他应用是否有声音。
3. 在“音频”菜单中切换到另一个音频轨道，排除当前轨道为空或编码不兼容。
4. 暂时关闭均衡器、特殊音效和自定义音频输出，再重新播放。
5. 如果只有一个文件没有声音，用媒体属性确认它是否真的包含音频轨道。

如果所有媒体都没有声音，再考虑音频输出驱动或系统设备；如果只有某个来源异常，则优先检查来源返回的流和权限。

## 均衡器适合怎么用

均衡器适合做个人听感调整，例如让对白更突出，或降低某些频段的刺激感。它不会修复没有音频轨道、损坏音频或错误音频流。

建议先保存或记住原来的设置，每次只调整少量频段。调整后用人声、音乐和环境声都试听一下，避免只对某一段声音有效，却让其他内容失真。

音频均衡器和更底层的音频输出驱动属于不同层级：前者改变声音特性，后者决定声音如何送到系统设备。相关默认设置可在[播放、解码与画质设置](/docs/settings/playback)中查询。

## 需要把音轨单独保存或替换

播放器里的音轨菜单负责观看时切换，不会直接修改原文件。需要提取、替换或移除音轨时，使用[媒体处理工具箱](/docs/tools/media-toolbox#该选哪个工具)。先输出到新文件并试听确认，验收前不要覆盖唯一原件。
