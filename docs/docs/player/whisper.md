# Whisper AI 字幕：没有字幕时怎么办

Whisper 可以把媒体中的语音识别成文字，并按需要翻译成目标语言。它适合没有字幕、字幕质量不理想，或想临时理解外语对白的场景，但识别速度和准确度会受到模型、语言、音质和本机硬件影响。

## 两种使用方式

### 播放时实时显示

在播放器右键菜单的“字幕”分组中打开“AI 实时字幕”或“Whisper 实时字幕”，选择原始语言和翻译语言。播放器会在播放过程中准备、识别并显示结果，面板会提示当前处于准备、识别、翻译或已停止状态。

实时识别适合临时观看，不一定等同于一份已经校对好的字幕文件。对白密集、背景音乐很大、多人同时说话或专有名词很多时，识别结果更容易出错。

### 生成并保存字幕文件

需要之后反复使用时，可以打开 Whisper 字幕生成页面：选择媒体、模型、原始语言、翻译语言和输出文件，等待任务完成。生成过程中可以查看进度和已识别的字幕片段，完成后再像外挂字幕一样加载。

## 使用前需要准备什么

1. 到 Whisper 设置中下载或选择可用模型。
2. 根据电脑性能选择合适的模型大小；模型越大，资源占用和等待时间通常越高。
3. 尽量明确原始语言，不要让识别模型在不必要的情况下猜测。
4. 先用短片段测试识别效果，再处理整部电影或整集电视剧。

如果提示模型未配置，先完成模型准备；如果识别速度很慢，观察 CPU、GPU、内存和磁盘占用，不要同时启动多个大型识别任务。

## Whisper 和“内容结构”有什么关系

内容结构中的 AI 章节和内容搜索需要可分析的文字。媒体已经有字幕时，可以直接利用字幕；没有字幕时，可以在首页设置中开启“Whisper 媒体内容识别”，让 zPlayer 先识别媒体对话，再用于章节分析和语义检索。

因此：

- 只想边看边理解对白：使用 AI 实时字幕；
- 想得到可重复加载的字幕：生成并保存字幕文件；
- 想让 AI 识别剧情、建立章节并搜索视频片段：准备字幕或开启媒体内容识别，再看[播放列表与内容模块](/docs/player/content-modules)。

Whisper 生成的字幕建议人工校对，尤其是人名、地名、专业术语和多人对话。AI 识别是辅助工具，不会自动保证字幕内容和时间轴完全正确。
