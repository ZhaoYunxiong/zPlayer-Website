# 播放器界面：第一次打开该看哪里

刚打开播放器时，控制栏可能会自动隐藏，画面看起来像一块干净的视频窗口。把鼠标移到画面上，或在画面中点击一下，顶部标题栏和底部控制栏就会重新出现。

## 顶部和底部控制栏

顶部主要用于确认当前播放的媒体标题、查看缓冲状态，以及进行窗口最小化、最大化和关闭。

底部控制栏是日常最常用的区域，按钮从左到右可能会因为窗口宽度和设置不同而收纳，但功能大致包括：

| 区域 | 可以做什么 |
| --- | --- |
| 视频设置 | 打开播放器相关的画面、音频、字幕和其他播放选项 |
| 音量 | 静音、拖动音量滑块，或使用鼠标滚轮调整音量 |
| 置顶 | 让播放器窗口保持在其他窗口上方 |
| 前进、后退 | 按设定的秒数跳转 |
| 上一项、下一项 | 在播放列表或剧集播放顺序中切换内容 |
| 播放、暂停 | 控制当前媒体的播放状态 |
| 倍速 | 调整播放速度，适合快速浏览或反复听一句对白 |
| 全屏 | 在窗口播放和全屏播放之间切换 |
| 内容搜索 | 启用媒体语义搜索后，快速进入当前媒体的内容搜索 |
| 列表 | 打开“播放列表”“内容结构”“内容搜索”面板 |

“内容搜索”按钮只有在相关 AI 功能已经准备好时才会出现；没有看到它不代表播放器出错，具体条件见[播放列表与内容模块](/docs/player/content-modules#content-search)。

## 进度条不只是拖动条

进度区域会显示当前时间和总时长。除了点击、拖动进度条跳转，还可能看到：

- 章节书签在时间轴上的定位标记；
- A-B 循环的起点和终点；
- 视频缩略图预览；
- 与当前时间对应的字幕或其他进度提示。

如果一部视频很长，先把鼠标移动到时间轴上看缩略图，通常比盲目拖动更容易找到目标位置。章节书签的具体用法见[内容模块](/docs/player/content-modules)。

## 右键菜单：按钮之外的功能

播放器画面上右键，可以看到按用途分组的菜单。常见分组包括：

| 分组 | 常见操作 |
| --- | --- |
| 打开 | 打开视频、字幕或流媒体地址 |
| 播放 | 播放模式、跳转、倍速、切换来源、A-B 循环和逐帧 |
| 视频 | 视频轨道、画面比例、旋转、翻转、场景浏览器和章节书签 |
| 音频 | 静音和音频轨道 |
| 字幕 | 字幕轨道、搜索字幕、搜索弹幕、实时 Whisper 和字幕浏览器 |
| 画质 | 着色器和滤镜 |
| AI | 询问当前画面或向 AI 提问 |
| 属性 | 播放统计和媒体属性 |

有些功能本来就只在特定片源或模块启用时显示。例如没有字幕时，字幕轨道列表可能为空；没有准备语义搜索时，内容搜索入口也不会显示。

## 控制栏自动隐藏

播放面板和鼠标可以分别设置自动隐藏时间。想让视频画面保持干净，可以保留自动隐藏；演示、听写或需要频繁操作时，可以在播放器设置中延长时间或关闭自动隐藏。

如果按钮“消失”了，先移动鼠标，不需要重新启动播放器。窗口较窄时，优先从右键菜单或“列表”面板寻找被收纳的功能。

## 高能进度条：先找到信息密集的片段

进度条下方有时会出现一条高能曲线。它不是给剧情打分，而是根据当前媒体能够分析到的内容密度提示可能更精彩、对白更多或信息更密集的时间段；通常需要片源有可用字幕或其他分析数据才会显示。

第一次看一部长视频时，可以先看曲线的起伏，再配合进度条缩略图定位，往往比从头到尾盲目拖动更省时间。曲线只是辅助参考，综艺、纯音乐、没有字幕的片源可能没有曲线，也不能据此断定某一段一定是高潮。

它可以在“设置 → 播放器 → 高能进度条”中开关，默认开启。关闭后只会隐藏提示，不会影响播放、字幕或媒体文件本身。

## 进度条缩略图与场景浏览

这两个功能都能帮你找画面，但使用方式不同：

| 功能 | 适合什么时候用 | 怎么操作 |
| --- | --- | --- |
| 进度条缩略图 | 已经大致知道目标在前面还是后面，想快速扫过时间轴 | 鼠标移动到进度条上查看对应画面，点击后跳转 |
| 场景浏览 | 想连续查看一批场景，或者完全不知道目标出现在哪 | 打开“视频 → 场景浏览”，浏览缩略图后点击目标场景 |

场景浏览不会修改视频，也不会替你建立章节。它更像是一面“视频胶片墙”；想把某个位置长期留下来，请使用[章节书签与内容结构](/docs/player/content-modules#chapter-bookmarks)。

缩略图会消耗额外的读取、解码和网络流量，尤其是 NAS、媒体服务器或云端片源。可以到“设置 → 播放器 → 进度条缩略图”按数据源单独控制：本地片源通常适合开启，公网媒体服务器和云盘则可以先关闭；没有缩略图不代表视频无法播放。
