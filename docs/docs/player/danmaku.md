# 弹幕：独立于视频的评论层

弹幕是叠加在视频画面上的评论流，和字幕、视频片源是三套不同的内容。弹幕加载失败时，通常不影响视频本身播放。

本页介绍播放时怎样搜索和使用弹幕；密度、透明度、速度、区域和性能选项见[弹幕设置参考](/docs/settings/danmaku)。

## 弹幕从哪里来

弹幕可能来自本地文件或在线搜索服务。播放时可以在右键菜单的“字幕”分组中找到“搜索弹幕”等入口；已经准备好的弹幕文件，也可以通过打开功能加载。

在线搜索能否找到结果，取决于媒体名称、集数、站点数据和网络状态。搜索不到不一定是播放器故障，可以换一个更准确的媒体标题或手动加载已有文件。

“自动加载弹幕”默认开启。播放普通媒体时，软件会按媒体名称自动搜索并加载匹配的弹幕；不想让它自己找，可以到“设置 → 播放器 → 弹幕”关掉。

红果短剧的剧集会直接使用红果官方弹幕。软件会自动拉取、转换并接进现有弹幕管线；拉取失败时用本地缓存，不会回退到通用弹幕搜索，避免匹配到同名但不相干的剧。

## 看着舒服比信息越多越好

弹幕面板可以控制显示和隐藏，并调整透明度、字号、速度、位置或显示区域。弹幕太密时，优先降低显示数量或屏蔽不想看的关键词；学习、观影或需要看清画面时，直接暂时关闭弹幕也是更好的选择。

弹幕补帧等显示选项会增加渲染工作量，开启后如果出现卡顿或音画不同步，先恢复默认显示设置。

## 常见问题

- **视频正常但没有弹幕**：检查是否加载了弹幕轨道，或重新搜索当前媒体。
- **红果剧集没有弹幕**：先确认集数正确、自动加载没有被关闭；官方弹幕服务暂时不可用时，已有缓存仍会加载。
- **弹幕和画面不对应**：可能匹配到了错误的版本或集数，换结果比调整速度更可靠。
- **弹幕挡住字幕**：降低弹幕透明度、数量或显示区域，必要时开启字幕避让相关设置。
- **开启弹幕后卡顿**：先关闭弹幕确认视频是否正常，再降低弹幕数量或关闭补帧。

弹幕是观看时的附加层，不会参与[章节书签和内容搜索](/docs/player/content-modules)的内容索引；想找剧情片段，应使用内容模块。
