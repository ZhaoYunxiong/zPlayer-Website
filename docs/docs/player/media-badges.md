# 媒体徽章：一眼看出这部片的技术规格

播放界面右上角和媒体详情页右上角，可以显示一排小徽章，比如 4K、HDR、Dolby Vision、DTS-HD 之类。这些图标来自你导入的徽章库：软件读取当前剧集的视频和音频信息后，匹配出对应的徽章。

## 显示在哪里

- 播放器右上角：播放当前集时显示这一集的规格。
- 媒体详情页：在横版海报附近显示当前选中剧集的规格。

两处用的是同一套匹配结果。没有命中徽章时，整排会隐藏，不会留一块空白。

## 匹配依据

软件会根据当前剧集的分辨率、视频编码、位深、HDR 类型、音频编码和声道等信息去匹配徽章库。媒体服务器返回的信息越完整，匹配越准确；本地文件如果没有探测到这些信息，可能只显示一部分或者完全不显示。

徽章只是标签，方便你快速判断版本规格。它不代表这个文件一定能播放，也不代表画质一定比另一个版本好。实际能不能播、画质怎么样，还要看片源、解码和显示设备。

## 导入徽章库

入口是“设置 → 播放器 → 徽章库”。目前支持 Nuvio / EplayerX 格式的徽章库 JSON，可以从三个地方导入：

- 从链接导入：填写徽章库 JSON 的地址。
- 从文件导入：选择本机 JSON 文件。
- 从粘贴板导入：复制链接或 JSON 内容后直接导入，软件会自动识别。

导入后可以先预览整个库，看看名称、图标和数量是否正常。链接导入的库可以按原地址更新；本地文件和粘贴板导入的库不会记录来源地址，不能按链接更新，需要重新导入。

## 管理和排序

一个徽章库可以单独启用或禁用。导入多个库时，列表顺序就是匹配优先级：前面的库先匹配。同一个分组里通常只显示命中的第一枚徽章，避免一排标签互相重复。

“匹配预览”可以输入一段示例文本，实时看看会命中哪些徽章。自定义徽章库时，这个预览比反复播放视频更快。删除徽章库只会移除本地导入的徽章数据，不会影响媒体文件。

## 开关和排错

播放器设置里的“媒体徽章”控制是否在播放界面和媒体详情页显示徽章，默认开启。关闭后徽章库仍然保留，重新打开就能继续用。

| 现象 | 先检查什么 | 处理 |
| --- | --- | --- |
| 完全不显示 | 媒体徽章开关、徽章库是否启用 | 到“设置 → 播放器”检查开关和库状态 |
| 只显示一部分 | 当前剧集的元数据是否完整 | 打开媒体属性看看分辨率、编码、HDR 和音频信息 |
| 匹配到错误徽章 | 自定义库的 pattern 是否写得太宽 | 用匹配预览调整规则，或把更精确的库排在前面 |
| 导入失败 | JSON 格式、文件大小或网络地址 | 先用本地文件测试，确认是合法徽章库 JSON |
| 链接库不能更新 | 这个库是从文件或粘贴板导入的 | 重新导入，或改用链接导入 |
