# 播放控制与快捷操作：把定位和切集变成习惯

播放器的基本操作很直接，但几个不太显眼的功能，能让长视频、电视剧和教程看起来轻松很多。

## 日常播放

点击播放按钮或视频画面中的播放控件即可开始。底部的上一项、下一项会按照当前播放队列或剧集顺序工作；电视剧想换集时，也可以打开列表面板或回到媒体详情选择具体集数。

拖动进度条可以快速定位，点击进度条上的位置则适合做小范围跳转。网络片源跳转时需要服务端重新响应，画面短暂等待是正常的，不建议连续快速点击很多次。

## 播放模式

默认视频播放模式可以设置为：

- 播放完停止；
- 单集循环；
- 顺序播放；
- 随机播放。

视频和音乐有各自的播放模式。只想看当前一集时选择“播放完停止”；追剧或连续播放列表时选择“顺序播放”；需要反复练习某个片段时，使用章节书签里的区间循环更准确。

## 快进、倍速和逐帧

- 前进、后退按钮按照设置中的跳跃时间移动播放位置。
- 倍速可以在播放器底部调整，范围为 0.1 到 4 倍，适合快速浏览或放慢对白、动作细节。
- 逐帧功能适合检查画面、字幕时间轴或动作细节。视频暂停后使用更容易观察结果。
- 上一章、下一章会根据当前媒体已有的章节书签定位；没有章节数据时不会凭空生成章节。

## A-B 区间循环

想反复看一小段内容时，可以设置 A 点和 B 点，再开启 A-B 循环。它适合：

- 学习对白或外语听力；
- 检查音画同步；
- 复习教程中的一个步骤；
- 反复观看某个剧情片段。

如果循环没有按预期开始，确认 B 点在 A 点之后，并检查进度条上是否出现了对应的区间标记。章节书签也可以直接设置为区间循环，见[章节书签与故事剧情](/docs/player/content-modules#章节书签：给时间轴留下自己的标记)。

## 截图、动图和置顶

播放器菜单提供截图功能；Windows 版本还可以使用动图截取入口，把当前片段导出为 GIF。保存目录、文件名模板等属于播放器设置，可以在[播放、解码与画质设置](/docs/settings/playback)中查询。

置顶适合一边看教程一边操作其他软件。它只改变窗口层级，不会改变媒体来源或播放顺序。

## 快捷键可以自己改

播放器支持为播放/暂停、快进、快退、音量、全屏、上一项、下一项、上一章、下一章、截图、旋转、翻转、A-B 循环和逐帧等操作配置按键。

快捷键是可配置的，不建议在文档里死记某一个默认键位。到设置中的“播放器 → 快捷键”查看当前绑定；播放器获得焦点后再按键，且输入框获得焦点时不会抢走文本输入。

快捷键没有反应时，可以按这个顺序检查：

1. 先点击视频区域，让播放器获得焦点。
2. 如果正在输入搜索文字或编辑书签，先完成输入并移开文本框焦点。
3. 到快捷键设置中确认该按键没有被改掉或与其他操作冲突。
4. 用底部按钮测试同一功能，确认是按键问题还是播放问题。

## Windows 默认快捷键表

下面是 Windows 版本的内置默认键位。快捷键可以在“设置 → 播放器 → 快捷键”中重新绑定；如果你已经改过设置，请以软件当前显示的键位为准。

| 操作 | 默认按键 | 说明 |
| --- | --- | --- |
| 播放 / 暂停 | `Space` | 切换当前播放状态 |
| 快进 / 快退 | `Right` / `Left` | 按设置的跳跃时长移动进度 |
| 增大 / 减小音量 | `Up` / `Down` | 调整播放器音量 |
| 长按加速 / 长按减速 | `D` / `A` | 临时改变播放速度 |
| 全屏 | `F` | 切换全屏 |
| 下一项 / 上一项 | `.` / `,` | 播放列表或剧集中的下一项、上一项 |
| 下一章 / 上一章 | `]` / `[` | 在已有章节之间跳转 |
| 窗口置顶 | `T` | 切换窗口是否保持在最前 |
| 静音 | `M` | 切换静音 |
| 播放信息 | `I` | 查看当前播放信息 |
| 截图 | `S` | 保存当前画面 |
| 旋转 | `R` | 旋转画面 |
| 水平翻转 / 垂直翻转 | `H` / `V` | 翻转当前画面 |
| 迷你进度条 | `O` | 切换迷你进度条显示 |
| 设置 A 点 / B 点 | `J` / `K` | 设置 A-B 循环的起止位置 |
| 开启 / 关闭 A-B 循环 | `L` | 切换当前区间循环 |
| 下一帧 / 上一帧 | `N` / `B` | 暂停时逐帧检查画面 |
| 退出 | `Escape` | 优先退出全屏，或关闭当前播放器窗口 |

播放器需要先获得焦点。正在搜索、编辑书签或填写连接信息时，输入框会优先接收键盘输入，这是正常的。

## 手势操作：不用一直找按钮

Windows 播放器还提供几种适合鼠标或触摸屏的区域手势。到“设置 → 播放器 → 区域控制”可以分别开关和调整：

- **双击视频画面**：切换全屏。
- **点击暂停区域**：点击或触摸指定区域切换播放/暂停。默认区域在画面上方，占屏幕约四分之一；位置可改为上、下、左、右，大小可选二分之一、三分之一、四分之一或五分之一。
- **左右拖动定位**：先在画面上按住约半秒，再左右拖动；播放器会先显示目标时间，松开后才提交跳转。适合触摸屏，也适合不想精确抓住进度条的鼠标操作。
- **边缘长按变速**：按住画面最右侧约 100 像素区域会临时加速，默认是 2 倍；按住最左侧约 100 像素区域会临时减速。松开后恢复原来的倍速，长按加速倍率可在 1.1 到 4 倍之间调整。
- **鼠标滚轮调音量**：鼠标位于视频区域时滚动，可以调整音量；也可以使用音量按钮或 `Up` / `Down`。

这里的左右拖动主要用于调节播放进度，和“长按边缘临时变速”是两套手势。遇到误触时，可以先关闭“滑动手势”“长按加速”或“触摸暂停”，保留底部按钮和快捷键操作。

## 片头片尾跳过：追番时少等一会儿

打开“设置 → 播放器 → 跳跃播放”，可以配置片头和片尾的跳过区间。手动设置时填写四个时间点：片头起点、片头终点、片尾起点、片尾终点；保存后，播放到相应区间会自动跳过。想恢复自动判断时，可以删除手动区间并重新启用自动识别。

自动识别可能综合媒体信息、已有章节或弹幕提示、在线片头片尾数据库以及音频特征来推测区间。动漫片源还会优先尝试 AnimeSkip 一类的动漫片头片尾数据；The Intro Database 可用于更广泛的媒体。两个服务都可以填写自己的 API 密钥，留空时使用软件内置密钥。

自动识别不是百分之百准确：片头较长、片尾有彩蛋、特别篇结构不同，或者网络串流无法完成本地音频分析时，都建议先播放确认，再手动修正时间点。这个功能只改变播放时的跳过行为，不会剪辑或改写原视频。
