# 字幕：内封、外挂、搜索和实时识别

字幕不只有一种来源。视频内嵌字幕、同目录外挂字幕、在线搜索结果和 Whisper 实时识别，加载方式和适用场景都不同。

## 先选择正确的字幕轨道

播放时打开右键菜单的“字幕”分组，或使用字幕面板查看当前可用轨道。通常可以在下面几类字幕中选择：

- **内封字幕**：字幕已经包含在视频容器里，不需要单独的字幕文件；
- **外挂字幕**：从本地打开 `.srt`、`.ass` 等字幕文件；
- **在线字幕**：通过“搜索字幕”查找并下载匹配结果；
- **AI 字幕**：没有可用字幕时，由 Whisper 根据音频识别生成或实时显示。

如果列表里根本没有想要的字幕，先确认片源是否加载完成；如果是外挂字幕，再确认文件路径、文件名关联和字幕编码。

## 字幕和内容搜索不是一回事

“搜索字幕”是为当前媒体寻找字幕文件；“内容搜索”是用自然语言找视频中的某个片段。比如：

- 想找一份中文字幕：使用“搜索字幕”；
- 想找“主角在雨中告白的那一段”：使用[内容搜索](/docs/player/content-modules#内容搜索：用一句话找回视频片段)。

内容搜索需要字幕或语音识别结果来建立语义索引，不能代替字幕下载。

## 字幕不同步怎么办

先判断是整部视频都偏移，还是某一段字幕本身时间轴错误：

- 整部都提前或延后：使用字幕延迟调整；
- 只有个别句子不对：字幕文件可能分段或时间轴有问题，换一份字幕更快；
- 外挂字幕完全不显示：检查编码、文件路径和当前选择的轨道；
- ASS 等特效字幕显示异常：尝试更换字幕引擎或关闭可能冲突的处理。

字幕字体、字号、描边、阴影、位置、动画和延迟属于字幕样式设置。先用默认样式确认字幕能正常显示，再根据观看环境调整。

## 需要临时处理字幕时

右键字幕文字可以进行复制、网络搜索或询问 AI；字幕面板还提供字幕列表、字幕浏览器和翻译等入口。在线搜索、翻译和 AI 功能受网络、服务接口、模型及片源内容影响，结果需要自行核对。

没有字幕时，继续阅读[Whisper AI 字幕](/docs/player/whisper)；如果只是需要字幕文件而不需要边播边识别，优先使用生成字幕的方式，便于之后重复播放。

## 字幕翻译：原文和译文一起看

如果找到了原文字幕，但不方便直接阅读，可以使用播放器自带的字幕翻译：

1. 先把字幕引擎切换为 **zPlayer**。完整的翻译显示方式由 zPlayer 字幕引擎提供。
2. 打开“设置 → 播放器 → 字幕”，找到“字幕翻译”。
3. 选择“翻译到”的目标语言和翻译显示模式，然后打开翻译开关。
4. 播放时重新载入字幕，检查译文是否与原文对应。

翻译显示模式有三种：

- **只显示翻译后的文本**：画面更干净，适合只想看译文；
- **译文在原字幕上方**：保留原文，同时把译文放在上方；
- **译文在原字幕下方**：更符合许多双语字幕的阅读习惯。

如果改了目标语言或显示模式，记得先关闭翻译，再重新打开。翻译设置更新后不会自动替你重新启动当前翻译任务。翻译结果依赖网络和翻译服务，专有名词、歌名和人名建议结合原文核对。

### 内封字幕也可以翻译

打开“内封字幕翻译”后，选择内封字幕轨道即可尝试翻译。若视频容器里已经有对应的译文轨道，播放器会优先使用现成轨道；没有现成译文时，Windows 可以提取内封字幕后再进行翻译。网络或服务不可用时，通常会保留原字幕显示。

字幕翻译只负责把字幕文字转换为另一种语言，不等于[内容搜索](/docs/player/content-modules#内容搜索：用一句话找回视频片段)，也不会修改原字幕文件。

## 字幕动画：让歌词、台词和重点更有表现力

在“设置 → 播放器 → 字幕 → 字幕动画”中，可以为字幕选择预设动画。动画预设包括：无、渐变、缩放、光影、倾诉、轻读、上浮、扫色、描边脉冲、打字、旋转和 PV。

可以按观看内容这样挑：

| 内容 | 可以先试的动画 | 体验方向 |
| --- | --- | --- |
| 普通对白、纪录片、教程 | `无`、`渐变` | 最稳定，也最不影响阅读 |
| 歌词、音乐视频 | `光影`、`扫色`、`描边脉冲` | 强调文字出现和重点变化 |
| 需要逐字阅读或学习发音 | `打字`、`轻读` | 更容易注意到语义单元的出现顺序 |
| 想要更活泼的二次元观感 | `上浮`、`旋转`、`PV`、`倾诉` | 动态更明显，建议先降低强度 |

动画不是越多越好。遇到字幕跳动、边缘被裁切或阅读跟不上时，可以降低动画速度、入场时长、位置扰动和强调缩放，并适当增大动画安全区域；看长对白时直接使用“渐变”或“无”通常更舒服。完整的动画样式与参数主要由 zPlayer 字幕引擎提供，Native 引擎的支持范围取决于播放器内核。

## 同时加载多条字幕：没有固定条数上限

使用 **zPlayer 字幕引擎** 时，字幕列表支持同时选择多条字幕，没有软件人为设定的固定条数上限。你可以把原文、中文字幕、学习字幕，甚至不同版本的字幕一起载入，再通过字幕样式和显示位置区分它们。

操作时打开字幕列表，逐项点选需要显示的轨道即可；已经选中的字幕再次点选可以取消。多条字幕的文本过长或位置相同会互相遮挡，这时建议减少同时显示的条数，或者为不同字幕设置不同位置、字号和描边。实际可同时流畅显示多少条，仍会受到字幕复杂度、动画效果和设备性能影响。

如果使用 Native 字幕引擎，字幕轨道由播放器内核按单轨方式管理，不能获得 zPlayer 引擎的多字幕叠加能力。需要双语、原文对照或多版本字幕时，优先切回 zPlayer 引擎。
