# 字幕、弹幕或音频异常：先确认视频本身正常

字幕、弹幕和音频是附加轨道。排查时先关闭它们，确认视频画面能正常播放，再逐个恢复。

## 字幕完全没有

先打开播放时的字幕列表，确认当前媒体到底有哪些轨道：

- 内嵌字幕：字幕在视频容器中；
- 同目录外挂字幕：字幕文件通常和视频放在一起；
- 手动加载的外部字幕：从文件位置打开；
- 在线下载字幕：通过当前媒体搜索；
- Whisper 字幕：由本机模型识别或实时生成。

如果字幕列表为空：

1. 确认片源已经加载完成；
2. 检查字幕文件是否仍然存在；
3. 确认字幕文件名、所在目录和视频是否对应；
4. 换一条内嵌字幕或另一个外部字幕做对照；
5. 如果是在线字幕，检查网络和搜索结果是否匹配了正确的作品、季和集。

字幕搜索没有结果，不一定是播放器故障，也可能是当前片源、标题或集数无法被服务识别。

## 字幕显示乱码、错位或时间不对

### 乱码

检查字幕编码，并尝试另一份字幕文件。不要先修改播放器画面设置，因为编码错误通常不是渲染问题。

### 整部提前或延后

使用字幕延迟调整进行整体偏移。调整后如果所有台词都同步，说明字幕内容基本正确。

### 只有部分句子错位

这种情况通常是字幕文件的时间轴本身有问题，换一份与当前视频匹配的字幕比持续调延迟更有效。

### ASS 特效异常

ASS 字幕可能包含字体、位置、动画和复杂特效。先使用最简单的字幕样式或切换字幕引擎做对照，再决定是否保留特效。

## 翻译、动画和多字幕

字幕翻译、字幕动画和多条字幕叠加都属于 zPlayer 字幕引擎的功能：

- 需要原文字幕时，先确认原文轨道可以正常显示；
- 翻译结果受网络和翻译服务影响，人名、专有名词需要自行核对；
- 普通对白建议使用无动画或渐变；
- 多条字幕可以同时加载，但位置、字号和描边相同会互相遮挡；
- 多字幕、动画、弹幕和滤镜一起开启时，设备负载会增加。

如果遇到卡顿，先恢复为一条普通字幕。完整用法见[字幕](/docs/player/subtitles)。

## Whisper 实时字幕

没有字幕时可以使用 Whisper，但它需要本机已下载模型，并可能占用较多 CPU、GPU 和内存。

检查顺序：

1. “设置 → Whisper”中确认模型已下载；
2. 确认默认识别语言或手动选择的语言正确；
3. 识别语言和翻译语言不要混淆；
4. 如果字幕追不上播放，降低视频负载或适当增加字幕队列时长；
5. 如果模型下载失败，换下载来源或检查代理、磁盘和权限。

需要保存字幕时，确认“自动保存实时字幕”已开启，或在播放器中使用生成字幕功能。详见[Whisper AI 字幕](/docs/player/whisper)。

## 弹幕没有或对不上

### 没有弹幕

- 确认当前媒体已加载弹幕轨道；
- 重新搜索当前作品、季和集；
- 尝试更准确的标题；
- 检查网络和弹幕服务是否可访问；
- 用已有的本地弹幕文件做对照。

### 弹幕和画面不对应

弹幕通常和具体版本、集数、剪辑长度有关。先换一个更匹配的搜索结果或手动加载对应文件，不要先调速度。

### 弹幕太密或挡住字幕

降低弹幕数量、透明度、字号或显示区域；必要时直接关闭。想看清剧情时，少量弹幕通常比全部显示更舒服。

### 开启弹幕后卡顿

先关闭弹幕确认视频正常，再关闭弹幕补帧或其他高负载显示效果。只有在画面稳定后，才逐项恢复设置。

## 音频异常

- 检查 Windows 当前输出设备；
- 检查播放器静音和音量；
- 打开音频轨道列表，确认选择了正确轨道；
- 关闭均衡器、音频滤镜和特殊输出做对照；
- 蓝牙、HDMI 或 USB 声卡异常时，切换到另一个输出设备。

如果只有一个文件没有声音，检查它是否真的包含音频轨道；如果所有文件都没有声音，再看[音频与均衡器](/docs/player/audio)和[播放失败、黑屏、卡顿](/docs/troubleshooting/playback)。

## 仍然无法判断时

请写清是字幕、弹幕还是音频异常，不要只说“播放有问题”。反馈时附上：

- 媒体来源和当前片源；
- 使用的字幕或弹幕类型；
- 关闭附加轨道后的对照结果；
- 发生时间和脱敏日志。

不要发送字幕文件中不希望公开的内容，也不要把账号密码、Cookie 或访问令牌放进反馈。
