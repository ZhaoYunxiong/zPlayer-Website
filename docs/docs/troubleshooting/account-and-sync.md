# 账户、授权与同步问题：先分清是哪一种账户

zPlayer 里至少会遇到三种账户或授权：

- Microsoft 账户：负责 Microsoft Store 安装、购买和内购功能授权；
- zPlayer 本机账户：负责本机用户、PIN、播放记录和播放列表；
- Bangumi、Trakt、Emby、Jellyfin、Plex 等服务账户：负责第三方数据或媒体服务器访问。

它们互相不能替代。购买成功不代表媒体服务器登录成功，本机 PIN 也不是 Microsoft 账户密码。

## 内购后仍显示未解锁

媒体服务器连接功能的内购是 88 元一次性买断，授权与购买时使用的 Microsoft 账户绑定。

先检查：

1. 当前 Windows 和 Microsoft Store 登录的是购买时的账户；
2. Microsoft Store 订单已经显示购买成功；
3. zPlayer 是从 Microsoft Store 安装的；
4. 关闭并重新打开 zPlayer；
5. 系统时间、网络和 Microsoft Store 本身正常。

不要重复购买。仍然无法解锁时，保留购买结果和错误提示，通过[获取帮助](/support)联系开发者；不要发送完整订单号、账号密码或支付隐私信息。

## 本机账户无法登录或 PIN 有问题

本机账户的 PIN 只作用于当前软件配置。确认：

- 输入的是当前账户的 PIN；
- 没有把 Microsoft 账户密码当成 zPlayer PIN；
- 添加普通账户前，管理员已经设置管理员密码；
- 删除账户前确认其中的播放记录和播放列表是否还需要。

删除普通账户会同时删除与该账户相关的浏览记录、播放列表等信息。管理员账户、当前正在使用的账户和自带管理员账户不能删除。

## Bangumi 或 Trakt 没有同步

进入“设置 → 首页 → 历史记录”，检查：

- 总开关是否打开；
- “登录验证”是否完成且授权没有过期；
- 需要的“拉取播放历史”或“推送播放历史”方向是否打开；
- 测试媒体是否已经正确刮削；
- 作品的标题、年份、季数和集数是否能对应到服务中的条目。

建议只拿一部明确匹配的电视剧或电影测试。不要在匹配还错误时连续点击“立即同步”，否则错误状态可能继续被写到远端。

### 只拉取没有结果

拉取只会更新本地已经存在、并且能够匹配到的媒体。远端有记录但本地没有对应作品时，没有变化是正常的。

### 只推送没有结果

先确认本地已经产生观看记录，再检查 TMDB 匹配、季数和集数。只同名但不是同一部作品时，服务通常不会接受为同一个条目。

### 两边状态不一致

播放进度、已观看标记和外部网站的收藏/看过状态不是同一个字段。先确定你比较的是哪一种状态，再决定拉取还是推送。

完整流程见[Bangumi 与 Trakt](/docs/sync/bangumi-and-trakt)和[同步异常排查](/docs/sync/troubleshooting)。

## 媒体服务器播放进度没有同步

先确认你播放的确实是 Emby、Jellyfin、Plex、极影视或飞牛影视来源，不是本地或 NAS 中的同名文件。

然后检查：

- 当前服务器账号拥有更新播放状态的权限；
- 播放过程中网络没有断开；
- 播放一小段后正常停止，并等待几秒；
- 回到服务器网页确认播放进度；
- 媒体服务器没有限制客户端上报；
- 非自建服务器没有因为媒体库模式读取过多内容。

媒体服务器进度同步不使用 Bangumi 或 Trakt 的开关。服务端不支持、账号只有读取权限或播放来源选错时，zPlayer 无法替它写入进度。

详见[媒体服务器播放进度同步](/docs/sync/media-server)。

## 授权过期或登录反复失败

重新点击对应服务的登录验证前，先确认系统时间和网络正常。浏览器能打开服务网页，不代表 OAuth 回调、API 或当前权限都正常。

如果登录后马上又显示未登录，记录：

- 服务名称；
- 登录时间；
- 是否换过账户；
- 错误提示；
- 是否只有一个服务失败。

不要发送访问令牌、Cookie 或完整登录回调地址。

## 反馈时怎么描述

请写清楚：

- 是购买授权、本机账户、Bangumi、Trakt 还是媒体服务器；
- 当前账户类型和操作方向；
- 作品的类型、季集和来源；
- 你执行的是登录、拉取、推送、立即同步还是播放时自动上报；
- 发生时间和脱敏后的日志。

联系方式和动态微信二维码位置见[日志导出与反馈](/docs/troubleshooting/logs-and-feedback)。
