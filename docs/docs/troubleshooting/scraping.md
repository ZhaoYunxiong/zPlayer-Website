# 扫描或刮削失败：文件找不到和作品认错要分开处理

先看媒体库里有没有文件：

- **没有文件**：这是扫描、路径、权限或过滤问题，先看[媒体库为空](/docs/troubleshooting/library)；
- **有文件但没有海报、标题或剧集信息**：这是刮削或匹配问题；
- **有资料但认成了另一部作品**：优先重新选择 TMDB 条目，不要先手动改几十个字段。

## 扫描阶段

扫描阶段只负责让 zPlayer 发现文件。依次确认：

1. 连接管理中的来源地址仍然有效；
2. 当前账号能读取目录；
3. 文件格式已在“设置 → 文件夹 → 文件格式”中识别；
4. 文件没有被隐藏项目或加载过滤排除；
5. 网络文件服务没有超时或返回空目录；
6. 首页自动刷新或手动刷新任务已经完成。

建议先拿一个只有少量媒体的小目录测试。小目录能正常扫描，再扩大范围，更容易区分“配置错误”和“片库太大还在处理”。

## 刮削最容易错在哪里

### 内容类型

非媒体服务器来源的内容类型会直接影响 TMDB 匹配：

- 电影目录按电影添加；
- 电视剧目录按电视剧添加；
- 音乐目录按音乐添加；
- 不要把电影和电视剧混在同一个公共根目录后，用一个类型提交。

如果同一个来源里混合了多种类型，建议拆成多个更明确的目录分别添加。首页管理不是靠猜目录意图来工作的。

### 文件命名和季集

电视剧文件最好带有清晰的季集信息，例如 S01E01；电影文件名里保留片名和年份通常更容易匹配。特别篇、剧场版、重制版和多季作品尤其容易因为标题相同而认错。

命名不理想时，可以先在媒体详情里手动重新刮削；如果经常遇到同一套命名问题，再考虑整理目录和文件名。

### 媒体服务器模式

媒体服务器不需要在连接管理里手动选择电影或电视剧分类。它会使用服务器返回的媒体库和项目类型。

媒体库模式会获取服务器较多的媒体信息，适合自建服务器；非自建或共享服务器通常使用直连模式。错误的模式可能表现为首页长时间加载、媒体重复、内容不完整或刮削请求异常。

## TMDB 相关检查

### 网络

如果大量媒体同时刮削失败，先看[网络与 TMDB](/docs/troubleshooting/network-and-tmdb)。不要把每一部作品都当成单独的标题匹配问题。

### 密钥

“设置 → 首页 → TMDB 密钥”留空时使用软件内置密钥；填写自己的 TMDB API Key 后使用自己的密钥。密钥不要发给开发者或贴到公开截图中。

### 语言和地区

“TMDB 区域代码”“TMDB 默认语言”和“TMDB 默认图片语言”会影响结果偏好。中文用户通常可以先使用 CN、zh、zh；如果资料语言不对，再按作品实际地区和语言调整。

更改语言或图片质量不会自动把错误作品变成正确作品。已经认错的媒体要重新刮削并选择正确的 TMDB 结果。

## 修复一部错误媒体

推荐顺序：

1. 打开媒体详情，确认错误的是系列、季还是具体集；
2. 使用“重新刮削”，输入更准确的标题或补充年份；
3. 从 TMDB 搜索结果中选择正确的作品；
4. 如果作品已经匹配正确，只是译名、简介、海报或剧集字段不理想，使用“编辑元数据”；
5. 回到首页确认栏目和继续观看状态是否恢复。

“重新刮削”适合解决作品认错；“编辑元数据”适合解决资料展示不符合个人习惯。两者不要混为一谈。

## 来源发生变化后怎么办

新增、修改或删除连接管理中的来源后，回到首页会自动刷新，不需要每次手动点击刷新。来源很多、网络较慢或首次扫描数据量较大时，需要等待任务完成。

如果只有新增文件没有出现，可以先使用首页刷新功能确认来源变化；如果文件出现了但资料错误，再做单部媒体的重新刮削。不要一遇到一部错误作品就全库重新刮削。

## 成人媒体资料

如果启用了成人媒体刮削，相关媒体会按设置尝试使用对应的资料来源。ThePornDB 访问令牌是可选的；令牌错误、网络受限或关闭相关开关时，结果可能不同。

如果你不需要这类内容，关闭“启用成人媒体”以及“在媒体分类外显示成人媒体”，避免它们进入普通栏目和全局搜索。

## 仍然失败时导出什么

不要只发一张海报截图。首页右上角菜单中的“刮削信息导出”会提供更接近实际匹配过程的调试信息，可以把导出文件通过邮件发送给开发者。

反馈时附上：

- 原始文件名和所在来源类型；
- 选择的内容类型；
- 期望匹配的作品；
- 当前匹配到的作品；
- 是否只有这一部失败；
- 发生时间和脱敏后的导出文件或日志。

请删除导出内容中的私人路径、服务器地址、账号、令牌和其他不希望公开的信息。
