# 媒体库为空：先看是“没有来源”还是“没有文件”

先打开“媒体库”，不要直接去首页判断。媒体库能看到来源但首页没有内容，和媒体库本身为空，是两条不同的排查路径。

## 一步判断问题在哪

| 现象 | 说明 |
| --- | --- |
| 连接管理里没有来源 | 来源还没有保存成功，或入口被模块设置隐藏 |
| 有来源，但打开后没有文件 | 路径、权限、网络或过滤条件有问题 |
| 能看到文件，首页没有媒体卡片 | 扫描已部分成功，继续看[扫描或刮削失败](/docs/troubleshooting/scraping) |
| 媒体服务器只有一部分内容 | 检查媒体库模式、服务器账户权限和服务器返回的媒体库 |

## 连接管理里没有来源

确认你完成了这一整套流程：

> 连接管理 → 选择分类 → 选择服务 → 填写连接信息 → 保存

保存后回到首页，zPlayer 会自动刷新来源，通常不需要再手动添加一次。若入口本身不见了，打开“设置 → 模块”，确认媒体库、首页或在线库等相关模块没有被关闭。

连接媒体服务器属于内购解锁范围；如果只是本地目录、NAS 或普通文件服务，不需要为了播放本地文件先购买媒体服务器功能，见[内购解锁](/docs/getting-started/unlock)。

## 有来源但没有文件

### 本地目录

- 在 Windows 资源管理器中确认目录和文件仍然存在；
- 确认添加的是视频真正所在的目录，而不是一个已经移动过的旧路径；
- 如果文件扩展名不常见，到“设置 → 文件夹 → 文件格式”确认它被识别为视频或音频；
- 暂时打开“显示所有文件”，用来判断是文件不存在，还是被媒体格式过滤；
- 检查“加载过滤”里是否存在忽略路径。

### NAS 和网络文件服务

- 先用 Windows 资源管理器确认 NAS 地址可以访问；
- 确认填写的账号确实拥有目标目录的读取权限；
- 检查 NAS 是否只允许特定设备或 IP；
- 确认 SMB、FTP、SFTP、WebDAV 等服务的地址、端口和路径没有写错；
- 如果是映射盘，优先尝试使用实际网络路径进行对照测试。

浏览器或资源管理器能访问，不一定代表服务端给 zPlayer 返回了同样的目录。反馈时请写清使用的是哪一种文件服务。

### 隐藏和递归显示

“忽略以点开头的本地文件和文件夹”开启时，以点号开头的项目不会显示；“递归显示所有媒体”关闭时，深层目录中的媒体不会被汇总到当前层。

这些设置只影响 zPlayer 的浏览结果，不会删除文件。排查完成后，建议恢复为适合日常使用的值，避免把临时测试选项长期打开。

## 内容类型选错会造成“看起来像空”

非媒体服务器来源需要选择准确的内容类型：

- 一整个目录都是电影，选择电影；
- 一整个目录都是电视剧，选择电视剧；
- 音乐目录选择音乐；
- 不要把同时包含电影、电视剧和音乐的公共根目录直接加入连接管理。

例如 NAS 中有“媒体/电影”和“媒体/电视剧”两个目录，应分别添加，不能把“媒体”作为一个混合来源交给某一个类型。分类错误有时不会让媒体库完全为空，但会让首页刮削错误、栏目不出现或内容被归到意外位置。

媒体服务器不需要手动选择电影或电视剧分类，类型由服务器返回的媒体库决定。

## 媒体服务器的两个模式

### 媒体库模式

媒体库模式会读取服务器的大量甚至全部媒体信息，适合自己搭建并管理的 Emby、Jellyfin、Plex、极影视或飞牛影视。服务器内容很多时，首次加载可能需要等待。

### 直连模式

直连模式更像按目录和服务器返回的内容按需浏览。别人分享的服务器、公共服务器或非自建服务器，通常建议使用直连模式，不要开启媒体库模式，否则可能请求过多、加载很慢，甚至触发服务器限制。

如果服务器能连上但首页很慢、内容不完整，先确认是不是误用了媒体库模式。

## 两个容易写错的服务

### 飞牛影视

飞牛影视默认端口是 8005，不是 5666。连接地址通常类似：

http://你的飞牛地址:8005

如果你在飞牛端改过端口，以实际端口为准。

### 115 网盘

115 网盘已关闭开发者入驻，zPlayer 的 115 网盘连接暂不可用。不要因为这个入口失败而反复修改其他网盘或网络设置。

## 如果文件服务有内容、首页仍然为空

转到[扫描或刮削失败](/docs/troubleshooting/scraping)，重点检查：

1. 来源对应的内容类型；
2. 文件名和季集信息；
3. TMDB 网络和语言设置；
4. 首页扫描是否仍在进行；
5. 主页右上角是否可以导出刮削信息。

不要重复添加同一个来源。重复来源只会让结果更难判断，也可能造成同一媒体出现多份。
