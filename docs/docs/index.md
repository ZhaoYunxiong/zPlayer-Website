# 使用文档

欢迎使用 zPlayer 使用文档。这里按真实使用顺序介绍从安装、连接媒体来源，到整理首页、播放内容和同步记录的完整流程。

## 推荐阅读顺序

1. [软件简介](/docs/getting-started/overview)
2. [下载、安装与更新](/docs/getting-started/install)
3. [首次启动](/docs/getting-started/first-launch)
4. 根据媒体来源阅读[文件服务](/docs/media/file-services)、[首页管理](/docs/media/home-management)或[在线媒体](/docs/media/online-media)
5. 播放遇到问题时查看[播放器](/docs/player/)和[故障排查](/docs/troubleshooting/)

官网首页的每个功能标题都可以直接进入对应说明；也可以查看完整的[首页功能与文档索引](/docs/features)。

## 三种媒体入口

### 文件服务

面向已有媒体文件或媒体服务。它关注连接、扫描、目录结构和文件访问，不要求每个来源都先整理成海报墙。

按来源继续阅读：[本地与网络文件服务](/docs/media/connections/local-and-network)、[云盘与对象存储](/docs/media/connections/cloud-and-object-storage)、[媒体服务器](/docs/media/connections/media-servers)。

### 首页管理

面向希望把媒体整理成首页的用户。它关注扫描、刮削、元数据、媒体详情、收藏、片单、历史和继续观看。

### 在线媒体

面向直接从在线站点搜索内容的场景。它关注站点类型、线路、剧集和片源切换。

## 查看观看记录

播放之后，可以按需要继续查看：

- [历史记录](/docs/media/history)：按日期展开作品和每次播放，搜索、筛选或删除记录。
- [作品观看详情](/docs/media/history/work-details)：查看一部作品的累计观看、分季进度和完整历程。
- [播放统计](/docs/media/history/playback-statistics)：查看统计口径、观看分布和作品排行，点击数字核对记录。
- [观看回顾](/docs/media/history/viewing-recap)：翻看月度、年度片单，以及重看、完季和续看节点。
