# 文件夹与列表：决定“看得到什么”和“怎么排”

这里合并了“设置 → 文件夹”和“设置 → 列表”两页。

- 文件夹设置决定扫描哪些内容、是否递归显示，以及哪些扩展名被当成媒体；
- 列表设置决定网格或列表、排序、缩略图和滚动手感。

它们不会代替连接管理。长期使用的本地目录、NAS 或媒体服务器，仍然从[文件服务](/docs/media/file-services)添加。

::: tip 先区分两个浏览入口
媒体库适合按目录、文件和来源查找；首页适合按海报、元数据、推荐和动态栏目浏览。修改本页的列表样式，不会改变首页栏目规则。
:::

## 文件夹选项

### 自动加载连接管理内的媒体

默认开启。开启后，连接管理中保存的来源会自动进入媒体库加载流程。

如果你只想临时打开文件、不希望任何来源自动出现在媒体库，可以关闭；但长期维护片库时建议保留开启，否则容易误以为连接管理没有生效。

### 自动定位到最后一次观看的记录

开启后，重新进入文件夹浏览时会尽量回到上次观看的位置。适合目录层级较深、经常接着看同一位置的用户；如果你总想从文件夹根部开始浏览，可以关闭。

### 忽略以点开头的本地文件和文件夹

默认开启，用来隐藏以点号开头的文件或目录。这类项目经常是系统文件、临时目录或不希望出现在片库里的辅助文件。

它只影响 zPlayer 的显示，不会删除文件，也不会修改 Windows 的文件属性。

### 显示所有文件

默认关闭。开启后，文件夹中不属于已识别媒体格式的文件也会显示，适合检查目录内容或排查“文件明明存在但列表没有”的问题。

如果你的片库很大，建议保持关闭，避免字幕、压缩包、说明文档等内容混进媒体列表。

### 递归显示所有媒体

默认关闭。开启后，当前文件夹下更深层级的媒体也会被汇总显示，适合多层目录结构的临时查找。

它更像“跨层级查看”开关，不会把原有目录结构改平，也不会改变首页刮削所使用的来源路径。目录结构本身比较重要时，建议关闭后按文件夹逐层浏览。

## 文件格式与文件关联

### 文件格式

这里维护 zPlayer 识别的媒体扩展名，分别可以添加为视频或音频格式。例如某个视频使用了软件默认列表之外的扩展名，可以在这里补充。

建议：

1. 扩展名带上点号，例如 .mp4；
2. 只添加你确认属于视频或音频的格式；
3. 同一个扩展名不要在两个类别里重复添加；
4. 添加后先在一个小目录测试，再用于整个片库。

这只是在 zPlayer 内识别文件，不会把文件转换成其他格式。

### 设置文件关联和移除文件关联

这两个操作只在 Windows 上可用：

- 设置文件关联：让选中的媒体格式可以在资源管理器中关联到 zPlayer；
- 移除文件关联：取消 zPlayer 对这些扩展名的系统关联。

Windows 可能会弹出权限确认。它修改的是当前系统的文件打开方式，不会移动或删除视频。如果你不想改变系统默认播放器，只维护“文件格式”列表即可。

## 加载过滤

这里会列出已经配置的忽略路径。命中忽略路径的内容不会进入文件夹加载结果；移除过滤项只会让它重新可见，不会触碰原文件。

遇到媒体库少了一部分内容时，除了检查连接权限，也要看看是否有旧的忽略路径。

## 列表样式与浏览手感

### 网格还是列表

Windows 默认是网格。网格适合用海报快速扫一眼，列表适合文件名较长、需要对照目录和信息的场景。

### 网格大小

有大、中、小三档：

- 大：一屏内容少，但海报和文字更醒目；
- 中：在信息量和可读性之间折中；
- 小：一屏能放更多内容，适合片库很大的情况。

默认是小。高分辨率大屏可以尝试中或大；窗口较窄时，小网格通常更顺手。

### 排序和倒序

排序依据包括名称、日期和大小。倒序开关会反转当前排序结果。

常见用法：

| 目的 | 建议 |
| --- | --- |
| 按字母或标题找片 | 名称 |
| 看最近加入或修改的文件 | 日期 |
| 找大文件、检查空间 | 大小 |
| 想让最新内容排在前面 | 日期 + 倒序 |

首页的“最近更新”有自己的天数和栏目规则，不完全等同于这里的文件列表排序。

### 滚动边界回弹和滚动加速

滚动边界回弹默认开启，到列表顶部或底部时会有边界反馈。滚动加速默认开启，连续滚动时会逐渐加快。

高级选项中的“滚动加速倍率上限”范围是 1 到 10，默认 3。鼠标滚轮滚得太快时降低它；长列表翻页觉得不够快时再提高。标记为高级的选项需要先在“设置 → 账户”打开高级设置。

## 搜索和缩略图

### 模糊搜索

模糊搜索默认开启，能容忍一部分文件名或标题拼写差异。匹配度默认 70，范围是 1 到 100：

- 数值低：更容易搜到，但可能出现更多不相关结果；
- 数值高：结果更严格，输入名称必须更接近。

如果搜索一个明确文件名却出现太多结果，提高匹配度；如果经常因为少写了年份、符号或空格而搜不到，可以降低。

### 缩略图动态压缩

开启后，zPlayer 会根据显示尺寸调整缩略图加载，尽量减少不必要的解码和内存占用。默认开启。只有在排查缩略图清晰度或特殊显示问题时，才需要尝试关闭。

### 静态缩略图

默认开启，允许使用已经生成或缓存的缩略图，减少重复生成。关闭后可能导致列表加载更慢、磁盘和 CPU 工作方式发生变化。

### 缩略图宽度

桌面端可选 280、320、360、400、440、480，默认 320。数值越大，缩略图越清晰，也越占用内存和缓存空间。

一般建议：

- 普通笔记本：280 或 320；
- 高分辨率大屏：360 或 400；
- 只有在确实需要大图时才选 440 或 480。

### 动图预览

开启后，列表中的部分媒体会显示 GIF 动态预览。默认开启。高级选项可以调整：

| 设置 | 可选值 | 默认值 |
| --- | --- | ---: |
| 动图时长 | 3、5、7、10、13、15 秒 | 10 秒 |
| 动图帧数 | 10、12、15、24 | 15 |
| 动图宽度 | 280、320、360、400、440、480 | 320 |

动图预览更有表现力，但会增加解码、缓存和功耗。列表滚动卡顿、笔记本风扇频繁转动时，可以先关闭动图预览，再考虑降低宽度或帧数。

## 高级调色算法

“调色算法”用于从图片提取界面或卡片需要的代表色，提供 RGB、OcTree 和 Median-Cut 三种方式，默认是 OcTree。

它不会改变海报文件。只有在你很在意封面取色效果，或者遇到特定图片颜色异常时才需要调整；普通用户保持默认即可。

## 推荐的调整顺序

遇到问题时，不要一次把所有选项都改掉：

1. 文件看不到：检查来源、文件格式、隐藏项目和加载过滤；
2. 列表太拥挤：调整网格大小和缩略图宽度；
3. 搜索太宽或太严：调整模糊搜索匹配度；
4. 滚动不舒服：先关掉滚动加速，再调倍率；
5. 列表卡顿：先关闭动图预览，或降低缩略图宽度；
6. 每次只改一项，确认效果后再继续。
