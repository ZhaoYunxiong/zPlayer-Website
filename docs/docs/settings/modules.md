# 模块与启动页

入口是“设置 → 模块”。这里决定左侧导航显示哪些可选页面，以及软件启动后优先进入哪里。关闭模块只隐藏入口，不会删除对应数据。

## 选择启动默认页面

可选页面包括首页、媒体库、在线库、流媒体、播放列表、工具箱和[历史记录](/docs/media/history)。

- 刚开始使用：保留“媒体库”，先确认文件和连接可访问。
- 已完成扫描和刮削：可改成“首页”，直接查看海报墙和继续观看。
- 主要使用固定直播或网络地址：可选择“流媒体”。
- 经常做格式处理：可选择“工具箱”。

启动页对应的模块必须保持开启。若先选择某页、之后又关闭该模块，启动时可能无法进入预期入口。

## 模块开关

| 模块 | 关闭后的影响 | 数据是否删除 |
| --- | --- | --- |
| 首页 | 左侧不显示首页 | 否，刮削数据和栏目仍保留 |
| 在线库 | 隐藏在线媒体入口 | 否，站点配置仍保留 |
| 流媒体 | 隐藏已保存流媒体列表 | 否，地址列表仍保留 |
| 播放列表 | 隐藏独立播放列表入口 | 否，清单仍保留 |
| 工具箱 | 隐藏媒体处理工具 | 否，但正在执行的任务不要通过切换入口来管理 |
| [历史记录](/docs/media/history) | 隐藏独立历史页 | 否，播放历史仍保留 |

“打开”“媒体库”和“设置”属于基础入口，不在这组可选模块开关中。

## 找不到入口时

1. 先到“设置 → 模块”确认对应开关。
2. 如果整个高级设置项都没显示，到“设置 → 账户”开启高级设置显示。
3. 修改后回到主导航检查；必要时重新进入页面。

首次使用各入口的区别见[主界面与基本概念](/docs/getting-started/interface)，保存直播地址见[流媒体链接](/docs/tools/streaming)，工具箱见[媒体处理工具箱](/docs/tools/media-toolbox)。
