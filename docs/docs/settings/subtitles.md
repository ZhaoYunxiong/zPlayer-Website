# 字幕设置参考

入口是“设置 → 播放器 → 字幕”。这一页决定字幕引擎、默认样式、位置、动画、翻译和自动匹配行为；播放时临时选择字幕轨道的方法见[字幕使用指南](/docs/player/subtitles)。

## 先选字幕引擎

- zPlayer 引擎：支持多字幕同时显示、完整样式、动画和翻译等应用层能力。
- Native 引擎：由播放内核管理单条字幕轨道，适合需要内核原生渲染的情况。

遇到字幕不显示时，先保留默认引擎并确认轨道本身有效。只有在 ASS 特效兼容、性能或多字幕需求明确时再切换。

## 样式与位置

字体、字号、描边、阴影、颜色、位置和安全区域只改变显示，不会修改原字幕文件。建议按这个顺序调整：

1. 先确认字幕能显示且时间轴正确。
2. 调字号和垂直位置，避免被播放器控件或画面边缘遮挡。
3. 再调描边、阴影和颜色，提高明暗画面中的可读性。
4. 最后开启动画，检查长句和低性能设备是否仍然流畅。

## 翻译

字幕翻译需要 zPlayer 字幕引擎和可访问的翻译服务。选择目标语言与“只显示译文 / 译文在上 / 译文在下”后，再开启翻译。修改语言或模式时，关闭并重新开启当前翻译任务。

“内封字幕翻译”会尝试使用或提取视频容器里的字幕轨道；网络或服务不可用时，结果可能只保留原文。翻译不会覆盖原字幕文件。

## 动画与多字幕

动画预设和细节选择见[字幕动画](/docs/player/subtitles#subtitle-animation)。zPlayer 字幕引擎没有人为设定的固定多字幕条数上限，但同时显示过多轨道会遮挡画面并增加渲染负担。

## 改完没有生效

当前字幕任务可能保留了旧设置。先重新选择轨道或重新打开媒体；如果仍有问题，再按[字幕、弹幕或音频异常](/docs/troubleshooting/subtitle-and-danmaku)排查。
