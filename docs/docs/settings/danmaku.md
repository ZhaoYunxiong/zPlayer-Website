# 弹幕设置参考

入口是“设置 → 播放器 → 弹幕”。这里控制弹幕的默认显示方式、密度、透明度、速度、区域和性能相关选项；如何搜索、加载和切换弹幕见[弹幕使用指南](/docs/player/danmaku)。

## 推荐调整顺序

1. 先确认当前媒体已经加载了正确的弹幕来源。
2. 弹幕太密时，先降低数量或显示区域。
3. 挡住字幕时，再调整透明度、字号、区域或字幕避让。
4. 移动过快或过慢时，最后调速度。
5. 出现掉帧后，关闭补帧或其他性能开销较高的效果。

弹幕设置只影响评论层，不会改变视频、音轨或字幕文件。搜索不到弹幕时，调整透明度和速度不会有帮助，应先检查媒体标题、集数和网络来源。

## 画面和性能的取舍

更高密度、更大字号和补帧会让弹幕更醒目，也会占用更多渲染资源。低功耗设备或高分辨率视频出现卡顿时，先关闭弹幕确认视频本身是否流畅，再逐项恢复。

## 一套稳妥的默认思路

- 电影、纪录片：低密度、较高透明度，或临时关闭。
- 动画和综艺：中等密度，给底部字幕留出区域。
- 学习和跟读：关闭弹幕，避免与多字幕争夺注意力。

设置改动后仍无显示，继续查看[字幕、弹幕或音频异常](/docs/troubleshooting/subtitle-and-danmaku)。
