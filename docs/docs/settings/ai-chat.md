# AI 对话与 Agent：把问题说清楚，再让它动手

AI 对话可以读你给的文件、调用 zPlayer 里的工具、查媒体信息、打开页面，遇到长任务还会自己分步骤做。你要做的是把目标说清楚，知道它现在做到哪一步，该批准的时候批准，该停的时候停。

## 从哪里进入

- 在媒体卡片菜单里选“询问AI”，会带着当前媒体打开对话。
- 在“设置 → 在线库 → JS 爬虫站点 → AI生成站点”里，页面下方就是内嵌对话，用来生成或修复站点。具体步骤见[AI 生成与修复 JS 站点](/docs/media/online/js-site-generation)。
- 在命令面板里搜“对话列表”或“Agent”，也能打开对话页。

对话页左侧或顶部的对话列表可以新建会话、切换旧会话。每个会话的上下文和设置是分开的，换一个会话不会把上一个会话的内容带过去。

## 基本操作

输入框旁边可以选模型、附加文件或图片。发送后可以停止生成；回答完成后可以重新生成、复制或删除某条消息。

模型不支持工具调用时，对话会退回普通文本问答：它能读你贴的内容，但不能自己打开页面、查媒体库或执行操作。图片理解还需要默认视觉模型支持视觉输入，光有对话模型不够。

## 工具调用怎么看

AI 调用工具时，消息里会出现一条可折叠的记录。点开能看到这次调用的参数、返回结果、执行状态和用时。状态一般分为成功、失败、执行中、已拒绝和超时，失败时先看返回结果里的错误，不要只看 AI 后面的解释。

如果工具产出了文件，记录里会出现“打开产物”；如果是长任务里的作业，可以查看作业输出。产物和作业都放在本地，打开前先确认路径是你预期的位置。

## 思考强度

聊天页可以给当前会话单独调思考强度，默认跟随 AI 设置里的“模型默认思考强度”。聊天页把这个入口合并成了一个选项，从“关闭思考”到最高档一次选完：默认、关闭、轻度、中等、高、极高和最大；强度越高，模型想得更多，等待时间也可能更长。

这个功能目前只对 OpenAI 及兼容接口生效。用其他服务商时，思考强度选项可能不可用，这是接口能力限制。简单问答用低强度就够，复杂排错或写站点脚本再用高强度。

## 上下文圆环

输入框旁边有一个圆环，显示当前会话用了多少上下文。它按 AI 设置里的上下文窗口计算，取窗口的 95% 作为可用上限，K 按 1000 tokens 显示。接口没有返回真实用量时，圆环会标成“估算”，不要拿它和服务商账单对数字。

上下文快满时，长任务会尝试把前面的对话压缩成摘要，保留目标和关键结果，再继续做。压缩失败时会保留完整原始对话，并提示你可以重试或新开会话。重要的约束最好在任务开头写清楚，压缩后不容易丢。

## 审核模式

新对话默认开启审核。读数据、查页面这类白名单操作会自动放行；安装、删除、修改文件、执行有副作用的操作时，会先弹出确认。你可以批准、拒绝，或者在输入框里补充条件再让它继续。

已有对话会保留自己的审核模式，不会因为你改了默认设置就全部变掉。聊天输入栏里可以切换当前会话的审核开关；关闭后所有操作直接执行，适合你盯着它做重复工作的时候。

被拒绝的操作不应该换一个工具继续试。如果它这么做了，直接停止任务，检查它想改的文件或站点。

## 长任务和预算

复杂任务会分多轮模型请求和工具调用。软件会给长任务设置模型请求轮数和运行时长上限，达到上限时提示你调整预算或继续任务，不会无限跑下去。

任务运行中可以停止，已经写好的文件、草稿和产物通常会保留。继续任务时，软件会接着当前会话和产物往下做，不需要把所有内容重新说一遍。

长任务适合生成 JS 站点、批量查资料、整理媒体信息这类需要多步操作的事情。普通问答不用开长任务，直接用默认对话更省时间。

## 常见问题

| 现象 | 先检查什么 | 处理 |
| --- | --- | --- |
| 模型不支持工具调用 | 当前模型是不是只支持文本 | 到 AI 设置里换一个支持工具调用的模型 |
| 圆环突然变红或提示上下文不足 | 当前会话是不是太长 | 新开会话，或让软件压缩后继续 |
| 一直转圈没有输出 | 网络、模型服务或工具调用是否卡住 | 停止生成，查看最后一条工具记录；换模型或稍后重试 |
| 审核弹窗一直不出现 | 当前对话是不是关了审核 | 在输入栏打开审核模式，或检查默认审核设置 |
| AI 说已经完成，但文件没变 | 工具调用是不是失败或被拒绝 | 展开工具记录看返回结果，不要只看文字总结 |
| 生成结果不准确 | 站点、媒体信息或输入本身有歧义 | 补充具体页面、路径、错误信息和预期结果 |

## 安全提醒

AI 会犯错，尤其是站点脚本、文件操作和播放源这类事情。让它改文件前先备份，装站点前先看验证报告，涉及账号和密钥的内容不要直接贴进对话。

对话记录、附件和工具结果可能保存在本机。不要把 API Key、Cookie、媒体服务器密码和私人文件发到云端模型；需要排查时，先脱敏再发。
