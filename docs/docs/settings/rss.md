# RSS 订阅与自动下载

RSS 用于聚合资源更新，并可把符合条件的项目发送给 qBittorrent 或 Aria2。它和 Bangumi、Trakt 的观看记录同步不是同一件事。

## 先手动跑通订阅

1. 打开“设置 → RSS 订阅”。如果没有这个高级设置入口，先到“设置 → 账户”开启高级设置显示。
2. 添加标题、内容类型和 RSS 地址。
3. 手动刷新，确认能看到预期条目。
4. 检查标题、集数和下载链接是否能被正确识别。
5. 完成上述验证后，再考虑自动下载、刮削或番剧补全。

只添加你信任并有权使用的订阅。普通网页地址不等于 RSS 地址；添加成功但没有内容时，应先用浏览器确认地址确实返回 RSS/XML。

## RSS 更新与聚合

“RSS 更新”控制自动检查间隔，默认 10 分钟。它只负责刷新订阅，不等于自动下载。“聚合”会把多个订阅结果放在一起浏览，不会合并或去重服务器上的资源。

## 配置搜索引擎

搜索引擎 URL 必须包含 `%s` 作为关键字占位符，例如：

```text
https://example.com/search?q=%s
```

搜索时 zPlayer 会把 `%s` 替换为输入的关键词。没有占位符的普通首页地址不会形成有效搜索；需要登录、验证码或复杂脚本的网站也可能无法直接使用。

## 自动下载

自动下载默认关闭。开启前填写：

| 设置 | 应该填什么 |
| --- | --- |
| 下载工具 | qBittorrent 或 Aria2 |
| 远程下载 API | 下载器实际提供的 API 地址 |
| 下载路径 | 下载器所在机器看到的保存路径 |
| 下载分类 | 下载器中的分类或标签 |
| 远程账号、密码 | 下载器 API 的登录信息 |

如果下载器运行在 NAS 或另一台电脑上，“下载路径”不能直接照抄 zPlayer 电脑上的盘符。先在下载器端确认路径，再配置下面的媒体挂载映射。

## 过滤、刮削和路径映射

下载过滤使用正则表达式，命中的资源会被跳过。一次只添加一条规则并观察结果；过宽的表达式可能把需要的版本一起过滤。

开启“媒体刮削”或重命名后，必须设置 zPlayer 可以访问的“媒体挂载路径”。可以这样理解：

- 下载路径：qBittorrent 或 Aria2 看到的目录；
- 媒体挂载路径：zPlayer 在 Windows 中访问同一批文件的目录。

下载成功但 zPlayer 找不到文件，通常是这两个路径没有正确对应，或网络共享尚未挂载。

## 番剧补全

番剧补全会根据已识别的番剧、搜索引擎和制作组信息，尝试找出缺少剧集并加入选择或下载流程。它依赖标题解析和搜索源，不保证每次匹配正确。发现补错、重复或版本不合预期时，先关闭补全，再检查搜索引擎与过滤规则。

## 邮件下载报告

报告推送需要邮箱地址以及该邮箱的密码或 SMTP 授权码。多数邮箱服务建议使用单独授权码，而不是网页登录密码。报告失败时检查 SMTP 权限、授权码和网络连接。

不要在日志、截图或公开反馈中保留邮箱授权码、下载器密码、Cookie 或私有订阅地址。
