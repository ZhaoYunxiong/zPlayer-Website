# AI、Whisper、RSS 与模块

这一页包含四组用途差别很大的设置。AI 和 Whisper 是可选能力，RSS 是订阅与下载自动化，模块是导航入口开关。普通播放不需要配置它们。

::: warning 先看隐私和费用
云端 AI 会把请求发送到你配置的服务商，可能产生费用；媒体语音识别和语义索引也可能消耗大量 CPU、GPU、磁盘或网络。不要把私人媒体内容、API Key 和账号密码贴到公开反馈里。
:::

## AI 模型

入口是“设置 → AI”。

### 三种默认模型

| 设置 | 用途 |
| --- | --- |
| 对话模型 | 文本问答、需要对话或工具调用的功能 |
| 视觉模型 | 需要理解图片或画面的功能 |
| 嵌入模型 | 语义搜索和媒体内容索引 |

嵌入模型还有“向量维度”设置，默认是 1024。只有在你明确知道所选模型的向量维度时才修改；模型和维度不匹配，可能导致旧索引无法继续使用，需要重新建立索引。

### 服务商和模型配置

每个服务商可以填写：

- API 密钥；
- API 地址；
- 一个或多个模型；
- 模型支持的能力。

添加模型时需要标记它是否支持工具调用、视觉理解和嵌入。标记决定它会不会出现在对应的默认模型下拉框里，不代表 zPlayer 能替模型增加能力。

界面提供多种云端服务商，也提供 Ollama。云端服务适合不想在本机运行模型的用户；Ollama 适合已经在本机部署模型、希望尽量不把内容发到外部的用户。使用 Ollama 时，zPlayer 会尝试读取本机服务中的模型列表；服务没有启动时，需要先启动 Ollama，并确认地址和模型名称。

如果服务商使用 OpenAI 兼容接口，API 地址通常要填服务商给出的兼容接口地址，而不是官网首页地址。填错地址时，最常见的表现是模型列表或请求全部失败。

### 还原预设模型

“还原预设模型”会清理当前 AI 模型配置并恢复软件预设，同时重新设置默认对话、视觉和嵌入模型。

这是排查“模型配置被改乱”时的快捷办法，但会覆盖你自己添加的服务商和模型。点击前先记下自定义地址和模型名称。

## Whisper 实时字幕

入口是“设置 → Whisper”。播放器里的实际使用方法见[Whisper AI 字幕](/docs/player/whisper)。

### 默认实时字幕参数

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 默认模型 | 按本机已有模型决定 | 播放时优先使用的 Whisper 模型 |
| 默认识别语言 | 自动 | 让模型自动判断语音语言 |
| 默认翻译语言 | 跟随软件语言 | 识别后翻译成的目标语言 |
| 实时字幕队列时长 | 30 秒 | 提前准备多少秒的识别任务，范围 15–300 秒 |
| 自动保存实时字幕 | 开启 | 是否把生成的实时字幕保存下来 |

队列时间越长，字幕越不容易因为处理速度波动而断开，但会增加等待时的资源占用。电脑性能较弱时先保持默认；如果实时字幕经常追不上进度，可以适当增加队列。

### 模型列表

模型需要单独下载。下载来源有多个镜像或托管选项，选择能稳定访问的即可。模型保存在本机的 zPlayer 数据目录中，下载前确认磁盘空间。

删除模型会释放本机空间，但之后不能再用它做实时识别，除非重新下载。模型下载失败时，先换下载来源、检查代理和磁盘权限。

## RSS 订阅与自动下载

入口是“设置 → RSS 订阅”。它和 Bangumi、Trakt 的观看记录同步不是一回事：RSS 负责订阅资源更新，外部追剧同步负责同步看过什么。

### 订阅、搜索和种子记录

RSS 页面可以：

- 添加订阅标题、内容类型和地址；
- 选择是否聚合订阅结果；
- 刷新或清空订阅；
- 通过搜索引擎搜索资源；
- 打开种子管理查看已记录的下载项目。

搜索引擎由名称和 URL 组成，URL 需要保留搜索关键字占位符。不要随便把普通网页地址当成 RSS 地址；如果站点没有提供 RSS 或搜索接口，添加成功也可能无法加载。

订阅地址和搜索站点只使用你信任的来源。RSS 内容可能包含失效链接、重复资源或不符合预期的文件名。

### RSS 加载

“RSS 更新”控制自动检查订阅的间隔，默认 10 分钟。它只负责刷新订阅，不等于自动下载。

### RSS 下载

“自动下载”默认关闭。开启后，zPlayer 会把符合条件的资源推送给下载器。界面提供 qBittorrent 和 Aria2 选项，具体要和你的下载器 API、账号和目录规划保持一致。

相关设置包括：

| 设置 | 应该填什么 |
| --- | --- |
| 远程下载 API | 下载器提供的 API 地址 |
| 远程下载路径 | 下载器所在环境看到的目标路径 |
| 种子分类 | 下载器中的分类或标签 |
| 远程登录账号、密码 | 下载器 API 的登录信息 |

如果下载器运行在另一台机器上，不能直接把 zPlayer 本机路径当成远程下载路径。先确认下载器实际保存到哪里，再配置媒体挂载路径。

### 资源过滤

资源过滤使用正则表达式。命中规则的资源会被跳过，适合排除分辨率、制作组、语言或不想要的版本。

规则写得过宽会把好资源一起过滤掉。建议一次只添加一条规则，先观察几次刷新结果，再继续调整。

### 媒体刮削和挂载路径

开启“媒体刮削”后，下载完成的番剧资源会尝试按识别出的标题和剧集整理并刮削。此时必须填写“媒体库路径”或“媒体挂载路径”：

- 远程下载路径：下载器接收到的保存目录；
- 媒体挂载路径：zPlayer 自己能够访问到的同一份媒体目录。

两台机器的目录结构不一致时，要填 zPlayer 环境中的实际映射路径，否则下载可能成功，但 zPlayer 找不到文件或无法刮削。

### 番剧补全

开启后，zPlayer 会根据已识别的番剧和搜索引擎尝试查找缺少的剧集并加入下载流程。它适合追番自动补集，但也更依赖标题解析、搜索源和分组名称。

发现补错、重复或下载了不想要的版本时，先关闭番剧补全，再检查资源过滤和搜索源。

### 下载报告

报告推送需要填写邮箱地址和邮箱密码或授权码。很多邮箱要求使用“授权码”而不是网页登录密码；如果不确定，按邮箱服务商的 SMTP 设置填写。

不要在公开反馈里发送邮箱密码、授权码或下载器密码。报告失败时，先检查邮箱服务商是否允许 SMTP、账号是否开启了授权码，以及网络是否能访问邮件服务。

## 模块与启动页

入口是“设置 → 模块”。

### 启动默认页面

可选：首页、媒体库、在线库、流媒体、播放列表、工具箱和历史记录。

新配置默认进入媒体库，这是最通用的起点。如果你已经有整理好的本地电影和电视剧，并且希望打开软件直接看到海报、继续观看和动态栏目，可以把首页设为启动页。首次启动和页面选择见[首次启动](/docs/getting-started/first-launch)。

启动页对应的模块如果被关闭，启动时可能无法进入预期页面。因此修改启动页后，要确认对应模块仍然开启。

### 模块开关

页面提供这些模块的显示开关：

| 模块 | 关闭后 |
| --- | --- |
| 首页 | 隐藏首页入口 |
| 在线库 | 隐藏在线媒体入口 |
| 流媒体 | 隐藏流媒体入口 |
| 播放列表 | 隐藏播放列表入口 |
| 工具箱 | 隐藏工具箱入口 |
| 历史记录 | 隐藏历史记录入口 |

关闭模块只是隐藏导航入口，不会删除媒体、播放记录、片单或已保存的配置。以后重新开启，数据仍然可以继续使用。

## 最稳妥的配置顺序

1. 先配置一个 AI 模型，确认对话、视觉或嵌入能力中你真正需要的部分；
2. 再下载一个 Whisper 模型，实际播放时测试实时字幕；
3. RSS 先只添加一个可信订阅，手动刷新几次；
4. 确认下载路径和媒体挂载路径后，再考虑开启自动下载；
5. 最后调整模块和启动页。

这样出了问题时更容易知道是哪一组设置造成的。
