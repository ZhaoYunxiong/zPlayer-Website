# AI、Whisper、RSS 与模块

这四类功能放在相邻的高级设置中，但用途彼此独立。普通媒体播放不要求配置它们；需要哪一项，再进入对应页面即可。

| 功能 | 用途 | 详细文档 |
| --- | --- | --- |
| AI | 对话、视觉理解、媒体摘要和语义搜索 | [AI 模型与内容理解](/docs/settings/ai) |
| Whisper | 从音频生成或实时显示字幕 | [Whisper AI 字幕](/docs/player/whisper) |
| RSS | 聚合订阅、搜索资源并按需自动下载 | [RSS 订阅与自动下载](/docs/settings/rss) |
| 模块 | 决定左侧显示哪些入口，以及启动时进入哪一页 | [模块与启动页](/docs/settings/modules) |

::: warning 隐私、费用与资源占用
云端 AI 会把请求发送到你配置的服务商并可能产生费用；RSS 自动下载会占用带宽和磁盘；Whisper 和语义索引可能长期占用 CPU、GPU 与存储。先完成单项测试，再开启自动处理。
:::

## 推荐配置顺序

1. 先保持模块默认值，确认本地文件能正常播放。
2. 需要 AI 时只配置一个模型并测试对应能力。
3. 需要语音识别时下载一个 Whisper 模型，在短视频上验证速度。
4. RSS 先手动刷新一个可信订阅，确认路径映射后再开启自动下载。

这样出现问题时，可以明确判断是模型、订阅、下载器还是导航配置造成的。
