# 账户、网络与其他：本机账户、代理和数据管理

这里合并说明“设置 → 账户”和“设置 → 其它”中的选项，包括本机用户管理、内购状态、语言、代理、配置备份和缓存清理。

## 先分清两种账户

zPlayer 里有两种不同的账户概念：

- Microsoft 账户：用于 Microsoft Store 安装和内购授权，解锁状态与购买账户绑定；
- zPlayer 本机账户：用于在软件内区分使用者、播放记录和播放列表。

本机账户不是 Microsoft 账户的登录入口，也不会自动把本机配置同步到另一台电脑。内购说明见[内购解锁](/docs/getting-started/unlock)。

## 本机账户

入口是“设置 → 账户”。

### 解锁 PIN

账户页可以为管理员设置或修改软件解锁 PIN。这个 PIN 是 zPlayer 本机账户的验证信息，不是 Microsoft 账户密码。

建议使用一个不会和 Microsoft 账户、邮箱或媒体服务器重复的 PIN。忘记后不要把 PIN 发到公开群组，反馈时只说明“无法解锁”即可。

### 添加账户

添加新账户前，需要先设置管理员密码。新账户包含用户名和软件解锁 PIN，适合家庭共用一台电脑、又希望各自保留浏览记录的情况。

### 删除账户

只有管理员可以删除账户，管理员账户、自带管理员账户和当前正在使用的账户不能删除。

删除一个普通账户时，与该账户相关的浏览记录、播放列表等信息也会一起删除。确认前先让该用户导出或记录需要保留的内容。

### 高级设置

账户页里的“高级设置”开关控制其他设置页中标记为高级的选项是否显示。它不会解锁媒体服务器连接，也不等于 Microsoft Store 的内购授权。

如果需要调整滚动倍率、代理、缓存路径或缩略图高级参数，可以从这里查找对应开关。

## 语言

当前可选简体中文和 English。切换语言后，界面资源会按新语言加载；如果你正在阅读中文文档，不需要为了使用中文界面额外修改其他设置。

## 网络代理

入口是“设置 → 其它 → 网络代理”。可选三种模式：

| 模式 | 作用 |
| --- | --- |
| 系统代理 | 使用 Windows 当前配置的代理 |
| 不使用代理 | zPlayer 直连网络 |
| 手动代理 | 使用你填写的代理地址 |

手动代理模式下还可以选择“绕过局域网”。开启后，访问本地地址、NAS 或局域网媒体服务器时尽量不经过代理；如果你的网络环境必须通过代理访问某些内网地址，再按实际情况关闭。

排查联网问题时建议按这个顺序：

1. 用浏览器确认目标地址本身能访问；
2. 确认是 zPlayer 的哪个来源失败；
3. 再尝试系统代理、手动代理或直连；
4. 把代理地址和认证信息从反馈内容中脱敏。

代理只影响网络请求路径，不会修复错误的媒体分类、目录结构或刮削匹配。

## 配置路径和缓存

“配置路径”可以打开 zPlayer 的数据目录，适合高级排查和备份前确认位置。

“删除所有缓存”只清理缓存目录，例如缩略图、首页缓存和临时数据，不会删除你的原始视频、音频或 NAS 文件。清理后第一次进入首页或列表可能需要重新加载，速度会比平时慢。

如果只是某一张海报显示不对，优先使用媒体详情里的重新刮削或元数据编辑，不要动不动清空整个缓存。

## 重置配置

“重置配置”会把软件设置恢复为默认值，并且操作不可恢复。它适合配置被改乱、无法判断是哪项设置导致问题时使用。

重置前至少记下：

- 媒体来源地址和分类；
- 媒体服务器账号；
- TMDB、AI、ThePornDB 等密钥；
- 播放器和字幕习惯；
- 本机账户和 PIN。

原始媒体文件不会因为重置配置而消失，但连接、界面、播放和服务参数会回到默认状态。

## 软件数据备份与恢复

### 备份

“备份当前软件数据”会导出 zpb 备份包，主要保存 zPlayer 的配置和软件数据，适合换机前、重装前或尝试大范围改设置前留一份可回退的副本。

备份包不包含你的电影、电视剧和音频原文件，也不会把媒体库内容复制到备份包中；缓存、首页缓存和日志也不在备份范围内。因此恢复后，媒体文件仍需要位于原来可访问的位置，缓存可能重新生成。

zpb 文件里可能包含来源地址、账户配置和令牌等敏感信息，请像保管密码一样保存，不要上传到公开网盘或直接发到群里。

### 恢复

“从备份包恢复软件数据”会覆盖当前软件数据。恢复完成后软件会自动关闭，需要重新启动才会生效。

恢复前建议：

1. 先备份当前状态，以免新备份本身有问题；
2. 确认选择的是正确的 zpb 文件；
3. 确认备份对应的 zPlayer 版本和数据用途；
4. 恢复后检查来源地址、账户和媒体路径。

## 一句话判断

- 购买状态不对：看 Microsoft Store 账户和[内购解锁](/docs/getting-started/unlock)；
- 播放记录想分开：使用 zPlayer 本机账户；
- TMDB 或在线站点访问不了：看代理和[网络与 TMDB](/docs/troubleshooting/network-and-tmdb)；
- 首页变空但文件还在：先清缓存并等待重新加载，不要删除原始媒体；
- 配置改乱：先备份，再考虑重置。
