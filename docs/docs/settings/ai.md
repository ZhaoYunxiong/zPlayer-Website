# AI 模型与内容理解

zPlayer 的 AI 设置负责告诉软件“请求发给谁、使用哪个模型、模型具备什么能力”。入口是“设置 → AI”。AI 是可选能力，不影响普通本地播放。

## 三种默认模型

| 默认模型 | 用途 |
| --- | --- |
| 对话模型 | 问答、媒体摘要、章节或剧情内容生成，以及支持工具调用的助手功能 |
| 视觉模型 | 理解用户附加的图片或从画面取得的视觉信息 |
| 嵌入模型 | 把媒体摘要、字幕和章节转成语义索引，用自然语言搜索内容 |

同一个模型可以具备多种能力，但只有在模型配置中正确标记后，才会出现在相应的默认模型列表。能力标记不会替模型增加服务端本来没有的功能。

嵌入模型还会涉及向量维度。除非服务商明确要求，否则保留默认值；更换模型或维度后，旧索引可能无法继续使用，需要重新建立。

## 使用 AI 助手

配置默认对话模型后，在媒体卡片的菜单中选择“询问 AI”，zPlayer 会打开对话页，并根据当前媒体标题或可取得的 TMDB 资料开始分析。对话模型支持工具调用时，还可以按模型能力调用 zPlayer 提供的查询或媒体工具；不支持时，功能会退回普通文本问答。

对话页可以附加文件。图片理解需要已经配置默认视觉模型，并且该模型确实支持视觉输入。AI 给出的剧情、人物和媒体信息都可能出错，播放来源、集数和实际画面仍以原媒体为准。

## 添加服务商和模型

1. 在 AI 设置中添加或选择服务商。
2. 按服务商文档填写 API 地址与 API Key。
3. 添加模型名称，并标记工具调用、视觉和嵌入等实际能力。
4. 在页面顶部选择默认对话、视觉或嵌入模型。
5. 用一段非敏感内容做小范围测试。

OpenAI 兼容服务需要填写它提供的兼容 API 基地址，而不是官网首页地址。`401`、`403` 通常与密钥或权限有关；`404` 常见于 API 地址或模型名称不对；限额错误需要到服务商后台检查余额与速率限制。

## 使用 Ollama 在本机运行

如果已经安装并启动 Ollama，zPlayer 会尝试访问本机 `http://localhost:11434` 并读取模型。列表为空时，先确认：

- Ollama 服务正在运行；
- 模型已经在 Ollama 中下载完成；
- 本机防火墙或代理没有拦截 localhost；
- 模型名称与 Ollama 实际名称一致。

本地模型能减少内容发送到第三方，但仍会占用本机内存、显存和磁盘。模型越大不一定越适合实时使用。

## 视觉模型与多模态

视觉模型用于理解图片或视频画面相关输入。使用时，应选择真正支持视觉输入的模型，并在模型配置中开启视觉能力。仅支持文本的模型即使被手工标记，也可能在上传图片后报错。

多模态结果是模型对输入的推断，不是原始媒体事实。人物、字幕、画面细节和时间点都可能识别错误，重要内容仍需回到原视频核对。

## 媒体摘要与智能搜索

启用相应首页内容索引后，嵌入模型可以为媒体摘要、字幕或 AI 章节建立语义索引，让搜索不只依赖标题和文件名。播放器里的章节、故事剧情和内容搜索见[播放列表与内容模块](/docs/player/content-modules)，首页搜索见[搜索、分类与推荐](/docs/media/home/search-and-recommendation)。

第一次建立索引可能需要时间和额外存储。更换嵌入模型、向量维度或清理索引后，需要等待重新生成；索引还没完成时，语义搜索结果可能不完整。

## 隐私与费用

使用云端模型时，文本、图片、字幕或媒体摘要可能会发送给所配置的服务商。不要上传不愿离开本机的私人内容，也不要在截图和反馈中泄露 API Key。费用、保存策略和内容使用规则以服务商条款为准。

“还原预设模型”会清理当前 AI 模型配置并恢复软件预设，也会覆盖你添加的自定义服务商和模型。只在准备好重新配置时使用。
