# 主题与外观：先让界面看着舒服

入口是“设置 → 主题”。这里主要有两个选项：明暗主题和主题颜色，不需要为了换个颜色去改配置文件。

## 主题模式

可选：

| 模式 | 适合谁 |
| --- | --- |
| 浅色 | 白天使用、喜欢明亮界面 |
| 深色 | 夜间观看、希望界面更柔和 |
| 自动 | 跟随 Windows 的系统主题切换 |

新配置默认是浅色。平时白天办公、晚上看视频，建议选“自动”；如果你不希望系统主题变化影响 zPlayer，直接固定浅色或深色即可。

主题切换会立即影响界面，不会改变媒体文件、刮削资料或播放器画面本身。

## 主题颜色

主题颜色是界面的强调色，会影响按钮、选中状态、进度条等交互元素。它不改变海报原图，也不等同于播放器里的视频滤镜。

如果自定义颜色导致文字或按钮不容易看清，换回一个对比度更明显的颜色即可。遇到局部显示异常时，先切回浅色或深色的固定模式，再判断问题是否仍然存在。

::: tip 和视频画面有关的设置不在这里
播放器的着色器、滤镜、字幕颜色和画面比例，请看[画质与滤镜](/docs/player/video-quality)和[字幕](/docs/player/subtitles)。
